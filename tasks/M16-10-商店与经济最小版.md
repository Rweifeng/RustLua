# M16-10 商店与经济最小版

## 状态
DONE

## 类型
[引擎+玩法]

## 目标
新增 `shop` Lua API（商品目录/买/卖/资金），`data/shop.json` 数据驱动，实机完成买卖闭环。

## 背景
`main.lua` 用区域 if + 直接卖番茄，无商店概念。缺口清单 2.4 的闭环终点「出售」与 2.5 的资金在此落地；营业时间/库存/季节商品/交易确认面板留 M17-05。

## 输入
- `item` 定义、`inv`、`data.load`
- M16-06 收获产物、M16-07 背包

## 不做什么
- 不做营业时间/库存/季节商品/交易确认面板（M17-05）；
- 不做出货箱物流；
- 不做货币之外的计费规则。

## 依赖
M16-06、M16-07、M16-11

## 验收标准
1. `shop` API：定义商品目录（种子卖入、作物收购价）、`query`、`buy(item,n)` / `sell(item,n)`、资金扣加。
2. 数据驱动：`data/shop.json` 改价格/目录重载后立即生效。
3. 实机：商店位按交互键打开面板，买种子进背包扣钱、卖作物加钱，资金持久化。
4. 交易边界：钱不够拒绝购买、空物品拒绝卖出，均有提示不报错。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
Rust 单测：买卖金额、余额不足、空物品；实机：买卖闭环 + 改价重载生效。

## 风险
- 价格与物品定义重复 → shop.json 只存价格/上架，物品本体引用 item 定义；
- 资金溢出（Lua number）→ 单测边界。
