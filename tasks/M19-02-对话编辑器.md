# M19-02 对话编辑器

## 状态
BACKLOG

## 类型
[编辑器]

## 目标
多分支对话可视化编辑：节点/分支/条件，写回 `data/dialogue.json`。

## 背景
对话数据（M17-03）规模增长后需编辑器。建立在对话数据格式之上。

## 输入
- M17-03 `data/dialogue.json` 格式
- 编辑器节点图基础

## 不做什么
- 不做可视化节点图（先列表/树形编辑）；
- 不做运行时测试对话框；
- 不做多语言编辑（引用本地化键）。

## 依赖
M17-03

## 验收标准
1. 列出对话树，按 NPC/对话 ID 组织，支持编辑节点文本、分支、条件（时间/好感度/季节/任务）。
2. 保存写回 `dialogue.json`，与运行时读取格式一致。
3. 条件引用合法（引用存在的字段/物品/任务），非法引用在保存时警告。
4. 保存后游戏内对话即时生效。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：改一段对话→保存→游戏内触发新文案。

## 风险
- 条件表达式校验复杂 → 先限定条件字段集合，非法引用警告不阻塞；
- 与内容编辑器（M19-01）功能重叠 → 本任务专注对话语义。

- 已完成内容、修改文件、验证结果、已知问题、下一步建议。
