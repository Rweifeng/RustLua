# M20-03 发布包

## 状态
BACKLOG

## 类型
[工程]

## 目标
农场发布包闭环：数据表/字体/Lua 脚本打包路径正确，发布自测与安装包验证。

## 背景
农场功能新增 `game_farm/data/`、`scripts/` 多模块与本地化表，发布工具（assetc/M7 系列）需把新资源类型正确入包。复盘结论 §9.2 提到发布包字体路径需补齐统一。

## 输入
- `assetc`、发布配置（M7 系列）、`game_farm` 数据/脚本/字体
- 复盘结论 §9.2

## 不做什么
- 不做加密算法改动（沿用 M7-09）；
- 不做跨平台发布（先本机/Windows）。

## 依赖
所有里程碑

## 验收标准
1. 发布包包含：`data/*.json`、`scripts/*.lua`、字体、本地化表、素材；运行时从包内路径全部可加载。
2. 干净机器/目录运行发布包：农场从新档到完整一天玩法可玩。
3. 发布包运行无「找不到资源/字体/脚本」日志错误。
4. 安装包验证记录（M7-05 方法沿用）。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
发布：按 M7 发布流程打包 → 干净目录运行验证。

## 风险
- 数据表/字体打包遗漏 → 验收标准 1/3 逐资源核对；
- 运行时路径与编辑器路径不一致 → 统一资源寻址约定。

## AI 输出（实施后填写）
- 已完成内容、修改文件、验证结果、已知问题、下一步建议。
