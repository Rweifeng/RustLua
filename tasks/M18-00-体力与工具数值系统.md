# M18-00 体力与工具数值系统

## 状态
BACKLOG

## 类型
[引擎+玩法]

## 目标
体力上限/消耗/恢复、食物效果、工具等级与蓄力/作用范围、升级材料，全部数值数据化。

## 背景
缺口清单 3.5 要求玩家体力、工具消耗、食物恢复、工具等级、蓄力工具、作用范围、升级材料和状态效果。`main.lua` 目前体力是硬编码 `spend_energy`。

## 输入
- M16-03 工具系统、M16-08 体力恢复钩子
- M17-08 食物恢复
- `data/`（数值表）

## 不做什么
- 不做状态效果（中毒/加速等）具体内容，只留字段；
- 不做装备系统完整实现；
- 不做技能经验（M18-07）。

## 依赖
M16-03、M16-08

## 验收标准
1. 体力数值全部来自 `data/stats.json`：上限、动作消耗、恢复食物效果、工具等级数值。
2. 工具等级与蓄力：蓄力时长改变作用范围/效果，等级提高消耗降低。
3. 体力为 0 时工具动作被拒并有提示，睡醒恢复按规则。
4. 工具升级材料与升级流程可复现（数据驱动）。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：体力耗尽被拒、蓄力改变范围、升级工具后消耗变化；改 stats.json 生效。

## 风险
- 数值平衡靠拍脑袋 → 数值表集中 + 验收记录实际体验值；
- 蓄力与输入事件 → 用按住时长驱动，热重载时清蓄力态。
