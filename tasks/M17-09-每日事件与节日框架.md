# M17-09 每日事件与节日框架

## 状态
BACKLOG

## 类型
[引擎+玩法]

## 目标
日历事件总线、节日标记（日期→节日）、事件钩子（每日/节日触发回调）。

## 背景
缺口清单 2.2 要求每日开始/结束事件、节日。M16-08 已有 `on_day_start/end`，本任务把它扩展为可配置的事件/节日框架。

## 输入
- M16-08 `day`/`calendar`、M17-07 `weather`
- `data/festivals.json`（节日日期与行为）

## 不做什么
- 不做节日小游戏内容（留玩法扩展）；
- 不做商店节日特殊折扣规则的具体内容（框架给钩子即可）；
- 不做事件编辑器。

## 依赖
M16-08、M17-07

## 验收标准
1. 事件总线：`on_day_start`/`on_day_end`/`on_festival` 等钩子可被多个玩法订阅，不互斥。
2. 节日数据化：`data/festivals.json` 定义日期→节日名与行为回调。
3. 节日当天 UI 提示与行为变化（如商店不关门）可复现。
4. 事件/节日随日历推进自动触发，读档后当日事件一致。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
Rust 单测：节日日期匹配、多订阅回调顺序；实机：睡到节日当天触发提示。

## 风险
- 事件订阅泄漏 → 热重载时清空并重建订阅表；
- 节日触发顺序依赖 → 定义回调优先级。
