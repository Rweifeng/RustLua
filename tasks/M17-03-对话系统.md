# M17-03 对话系统

## 状态
BACKLOG

## 类型
[玩法]

## 目标
对话数据（`data/dialogue.json`）、对话框 UI、多分支、条件（时间/好感度/季节/任务）。

## 背景
缺口清单 3.1 要求对话框、多分支对话、条件。建立在 M16-02 交互与 M17-02 NPC 之上。

## 输入
- M16-02 交互、M17-02 NPC
- `ui` 动态面板（panel/image/tooltip/modal）
- `data/dialogue.json`

## 不做什么
- 不做送礼/好感度（M17-04）；
- 不做对话编辑器（M19-02）；
- 不做语音/表情动画。

## 依赖
M17-02

## 验收标准
1. 靠近 NPC 按交互键打开对话，对话框显示说话人与文本。
2. 支持多分支：按选项走不同分支，分支可引用条件（时间/季节/好感度/任务进度）。
3. 对话期间暂停玩家控制与时间推进，关闭后恢复。
4. 对话数据全在 `data/dialogue.json`，改文案重载生效；缺失条目明确报错。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：与 NPC 对话走完多分支、条件分支按状态切换。

## 风险
- 对话框状态机复杂化 → 先线性+单选分支，条件只读不写；
- 对话中时间暂停 → 与 DayLifecycle 冲突，用「对话占位符」暂停时钟步进。
