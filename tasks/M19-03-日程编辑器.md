# M19-03 日程编辑器

## 状态
BACKLOG

## 类型
[编辑器]

## 目标
NPC 日程可视化编辑：时间→地图/目标点/动作，写回 `data/npcs.json`。

## 背景
NPC 日程（M17-02）数据量大且易错，需编辑器。建立在日程数据格式之上。

## 输入
- M17-02 `schedule` 数据格式、`data/npcs.json`
- 编辑器表格/时间轴基础

## 不做什么
- 不做日程可视化时间轴动画；
- 不做寻路编辑器（M18 pathfind 数据）；
- 不做多 NPC 批量粘贴外的复杂操作。

## 依赖
M17-02

## 验收标准
1. 按 NPC 编辑一日/一周日程表：时间→地图/目标点/动作（站岗/走路/在家）。
2. 地图与目标点引用合法性校验（引用的地图/坐标存在）。
3. 保存写回 `npcs.json`，运行时 NPC 按新日程移动。
4. 冲突检测：同一 NPC 时间重叠给出警告。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：改 NPC 日程→保存→游戏内不同时刻位置符合新日程。

## 风险
- 时间轴粒度与运行时分片不一致 → 编辑器以运行时支持的最小时段为刻度；
- 坐标引用变化 → 保存前校验地图/坐标存在。

## AI 输出（实施后填写）
- 已完成内容、修改文件、验证结果、已知问题、下一步建议。
