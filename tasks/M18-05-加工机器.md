# M18-05 加工机器

## 状态
BACKLOG

## 类型
[玩法]

## 目标
加工机器（磨粉/奶酪/酿酒等）、配方、产线，数据驱动。

## 背景
缺口清单 3.x 提到机器状态（2.3）与配方（4.1）。加工是资源增值的核心出口。

## 输入
- `data/recipes.json` 扩展（机器配方 + 加工时长）、`data/machines.json`
- M16-07 容器（机器料槽）、M16-08 时间（加工时长）

## 不做什么
- 不做多级流水线依赖图（先单机单配方）；
- 不做机器升级；
- 不做产出质量随机。

## 依赖
M16-08、M16-07、M18-00

## 验收标准
1. 机器数据化：类型/加工时长/配方，放料后按游戏时间产出。
2. 加工期间机器状态（进行中/完成）可查询，完成后收取产物。
3. 加工进度跨存档、跨切图保留（入 WorldSnapshot）。
4. 改 machines/recipes 表重载生效。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：放料→时间推进→完成→收取；F1/F2 加工进度保留。

## 风险
- 加工时长与时间流速（clock rate）→ 用游戏分钟计，不依赖真实时间；
- 机器与容器状态重叠 → 料槽内容存容器，加工态存机器。

- 已完成内容、修改文件、验证结果、已知问题、下一步建议。
