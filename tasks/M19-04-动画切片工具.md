# M19-04 动画切片工具

## 状态
BACKLOG

## 类型
[编辑器]

## 目标
Sprite Sheet 切帧工具：切帧、命名帧集（多方向/工具动作）、动画事件，写回动画数据。

## 背景
缺口清单 4.2 的四方向帧/工具动作帧/动画事件需要生产工具。建立在 M18-09 动画工作流约定之上。

## 输入
- M18-09 sprite sheet 约定、`animation` 组件格式
- 编辑器资源浏览器

## 不做什么
- 不做骨骼动画编辑；
- 不做 Blend Tree；
- 不做运行时动画预览以外的重放控制。

## 依赖
M18-09

## 验收标准
1. 从一张 sprite sheet 切帧：网格切分、命名帧集（`walk_down`/`tool_use_right` 等）。
2. 编辑帧序列与帧事件（帧号→回调标记），输出与 `animation` 组件格式兼容的数据。
3. 编辑器内可预览播放，运行时可回放。
4. 保存的动画数据可被玩家/NPC/作物/动物复用。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：切一张角色表→配 walk/tool 动画→游戏内播放正确。

## 风险
- 帧命名约定与运行时解析脱节 → 输出格式以 `animation` 组件为准；
- 切帧精度 → 支持偏移/间距参数。
