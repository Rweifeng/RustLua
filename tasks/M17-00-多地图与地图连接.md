# M17-00 多地图与地图连接

## 状态
BACKLOG

## 类型
[引擎+玩法]

## 目标
扩展 `map` Lua API：多地图注册与加载/卸载、出入口/传送点、屏幕过渡、地图音乐切换；落成 `MapManager` 概念。

## 背景
缺口清单 3.2 要求地图注册、加载/卸载、出入口、传送点、地图持久化、室内外切换、屏幕过渡、地图音乐。`map` API 已有 `go/enter/current/spawn/set_spawn/state`，缺统一编排。本任务是 M17 生活系统（NPC/商店/天气/厨房）的地基。

## 输入
- `map` API（18-lua-api.md）
- `game_farm/scenes/` 现有场景（farm_day_flow 等）
- M16-08 日历（跨天保持地图状态）

## 不做什么
- 不做地图持久化（M17-01，本任务只做切换编排）；
- 不做 NPC（M17-02）；
- 不做寻路（M18）。

## 依赖
M16-08

## 验收标准
1. `map` API 扩展：地图注册表（名称→场景/出生点/音乐）、`load`/`unload`、`transition`（带屏幕过渡效果）、`music` 切换。
2. 出入口/传送点数据化（`data/maps.json`），玩家碰 TriggerZone（M16-02）即可切图。
3. 屏幕过渡（淡入淡出或遮罩）可复现，切换后出生点正确。
4. 地图音乐随切换改变，回到原图恢复原音乐。
5. 跨地图玩家状态（背包/工具/体力）保持不丢。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：农场→室内→小镇往返切换，出生点/音乐/背包正确。

## 风险
- 场景加载耗时导致卡顿 → 小地图同步加载 + 过渡动画遮挡；
- 地图状态（M16-09）与切换耦合 → 切换前后各触发一次快照钩子。
