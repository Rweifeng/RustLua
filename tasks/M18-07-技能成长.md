# M18-07 技能成长

## 状态
BACKLOG

## 类型
[玩法]

## 目标
经验/等级/技能效果，数据驱动。

## 背景
缺口清单 3.x 提到技能成长（阶段 3）。技能是长线目标与数值出口。

## 输入
- `data/skills.json`（技能/经验曲线/等级效果）
- M18-00 体力/工具（消耗关联）、各玩法动作（采集/钓鱼/种地等加经验）

## 不做什么
- 不做技能解锁专属内容（先数值效果）；
- 不做技能 UI 面板详细页（M18-08 给列表）；
- 不做洗点。

## 依赖
M18-00

## 验收标准
1. 技能数据化：若干技能（耕种/采集/钓鱼/采矿等）、经验曲线、等级效果。
2. 各玩法动作给经验（钓鱼/采集/收获/采矿），实时累计。
3. 等级效果生效（如锄地消耗降低/钓鱼判定加成）。
4. 技能进度持久化并读档保留。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：反复动作升级→效果变化→读档等级保留；改 skills.json 生效。

## 风险
- 经验来源分散 → 通过事件总线统一定点加经验；
- 效果堆叠 → 等级效果按「乘数/偏移」两个字段实现。

## AI 输出（实施后填写）
- 已完成内容、修改文件、验证结果、已知问题、下一步建议。
