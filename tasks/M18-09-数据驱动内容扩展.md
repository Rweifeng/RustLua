# M18-09 数据驱动内容扩展

## 状态
BACKLOG

## 类型
[数据+引擎]

## 目标
本地化表、掉落表、配方表、schema 完善；sprite sheet 多方向/工具动作帧/动画事件工作流。

## 背景
缺口清单 4.1（大量内容数据 + Schema 校验 + 本地化表 + 掉落表 + 配方表）与 4.2（sprite sheet 多方向帧、工具动作帧、动画事件）。所有系统（钓鱼/采集/采矿/机器/任务）都依赖掉落与配方表，故统一在此落地。

## 输入
- M16-11 数据管线、`data` API
- `animation` 模块、现有素材
- 各玩法的掉落/配方需求

## 不做什么
- 不做内容编辑器（M19-01）；
- 不做本地化语言切换 UI（表先建）；
- 不做 Blend Tree（非目标）。

## 依赖
M16-11

## 验收标准
1. 掉落表/配方表标准结构落地，所有玩法（钓鱼/采集/采矿/机器/作物掉落）统一引用。
2. 本地化表：`data/locales/*.json` 键值，UI 文案走 `localize` API，缺键回退默认语言。
3. sprite sheet 工作流：多方向帧、工具动作帧、动画事件（帧回调）约定，示范接入玩家与一种作物/动物。
4. schema 校验覆盖新增表；改表重载生效且非法数据定位报错。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
Rust 单测：掉落表权重、本地化回退、动画事件回调；实机：改掉落/文案生效。

## 风险
- 掉落表结构各玩法自定 → 本任务定统一 schema，各玩法遵守；
- 动画事件与热重载 → 事件表随脚本重载重建。
