# M19-06 存档查看器

## 状态
BACKLOG

## 类型
[编辑器]

## 目标
查看/修改存档 slot：可视化 WorldSnapshot 内容，手动改值并校验回写。

## 背景
排错需要直接查看存档（M16-09 格式）。建立在存档格式与校验之上。

## 输入
- M16-09 存档格式、`save` 模块
- 编辑器面板基础

## 不做什么
- 不做多槽位管理（新建/复制/删除槽位）之外的复杂操作；
- 不做存档差异对比；
- 不做在线热改（只对磁盘存档）。

## 依赖
M16-09

## 验收标准
1. 打开存档 slot，树状展示：日历/玩家/背包/农田/作物/商店等快照字段。
2. 可编辑数值型字段，保存前用 schema 校验，非法值拒绝并提示字段。
3. 修改后的存档能被游戏正常读取（往返一致）。
4. 存档版本与迁移信息可见（用于排查旧档）。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：打开存档改金钱→游戏中读档金额变化且无校验错误。

## 风险
- 改值破坏关联（如背包物品 id 不存在）→ 保存前做引用校验；
- 与运行时存档版本漂移 → 严格按 schema 字段集。

## AI 输出（实施后填写）
- 已完成内容、修改文件、验证结果、已知问题、下一步建议。
