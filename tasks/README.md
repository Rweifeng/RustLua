# 任务管理目录

AI 驱动开发模式的任务承载目录，与[项目章程](../docs/00-project-charter.md#9-ai-开发规则)§9 一致。

- `TASK-TEMPLATE.md`：任务模板，每个 AI 任务据此创建。
- `done/`：已验收任务的归档，按里程碑 `M0-*` … `M15-*` 命名归档。
- 规划中的任务（BACKLOG，M16–M20）放在本目录，按 `M<里程碑>-<序号>-<简述>.md` 命名，待认领后移到对应里程碑并走[任务生命周期](../docs/00-project-charter.md#91-任务生命周期)。

## 命名约定

- 未归档：`M<里程碑>-<序号>-<简述>.md`（例如 `M12-03-资源依赖图.md`）。
- 已归档：移入 `done/`，保留原名。
