# 任务管理目录

AI 驱动开发模式的任务承载目录，与[项目章程](../docs/00-project-charter.md#9-ai-开发规则)§9 一致。

- `TASK-TEMPLATE.md`：任务模板，每个 AI 任务据此创建。
- `done/`：已验收任务的归档，按里程碑 `M1-*` … `M22-*` 命名归档（当前 152 份，**M0–M20 与 M22 专题已全部归档**）。
- `plan/`：待做任务（BACKLOG）的计划目录，按 `M<里程碑>-<序号>-<简述>.md` 命名；AI 开始实现前必须先从此目录认领任务，并按[任务生命周期](../docs/00-project-charter.md#91-任务生命周期)推进。

  `M34-00-存档版本门与长跑基线`（前置止血，含 `jhyt_m17_shop` 的待裁定）、
  `M34-01-关系与声望档位接线`、`M34-02-节气与节日事件`、`M34-03-中毒与瞬时状态机制`、
  `M34-04-招式扩充与防御属性结算`、`M34-05-茶棚茶饮与社交收益`。

  commit 与门读数；本批唯一尚未做的项是**三宿主目验**（编辑器 Play / 桌面 / Web），
  headless 门绿不等于按键真的接上。

  引擎下沉（`status` 进 `rustlua-gameplay`）的触发条件写在 `M34-03` 的"是否动引擎"一节。

## 命名约定

- 未归档：`M<里程碑>-<序号>-<简述>.md`（例如 `M12-03-资源依赖图.md`）。
- 已归档：移入 `done/`，保留原名。
