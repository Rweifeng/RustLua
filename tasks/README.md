# 任务管理目录

AI 驱动开发模式的任务承载目录，与[项目章程](../docs/00-project-charter.md#9-ai-开发规则)§9 一致。

- `TASK-TEMPLATE.md`：任务模板，每个 AI 任务据此创建。
- `done/`：已验收任务的归档，按里程碑 `M1-*` … `M22-*` 命名归档（当前 151 份，**M0–M20 与 M22 专题已全部归档**）。
- `plan/`：待做任务（BACKLOG）的计划目录，按 `M<里程碑>-<序号>-<简述>.md` 命名；AI 开始实现前必须先从此目录认领任务，并按[任务生命周期](../docs/00-project-charter.md#91-任务生命周期)推进。
- `plan/` 现有 [`WP12-host拆分`](plan/WP12-host拆分.md) 一份待认领任务：
  `host/runtime_scene.rs`（10,458 行）与 `host/renderer.rs`（6,089 行）两个上帝文件拆成子目录，
  行为与对外符号零变化，排在 PBR/HDR 之前（`docs/62` §6 的两条 P1 架构债）。
  其余历史工作包（`WP4`/`WP6`/`WP9`/`WP10`/`WP11` 与执行台账）均已归档 `done/`。
  **W6 是「已裁定不做」的项**，触发条件与决策留在 `done/M22-输入层收口.md` §9（不在 `plan/` 另立文件）。
- CHANGELOG 版本映射：M16 → v0.12，M17 → v0.13，M18 → v0.14，M19/M20 → v0.15 起（收口延续到 v0.21）。

## 命名约定

- 未归档：`M<里程碑>-<序号>-<简述>.md`（例如 `M12-03-资源依赖图.md`）。
- 已归档：移入 `done/`，保留原名。
