# M16-07 背包、快捷栏与容器完善

## 状态
DONE

## 类型
[引擎+玩法]

## 目标
在既有 `inv/container/ui.grid` 基础上补齐：拖拽完成态、拆分、物品使用、图标 tooltip、Equipment 数据模型骨架。

## 背景
引擎已具备 `item/inv/container` API 与 `ui.grid/drag_*`（18-lua-api.md），但 `main.lua` 只展示了静态热栏。缺口清单 2.5 要求拾取/丢弃/拆分/使用、容器、拖拽、图标名称描述价格。

## 输入
- `inv` / `container` / `item` API
- `ui.grid / grid_cell / grid_hit / tooltip / drag_begin / drag_end`（`on_drag` 全局回调）
- 现有热栏 UI（main.lua）

## 不做什么
- 不做商店交易（M16-10）；
- 不做装备效果（Equipment 只建骨架，效果后续）；
- 不做手柄/键盘焦点导航（M18-08）。

## 依赖
M16-00

## 验收标准
1. 背包↔容器拖拽移动、拆分堆叠可完成（`on_drag` 回调驱动，状态一致）。
2. 物品「使用」：定义 `use` 行为（如食物回体力），数字键/点击触发。
3. Tooltip 显示名称/描述/价格。
4. Equipment 骨架：`inv` 扩展装备槽类型与查询接口，暂不接效果。
5. 容器打开/关闭生命周期正确，关闭后拖拽状态清空。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：拖拽移动/拆分、tooltip 出现、吃食物回体力、开关箱子无残留拖拽。

## 风险
- 拖拽状态与热重载冲突 → 拖拽中禁用热重载或状态放在 `state.lua` 统一管理；
- 拆分数量 UI 未定 → 先弹数字输入占位，M18-08 再统一。
