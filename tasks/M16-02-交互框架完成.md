# M16-02 交互框架完成

## 状态
DONE

## 类型
[引擎+玩法]

## 目标
落地统一交互框架：Interactable 约定、TriggerZone、交互提示。

## 背景
`interact.query/prompt` API 已存在，但无统一的 Interactable 约定与触发器。缺口清单 2.1 要求「与 NPC、箱子、门、作物、商店等对象交互」与「进屋/进镇/下矿触发器」。

## 输入
- `engine/crates/engine/src/core/script.rs`（`interact`/`tag` 模块）
- `docs/18-lua-api.md`
- M16-01 的玩家控制

## 不做什么
- 不做对话系统（M17-03）；
- 不做工具使用（M16-03）；
- 不做实际切图（TriggerZone 只产出回调占位）。

## 依赖
M16-01

## 验收标准
1. 交互对象统一挂 `tag kind=interactable`，`interact.query` 返回按距离 + priority 排序的候选。
2. TriggerZone：区域实体，玩家进入/离开触发 Lua 全局回调 `on_zone_enter/on_zone_exit`。
3. 交互提示：靠近显示 `interact.prompt`，离开 `clear_prompt`。
4. 演示：地图上一个「门」TriggerZone，靠近显示提示、进入触发切图占位回调。

## 风险
- 触发器区域判定精度（矩形 vs 距离）→ 先矩形轴对齐，后续按需扩展；
- 回调与热重载的绑定 → 沿用全局函数约定（同 `on_drag`）。
