# M17-07 天气系统

## 状态
BACKLOG

## 类型
[引擎+玩法]

## 目标
新增 `weather` Lua API（晴/雨/雪）、每日天气、降雨免浇水、天气对玩法的影响钩子。

## 背景
缺口清单 2.2 要求天气；3.x 农场玩法常用「降雨自动浇水」。天气影响作物（M16-06）、NPC（M17-02）、商店营业（M17-05）等多个系统，故做成引擎级 API + 玩法消费。

## 输入
- M16-08 `calendar/day`（每日天气生成挂 `on_day_start`）
- M16-06 作物浇水逻辑

## 不做什么
- 不做天气特效渲染（雨滴/雪粒子视觉留作占位或后续）；
- 不做季节天气概率配置 UI；
- 不做风暴等极端事件。

## 依赖
M16-08

## 验收标准
1. `weather` API：`now()` 返回当前天气、`set/seed`（每日生成规则）、`on_day_start` 自动出当日天气。
2. 降雨天气下当日免浇水：作物按「已浇水」结算（M16-06 消费端行为）。
3. 天气进存档（读档后天气与日历一致）。
4. 天气可被玩法查询用于其他效果（如雨天 NPC 收摊）——提供钩子即可。

cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release

## 风险
- 天气确定性（同一档同一天天气一致）→ 用种子+日期推导，不依赖随机全局态；
- 视觉占位被误认完成 → 验收聚焦行为，视觉在 M18-09 动画工作流。
