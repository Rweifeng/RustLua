# M16-01 玩家控制器

## 状态
DONE

## 类型
[引擎+玩法]

## 目标
八方向移动 + Tilemap 碰撞 + 朝向 + 行走/待机动画，落地为 `scripts/player.lua`。

## 背景
`main.lua` 移动无碰撞、无动画、无朝向。工具系统（M16-03）依赖「朝向」概念，必须先行落地。

## 输入
- `engine/crates/engine/src/core/tilemap.rs`（`set_solid` 碰撞层）
- `transform` / `input` / `animation` Lua API（18-lua-api.md）
- `assets/curated/farm/farmer_down_sample_hnnnnnnn.png` 等现有素材

## 不做什么
- 不做工具使用与交互（M16-02/M16-03）；
- 不做 NPC 移动（M17-02）；
- 不做动态障碍开关。

## 依赖
M16-00

## 验收标准
1. WASD 八方向移动，速度与现状一致（150 单位/秒）。
2. 玩家实体被 Tilemap solid 格阻挡，含贴墙斜向滑行。
3. 四个朝向可切换；移动播放行走动画、静止播放待机动画。
4. 朝向可被 Lua 查询/设置（供 M16-03 工具方向使用）。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：走到墙边被挡；按 A/D 朝向翻转；行走/待机动画切换。

## 风险
- 斜向滑行手感与预期不符 → 验收项 2 明确贴墙滑行；
- 动画帧来源（现有素材为单帧 down）→ 阶段内可用纯色占位帧，动画完整工作流在 M18-09。
