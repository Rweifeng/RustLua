# M19-05 运行时调试器

## 状态
BACKLOG

## 类型
[编辑器]

## 目标
运行时调试面板：Lua 控制台、状态查看（背包/农田/时钟/体力/好感度），运行中检查与修改。

## 背景
玩法系统（M16~M18）状态复杂，需运行时观测。建立在 M16-09 快照与 Lua 桥之上。

## 输入
- M16-09 WorldSnapshot、Lua 桥（`script.rs`）
- 编辑器面板基础

## 不做什么
- 不做断点/步进（Lua 调试协议先行保留）；
- 不做内存/性能分析器（M20-02）；
- 不做存档修改写回（M19-06）。

## 依赖
M16-09

## 验收标准
1. 调试面板在 Play 时可见：Lua 控制台（执行表达式、打印日志）。
2. 状态树查看：背包、农田格、作物、时钟/日历、体力、好感度、任务进度。
3. 只读查看不破坏运行；提供受控的「设值」入口（如改金钱）用于排查。
4. 面板随 Play/Stop 生命周期正确创建/销毁。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：Play 中执行 Lua 表达式、查看/修改状态、Stop 后面板清理。

## 风险
- 运行时只读与持有冲突 → 状态快照线程/帧边界对齐；
- 设值破坏一致性 → 只允许白名单字段设值。
