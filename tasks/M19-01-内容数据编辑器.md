# M19-01 内容数据编辑器

## 状态
BACKLOG

## 类型
[编辑器]

## 目标
物品/作物/鱼/矿物等 JSON 数据可视化编辑：表格/表单编辑、校验、写入 `data/`。

## 背景
缺口清单 4.1 的内容数据量大，手改 JSON 易错。建立在 M16-11 schema 之上。

## 输入
- M16-11 schema、`data/` 目录
- 编辑器 Inspector/表单基础

## 不做什么
- 不做对话/日程专用编辑器（M19-02/M19-03）；
- 不做本地化键值编辑器（可并入通用表）；
- 不做运行时热编辑（只写数据文件）。

## 依赖
M16-11

## 验收标准
1. 打开物品/作物/鱼/矿物表，表格列出字段，选中行表单编辑，校验规则即时反馈。
2. 保存写回 `data/<domain>.json`，格式与 schema 一致（round-trip 校验）。
3. 新增/删除条目走同一 schema，非法值拦截并定位字段。
4. 保存后游戏重载即可见（无需重启）。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：改一个作物价格→保存→游戏内重载生效；构造非法值被拦截。

## 风险
- round-trip 破坏注释/顺序 → 只序列化 schema 字段，接受重排；
- 大表性能 → 虚拟滚动/分页。

## AI 输出（实施后填写）
- 已完成内容、修改文件、验证结果、已知问题、下一步建议。
