# M20-02 性能与稳定性

## 状态
BACKLOG

## 类型
[工程]

## 目标
性能基线、长会话与重复 Play/Stop 资源生命周期、SDF glyph 扩容；修复农场功能引入的性能/稳定性回归。

## 背景
复盘结论 §8 列出已知编辑器风险（半分辨率缓存、readback 缓存失效、输入边沿、Play 失败状态、SDF 泄漏与 glyph 上限）。农场玩法（动态 UI、Tilemap 运行时写、多实体）会放大这些风险。

## 输入
- 复盘结论 §8 风险清单
- `M15-00 性能基线` 方法
- 农场实机数据

## 不做什么
- 不做大规模渲染重构；
- 不做 ECS 多线程优化（非目标）；
- 不追求超出「小体量农场」目标的性能。

## 依赖
所有里程碑

## 验收标准
1. 重复 Play/Stop 30 次 + 长会话（30 分钟）无内存持续增长/资源泄漏（对比基线）。
2. SDF glyph 超过 256 不再静默丢字：扩容或明确溢出错误（复盘结论 §9.5）。
3. 农场实机在目标帧率内运行（记录基线对比），动态 UI 与 Tilemap 写不造成明显掉帧。
4. 复盘结论 §8 的编辑器回归风险项复核并修复或记录 REWORK。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
性能：M15 基线方法 + 长会话/重复 Play 记录。

## 风险
- 性能问题定位困难 → 以基线对比定位，避免无数据优化；
- SDF 扩容影响内存 → 权衡后选择扩容或溢出报错。
