# M17-04 好感度

## 状态
BACKLOG

## 类型
[玩法]

## 目标
送礼、好感度数值与阶段、好感度触发的对话/事件。

## 背景
缺口清单 3.1 要求送礼、好感度与特殊事件。依赖对话系统。

## 输入
- `data/npcs.json`（好感度表、礼物喜好）
- `data/dialogue.json`（好感度条件分支）
- `inv` / `item`（送礼物品）
- M16-09 存档（好感度持久化）

## 不做什么
- 不做结婚/恋爱线；
- 不做好感度 UI 详情面板（M18-08 任务日志一类）；
- 不做 NPC 日程编辑器。

## 依赖
M17-03

## 验收标准
1. 送礼：把物品给 NPC，按喜好表加减好感度，喜恶不同反馈。
2. 好感度按 NPC 分档持久化（存档往返一致）。
3. 好感度达到阈值解锁新对话分支/事件。
4. 每日送礼上限（防止刷）等基础规则数据化。
