# M18-02 采集

## 状态
BACKLOG

## 类型
[玩法]

## 目标
采集点、刷新、季节生成、掉落表，数据驱动。

## 背景
缺口清单 3.4 要求采集点刷新、季节性生成。采集是农场循环的资源补充。

## 输入
- `data/forage.json`（物品/季节/生成位置）、`data/loot_tables.json`
- M16-08 日历、M18-00 体力/工具
- M16-04 地图状态（采集点被采后持久化）

## 不做什么
- 不做采集动画；
- 不做稀有度音效反馈；
- 不做采集经验（M18-07）。

## 依赖
M16-08、M18-00

## 验收标准
1. 采集点按地图与季节生成，采后消失并被地图持久化（M17-01 复用）。
2. 刷新规则数据化：每日/数日刷新，位置与物品来自数据表。
3. 采集消耗体力并可能产出多个物品（掉落表）。
4. 改 forage/loot 表重载生效。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：采集→消失→次日刷新→掉落符合掉落表。

## 风险
- 刷新与存档冲突 → 刷新时机挂 `on_day_start`；
- 采集点与地图修改状态重叠 → 统一走 PersistentMapState。
