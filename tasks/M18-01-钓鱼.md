# M18-01 钓鱼

## 状态
BACKLOG

## 类型
[玩法]

## 目标
钓鱼点、出现条件、钓鱼小游戏（UI）、掉落表，数据驱动。

## 背景
缺口清单 3.4 要求钓鱼点、出现条件、钓鱼小游戏、掉落表。

## 输入
- `data/fish.json`（鱼种/出现时段季节/难度）、`data/fishing_spots.json`
- `ui` 动态面板（小游戏）、M16-08 时间/季节、M18-08 完整 UI
- M16-02 交互（钓鱼点触发）

## 不做什么
- 不做蓄力抛竿力度手感调优（先固定动作）；
- 不做钓鱼等级/图鉴（M18-07/任务）；
- 不做鱼的动画表现。

## 依赖
M17-00、M18-08、M16-08

## 验收标准
1. 钓鱼点数据化：位置/出现条件（时段/季节/天气），满足时显示交互提示。
2. 下竿后进入小游戏：按键时机判定（`ui` 进度条/圈），按难度判定成败。
3. 成功按掉落表出鱼进背包，失败不扣鱼、提示可重试。
4. 不同鱼按时间/季节出现，数据驱动改表生效。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：在条件满足的钓鱼点钓到对应鱼，改 fish.json 出现表生效。

## 风险
- 小游戏手感 → 判定窗口参数化，集中调参；
- 与时间推进冲突 → 下竿时暂停时间，起竿恢复。
