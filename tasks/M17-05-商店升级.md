# M17-05 商店升级

## 状态
BACKLOG

## 类型
[引擎+玩法]

## 目标
在 M16-10 基础上补：营业时间、库存与补货、季节商品、交易确认面板。

## 背景
缺口清单 3.3 要求营业时间、商品目录、买卖价格、季节商品、库存、玩家资金、每日结算、交易确认。M16-10 已做买卖原语，本任务补齐营业与 UI。

## 输入
- M16-10 `shop` API、`data/shop.json`
- `calendar`（M16-08）营业时间判定、季节
- `ui` 面板（交易确认）

## 不做什么
- 不做出货箱物流；
- 不做 NPC 营业员实体（用商店位即可）；
- 不做多货币/讨价还价。

## 依赖
M16-10、M17-09

## 验收标准
1. 营业时间：商店仅在定义时段开张，关门时交互提示「未营业」。
2. 库存与季节商品：商品目录按季节/日期变化，数量有上限可补货。
3. 交易确认面板：买卖数量可调、价格预览、确认后结算。
4. 买卖金额入存档（资金与商店库存一致往返）。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
Rust 单测：营业时段、季节商品、库存上限；实机：营业/非营业 + 交易确认全流程。

## 风险
- 库存与时间耦合 → 补货逻辑挂在 `on_day_start`；
- 交易面板与背包拖拽（M16-07）冲突 → 面板打开时禁拖拽。
