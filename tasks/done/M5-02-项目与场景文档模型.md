# M5-02：项目与场景文档模型

## 状态

- 状态：DONE
- 依赖：M5-01
- 完成日期：2026-08-21

## 目标

建立编辑器的项目文档和场景文档状态模型，复用 `engine_core::Scene`，支持新建、打开、保存、另存为和 dirty 状态管理。

## 实施范围

- `ProjectDocument`：关联已打开项目和当前场景；
- `SceneDocument`：场景数据、路径和 dirty 状态；
- 保存前校验场景，临时文件解析验证后再替换目标文件；
- 保存失败时保留原文件并保持 dirty；
- 临时目录自动化测试覆盖 roundtrip、另存为、失败保护和重复保存稳定性；
- 不修改 M4 场景文本格式。

## 验收方案

```powershell
cargo fmt --manifest-path engine/Cargo.toml --all -- --check
cargo clippy --manifest-path engine/Cargo.toml --workspace --all-targets --all-features -- -D warnings
cargo test --manifest-path engine/Cargo.toml --workspace --all-features
cargo build --manifest-path engine/Cargo.toml --workspace
cargo build --manifest-path engine/Cargo.toml --workspace --release
git diff --check
```

验收标准：

- 新建场景初始 `dirty=true` 且无路径；
- 打开场景后路径正确且 `dirty=false`；
- 修改后 dirty，成功保存后 clean；
- 保存/加载内容一致，另存为更新当前路径；
- 非法场景保存失败，原文件字节内容不变，dirty 不被清除；
- 重复保存生成相同场景内容；
- 所有质量门通过。
