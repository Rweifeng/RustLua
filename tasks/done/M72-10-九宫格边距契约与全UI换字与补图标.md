## 设计要点

1. **边距契约**：每张 `_9s` 图登记 margin（像素）与**最小可用尺寸**，三处现存真相（清单 27 / `skin.lua` 21 /
   prefab 12）收成**一处真源 + 两处消费**，并由门保证不漂。旧说法"而不是脚本里各写一个数"要说清今天的样子：
   硬写的那 21 条已经在 `skin.lua` 集中了（不是散在各脚本），**缺的是"只此一处"这件事本身与它的门**。
   母图 96×96 的边框实际占多少像素要先量出来——清单今天声明的是 `16,16,16,16`，那是**登记值**，
   不是从像素上量出来的（量法：逐列数第一圈非底色宽度）。
2. **量化失真判据**：面板边长 / 母图边长 的比例超阈值就报错，而不是靠肉眼说"看着还行"。
   先要有消费侧的修法：`inventory.prefab` 那 11 行、`hud.prefab` 那 3 行现在根本没走九宫格，
   比例判据对它们无意义（**没带 `nine_slice=` 的行不参与拉伸，也就没有"边距"可校**）。
3. 全 UI 换字 = M72-03 的字体在项目设置里生效 + 逐屏目验；
   `font_size` 吸附到整像素后，**原来靠 float 微调对齐的排版会全部错位**（`text_fit.lua` 是活的），
   这条要在验收里显式测。
4. 图标按 **`51` §图标段**（32×32、硬像素、左上光源、1px 外描边、透明 PNG）+ **`57` §5**
   （硬像素量化：alpha 二值化 >127→255 + 每通道 6bit）两条契约。旧说法把这两条都算在 `51` 头上，
   `51` 里没有量化那一句。**6bit 那条的口径必须写死取"每通道不同取值 ≤64 档"**（另一读法"取值全为 4 的倍数"
   在盘上是 0/92，会被误读成违约；见 `docs/58` §6.1 的甲/乙段与工具自检第 ④ 条）。
   本包**没有**"大攻击图标 64×64"这一档：旧说法里那句是从 `51` §2.4「特效规范：基础特效帧 32×32、
   大型攻击特效 64×64」串过来的，图标侧从头到尾只有 32×32（`51` §2.3 末尾的图标段 + `57` §5 两条都是）。
