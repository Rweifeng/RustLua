## 技术方案

1. **资源目录重组**（按类型）：`game/assets/textures/`（PNG）、`game/assets/audio/`（OGG）；场景/SpriteAsset/Animation/Tilemap 路径与 `set_audio_asset_dir` 相应更新。
2. **Sprite 尺寸可配**：`Sprite` 组件支持 `assets/x.png;size=32`（或 `size=32x32`），`parse_sprite_ref` 解析；编辑器仍写无 size 形式（默认 128）。
3. **AudioSystem 支持 OGG**：`sound_bytes` 依次尝试 `.wav`/`.ogg`（rodio 从字节自动识别格式）。
4. **物理体移除**：`PhysicsWorld::remove_body`（Rapier `RigidBodySet::remove` 连带碰撞体），`entity.destroy` 时调用，避免销毁敌人后幻影碰撞。
5. **玩法**（main.lua）：史莱姆按名 `find_all("Slime")` 收集并追击（速度朝玩家）、接触伤害（20/次，`physics.events`）；SPACE 攻击（半径 48 内击杀史莱姆 + 音效/粒子）；金币传感器拾取（+pickup 音效/粒子）；全收集 VICTORY、hp=0 DEFEATED；保留 F1存/F2读/F4切场景。

## 风险与应对

| 风险 | 应对 |
|---|---|
| 资源许可风险 | 仅用 Kenney CC0（公有领域，免署名可商用），逐项记录于 THIRD_PARTY.md |
| 图块索引误判 | 程序化颜色分析（平均色/颜色数）区分墙/地板；单测 round-trip 兜底 |
| 旧 WAV 抢先于 OGG | 清理被取代的 attack.wav/hit.wav，AudioSystem 保留 .wav→.ogg 回退 |
| 敌人销毁后幻影碰撞 | `PhysicsWorld::remove_body` 随 `entity.destroy` 移除刚体与碰撞体 |
| 精灵尺寸与纹理不符 | `Sprite;size=N` 显式配置；默认仍 128 兼容编辑器 |
