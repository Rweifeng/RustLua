# M8-00 M8 基线与技术决策

## 状态

ACCEPTED

## 目标

确认 `v0.7` 发布基线可复现，补充 M8 3D 坐标/资源格式决策，并准备一个可自由使用、可再生的最小 GLB 测试资产。

## 背景

M6/M7 已完成，当前 HEAD 精确位于 `v0.7`。M8 尚无 3D 数学、Mesh、Camera3D 或 glTF 导入实现，因此必须先固定边界和测试输入，避免后续任务同时改变坐标系、资源格式和渲染假设。

## 不做什么

- 不实现 glTF 解析器、Mesh GPU 上传、深度测试或 3D 渲染；
- 不修改现有 2D 场景格式和游戏资产；
- 不引入第三方下载资产；
- 不创建 `v0.8` 标签。

## 技术方案

- 采用 glTF 2.0，首版文件入口为 `.gltf` 和 `.glb`，详细边界见 ADR-0006；
- 采用右手系、+Y 向上、+Z 指向观察者、米制单位、`Depth32Float` 和 `LessEqual`，详细约定见 ADR-0007；
- 使用 `scripts/gen-m8-test-gltf.ps1` 生成自制最小三角形 GLB，生成过程只使用 .NET 标准库；
- 将生成脚本、GLB 文件和许可证说明纳入版本控制，保证后续导入测试可以重建输入。
