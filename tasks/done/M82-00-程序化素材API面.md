## 目标

把"零外部素材"做成引擎一等能力：几何用参数生成、贴图用程序化/文字栅格化、音效用合成，
全部可由 Lua **规格串/规格表**指定（于是 AI 生成的是数与规格，不是二进制素材）。服务两个真实约束：
① 微信主包 ≤ 4 MB、总量 ≤ 20 MB（`docs/52`）——wasm 核心是固定成本，素材侧趋零才是省体积的关键；
② AI 生产闭环（`docs/71` M75 / `docs/75` M76）——程序化素材让"提示词 → 可玩垂直切片"不必产二进制资产。

动机来源：掘金《4 个 3D 游戏，总体积 3.82MB：拆解 Claude 的 one-shot 工程链路》
（https://juejin.cn/post/7706833656825004058）。该文内核是**生产闭环 + 程序化素材 + 验证纪律**，
不是新渲染技术；本包只迁移"程序化素材"这一层，渲染仍走现有 wgpu/WGSL 管线。

## 范围分档（先写清买不到什么）

- **本包交付 API 面 + 门**，不是生成式美术管线。`docs/71` §1 明确把"生成式美术资产管线"列为非目标、
  `docs/75` M1–M6 未开工。程序化（参数化）≠ AI 出图：文章正是参数化路线，与本包对齐。
- **合成音效只交付合成原语**（振荡器/噪声/包络/滤波），不交付"调得像枪声/引擎"的预设——
  文章也承认"像不像全靠参数调"，那部分是人耳定标，不进机器门。
- **不追单文件极简**：`game_web.wasm` 约 9 MB（gzip 2.86 MB，`docs/71` §3.1）比文章整个 1.42 MB FPS 还大，
  裸体积赢不了也不该赢；本包省的是**素材侧**增量。
- **RTT 截屏式贴图（B1）缓做**，另立包；本包先做参数化贴图（B2）。

## 盘点结论（2026-11-13 实测，事实源 `lua_api_surface.json` + 各模块 doc 页）

| 文章技术 | RustLua 现状 | 复用 / 缺口 | 证据 |
|---|---|---|---|
| 程序化几何 | 哨兵 `__terrain__`/`__water__`/`__cells__`/`__ground_plane__`，串就是全部输入 | **复用哨兵模式**；缺通用 primitive（box/sphere/cylinder/cone/torus） | `engine/crates/rustlua-render/src/cellmesh.rs`、`terrain.rs`、`water.rs`；`docs/24` §MeshRenderer |
| InstancedMesh | `mesh.set_batch` + 程序化 motion + LOD + 打包实例，基准到 1 万实例 | **直接复用**，primitive 挂上即得实例化 | `engine/crates/engine/src/lua_api/doc/mesh.md`（14 函数）；`metrics/baselines/wp0-3d-stress.json` |
| 程序化贴图 | terrain 细节图集由 seed 生成、零素材文件 | 缺**通用** Lua 贴图生成/文字栅格化；GPU 离屏管子已在但只供门 harness | `engine/crates/rustlua-render/src/terrain_detail.rs`；`engine/crates/rustlua-gpu/src/offscreen.rs`（`OffscreenTarget`/`OffscreenDevice`） |
| Canvas→纹理 | 无 Lua 面 RTT；2D 绘制有 sprite/quad/render/text | 缺 `texture` 模块与动态纹理句柄消费 | `quad.md`(2)、`sprite.md`、`render.md`；`engine/crates/rustlua-render/src/text.rs` |
| 合成音效 | `audio` 是文件回放(mp3/wav/ogg)+空间+无障碍音色；`audio.tone()` 只读 mono/bass/treble | **缺合成**（振荡器/噪声/包络/滤波）；rodio 出口已在 | `engine/crates/engine/src/lua_api/doc/audio.md`（20 函数）；`engine/crates/rustlua-audio/src/{tone.rs,lua.rs,sink.rs}` |

结论：**几何最省**（哨兵 + 实例化全复用，A 批可不增 Lua 函数）；**贴图与音效是真缺口**，需新模块。

## 方案（待用户批准，见 §决策点）

### A 批 · 参数化 primitive 哨兵（3D，复用 mesh 模式）

- 新哨兵 `__primitive__?kind=<box|sphere|cylinder|cone|torus|plane>&...`，由 `mesh.set`/`mesh.set_batch` 消费。
  参数：box(`w,h,d`)、sphere(`r,seg`)、cylinder(`r,h,seg`)、cone(`r,h,seg`)、torus(`R,r,seg,ring_seg`)、plane(`w,h`)。
- 新文件 `engine/crates/rustlua-render/src/primitives.rs`（照 `cellmesh.rs` 形状）：解析规格 → `MeshAsset`
  （position/normal/texcoord + indices），**seed 无关、确定性**；接现有 PBR 管线。
- 扩 `MeshRenderer` 文法校验接受 `__primitive__`；非法 kind/参数报错（照 `cellmesh.rs` 逐字段校验）。
- **不增 Lua 函数**：哨兵是 mesh 路径值，`mesh` 表函数数不变；实例化经 `set_batch` 免费得到。
- 维度：`mesh` 表在 M81 属 3D 包 ⇒ primitive 天然 3D-only，2D 构建里 `mesh.set` 不存在即不可达，无需额外 cfg。

### B2 批 · 程序化贴图（新 `texture` 模块，维度无关基底）

- `texture.generate(spec) -> id`：spec 表 `kind=checker|noise|gradient|stripes` + `size/colors/seed/scale`；
  CPU 侧确定性生成像素 → 上传 GPU 纹理 → 返回句柄。
- `texture.from_text(text, opts) -> id`：复用 `rustlua-render` 文字栅格化（ab_glyph/swash）把文字/编号画进纹理
  （文章的集装箱编号/限重标签）。字体复用工程已有，许可见 `docs/THIRD_PARTY.md`。
- `texture.free(id)`：显式释放；句柄生命周期要防泄漏（文章浸泡测试教训：纹理数恒定）。
- 消费：`sprite.set_texture(id, tex_id)`（2D）与材质动态纹理（3D，随 `mesh` 属 3D 包）。
  需扩 sprite/材质接受动态句柄——**这是 B2 的主要管子成本**。
- 维度：`texture` 模块基底保留（2D/3D 都用）；3D 材质消费侧随 3d 包。

### C 批 · 合成音效（新 `synth` 模块，维度无关基底）

- `synth.play(spec) -> ok`：spec 表 `{wave="sine|square|saw|triangle|noise", freq, dur, attack, decay, sustain, release, gain, filter={type,cutoff}}`；
  规格表驱动（照 `mesh.set_batch` 的 motion 表形状），AI 生成表不生成代码。
- `synth.play_at(spec, x, y, z)`：复用 `audio` 空间衰减（可选，C 批末或另批）。
- 实现：`engine/crates/rustlua-audio/src/synth.rs` 新增 `SynthSource` 实现 rodio `Source` trait
  （振荡器 + 噪声 + ADSR + biquad 滤波），喂现有 Sink/bus；失败口径照 `audio.play_at`（`ok=false` + warn，不静默）。
- 维度：基底保留（同 `audio`，M81 已裁定 audio 整表不门控）。

### B1 批（缓做，另立包）· RTT 截屏式贴图

`render.capture_begin(w,h)` → 2D 绘制 → `render.capture_end() -> tex_id`，复用 `OffscreenTarget`。
管子重于 B2，本包不开工，登记为后续。

## 风险

- **哨兵文法扩展破坏既有 mesh 路径**：默认路径逐字节回归 + 反面对照防住。
- **动态纹理句柄泄漏**：显式 `free` + 浸泡测试断言纹理数恒定（文章 320 s 浸泡教训）。
- **合成在 wasm/微信未证**：rodio 的 wasm 出口与微信音频 API 不同，C 批先落桌面/WebGL，微信真机另验（诚实边界，不写"通过"）。
- **跨平台确定性**：程序化生成必须 seed 确定、跨平台逐字节一致（照 `terrain_detail.rs`）。
- **范围蔓延**：参数化 ≠ 生成式美术；不碰 M76 出图/切图链路。
