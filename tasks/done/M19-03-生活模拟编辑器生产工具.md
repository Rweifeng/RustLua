## 实现记录

1. **Lua 域数据桥（引擎侧最小新增）**
   `core/script.rs` 新增 `pub fn eval_json(&self, expression: &str) -> Result<serde_json::Value, LuaBridgeError>`：在已加载的 Lua VM 上求值表达式，复用既有私有 `lua_value_to_json`（与 `save.blob_*` 同一套值映射），语法/运行期错误统一转 `LuaBridgeError::Runtime` 并**原样保留 Lua 消息**；不支持的类型（函数等）报错而非 panic。未改动任何既有 API 语义。
   单测 `eval_json_converts_tables_arrays_scalars_and_reports_errors` 覆盖：nil / bool / int / float / string / 数组表 / 字符串键表（含嵌套数组）/ 多语句块 / 非法表达式 / 运行期错误 / 函数值。

2. **领域数据面板（`panels/domain_data.rs`）**
   - **校验来源（按 M20-01 协调改为统一入口）**：工程提供 `scripts/validate_data.lua` 时，编辑器执行 `set_project_root(root)` → `execute_project_script(scripts/validate_data.lua)`（建立 `scripts/` 的 require 搜索路径，**不执行 `main.lua`**）→ `execute_console("return require('validate_data').check({ strict = true })")`，结果与游戏启动校验、`game --check` / `editor --check` 同源；问题按 `[module]` 前缀分组，**问题文本原样保留**文件/对象/字段路径。工程没有该入口时回退为「发现 `scripts/data/**/*.lua` + 定义了 `validate_all` 的 `scripts/*.lua` → 逐模块 `require` + `validate_all()`」（`discover_domain_modules` / `validate_expression` / `parse_validate_result`），保证其它/新工程骨架可用。
   - 每次校验（含「重新校验」按钮）都**新建 Lua VM**：`require` 有模块缓存，复用 VM 会读到旧文件内容。
   - 只读视图经 `eval_json` 一次性取出：`data.maps`（maps/spawn/exits 的 cell→to/to_cell/label）、`data.places`、`data.npcs`（persist_id/home/schedule/character）、`data.shops`（keeper/place/hours/stock 单价与限购/buys）、`data.quests.index`、`data.dialogues.index`、`data.maps.TILE`。
   - 面板展示：校验来源、通过/问题计数、逐模块状态（通过 / 有问题 / 无校验器 / 加载失败）与逐条问题；折叠区展示 PersistId 注册表与只读视图；每行出口/地点有「定位」按钮，按 `id = "..."` / `name = {` 锚点在 Lua 源文件中找行并把 `文件:行` 复制到剪贴板（`locate_line` / `exit_anchor` / `place_anchor`，纯函数并有单测）。
   - **未在 Rust 侧复刻任何 NPC/任务/商店/日程规则**：所有问题字符串都来自 Lua，编辑器只做分组、展示与定位。

3. **PersistId 工作流**
   - **注册表**（`build_persist_registry` + `scan_scene_persist_ids`，纯逻辑）：① 扫描工程 `scenes/*.scene` 的 `entity_meta persist_id`（用 `Scene::from_text` 解析，兼容转义；解析失败作为备注而非 panic）；② 汇总 `data.npcs.persist_id` 定义；③ 收集 `data/shops.lua` 的 `keeper` 引用。报告三类问题：**重复定义**（含全部来源路径）、**场景/NPC 冲突**（同名会让运行期 `entity.spawn` 报 `persist_id already in use`）、**引用未定义**；场景声明但领域数据未提及的 id 作为备注（可能是农田/建筑/容器）。
   - **编辑**：Inspector 新增 PersistId 行（设置 / 清除，Enter 或失焦即提交）→ `EditorApp::set_entity_persist_id` 走 `CommandHistory::execute`（一次提交 = 单条 Undo，无净变化不产生历史），写/删自由 meta `entity_meta persist_id`，**不改场景格式版本**；同场景重名被拒绝并提示。

4. **地图出口 / 交互点 / NPC 地点**
   - Scene View 新增**只读覆盖层**（`draw_domain_overlay`）：当前场景名即地图 id，绘制 `data.maps` 的出口格（绿框 + `exit <id>`）与 spawn（橙框）、`data.places` 的地点格（蓝框 + 中心点），鼠标悬停显示详情（出口 cell/目标地图/落点/label；地点 map/cell/label），左下角显示汇总，未注册地图给出橙色提示。坐标换算复用 Scene 视图的世界→面板映射（`pan`/`zoom`/`pixels_per_point`），`cell` 覆盖 `[c*TILE, (c+1)*TILE)`、`TILE` 取自 `data.maps.TILE`（缺失则不绘制）。
   - 合法性完全委托 `data.maps.validate_all()` / `data.places.validate_all()`（经统一入口），Rust 侧不另写规则。
   - **可视化编辑降级**（见「未完成项」）：只做只读覆盖层 + 校验 + `文件:行` 定位。

5. **Tilemap 生产工具**
   - `panels/tilemap_tools.rs`：纯逻辑 `CellRect`（`normalize` 支持反向拖拽、`clipped` 越界裁剪）、`fill_rect`（tile 值 / solid 位 / 两者，返回是否有净改动）、`copy_region`、`paste_region`（`isize` 原点，右/下溢出与负原点都按网格裁剪）。
   - Scene View Tile 画笔第二行新增模式：`单格画笔`（原行为）/ `矩形填充` / `区域复制` / `区域粘贴`，含选区预览（黄=填充、蓝=复制，左上角显示 `M×N（K 格）`）、剪贴板尺寸与清空按钮。
   - 每个操作 **= 单条 Undo**：填充/粘贴只在释放/单击时调用一次 `commit_tilemap_paint_labelled`（内部 `history.execute`，label 区分「Tilemap 矩形填充 / Tilemap 粘贴」）；区域复制只更新编辑期剪贴板，不写文档不入历史；无净改动时不产生空历史。

6. **运行时调试面板（`panels/runtime_debug.rs`）**
   - `PreviewSession::with_script` 借出预览运行时的 Lua VM；探针表达式逐个经 `eval_json` 读取：当前地图（`map_manager.current()` + `scene.reload()`）、玩家坐标（`map_manager.player_cell()` + `player.ensure()` + `transform.get`）、NPC 列表与活动（`npc.capture()` / `npc.diagnostics()`）、任务（`quest.capture()` / `quest.active()`）、农田地块（`farm.stats()` / `farm.capture()`）、建筑与制作（`building.list()` / `crafting.capture()`）、存档摘要（`save_manager.last_summary()`）、时间与天气（`clock.now()` / `calendar.current()` / `weather.current()`）。
   - 每个探针在 Lua 侧自带 `pcall`：模块缺失/读取失败只显示「读取失败：<原始消息>」，不影响其它探针；未运行时显示「无运行态」占位（保留上次读取说明），**不 panic**；输出超长时格式化并按上限截断。
   - 面板**只读**，不修改游戏状态。

7. **文档**：`docs/25-editor-guide.md` 新增第 14 节（工具栏入口 / 领域数据面板 / PersistId / 覆盖层 / Tilemap 工具 / 运行时调试 / 已知限制），并更新第 4、5 节；`CHANGELOG.md` v0.15 段 M19-03 条目改为已实现摘要，对应任务行同步。

## 未完成项 / 已知限制

- **出口 / NPC 地点的可视化编辑（移动 cell）未实现**：降级为「只读覆盖层 + Lua 校验 + `文件:行` 定位」。原因：回写需要按 `id = "..."` / `name = {` 锚点外科式重写 `cell = { x = N, y = M }`，对嵌套表结构脆弱、易破坏注释与并行编辑；且这类改动作用在 Lua 数据文件上，无法并入以 `SceneDocument` 快照为单位的 Undo 栈（「单条 Undo」语义不成立）。移动出口/地点请在数据文件改 cell 后点「重新校验」（覆盖层随之刷新）。
- **跨场景 PersistId 完整性只报告不阻断**：重复/冲突/引用未定义会列出，但不阻止保存（编辑器不做跨文件写入决策）。
- **回退路径（工程无 `scripts/validate_data.lua`）只支持明文 Lua 模块**：该路径只设置 `package.path`，不经引擎的压缩/加密模块 searcher；提供统一入口的工程（如 `game_jhyt`）走 `execute_project_script`，支持压缩/加密模块。
- 域校验在 UI 线程同步执行（首次需要时自动跑一次 + 手动「重新校验」），大工程可能有一次数十至数百毫秒的停顿；未做后台化。
- 不实现完整蓝图编辑器、多人协作和大型开放世界工具链。
- 未修改任何本任务范围外的文件：过程中遇到的 `ui_navigation.rs`（clippy）与 `demo_persistence.lua`（Lua 语法）阻塞均由各自归属的并行会话修复，本任务只记录不代改。
