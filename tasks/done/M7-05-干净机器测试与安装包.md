# M7-05：干净机器测试与安装包

- 状态：ACCEPTED（待 M7 里程碑汇总验收）
- 验收日期：2026-08-22
- 前置任务：M7-04

## 目标

组装自包含发布包（无源码/工具链依赖），并通过目录隔离模拟"干净机器"验证含空格路径可运行。

## 实施

- `scripts/package.ps1`：
  - Release 构建 → `assetc package` 生成数据资源包（`pack/`）→ 复制 `game_runner.exe`/`assetc.exe`；
  - 生成 `build-info.txt`（版本/构建时间/toolchain）、`deps.txt`（`cargo tree` 依赖清单）、`run.txt`（运行说明）；
  - `-SelfTest`：复制发布包到**含空格**的临时目录（无源码/target/.cache），运行 `game_runner.exe --pack <pack> --check` 验证退出码 0；
- `game_runner` 新增 `--check`：仅校验资源完整性后退出（不弹窗口），供 CI/打包自测。

## 验收结果

- 发布包 `artifacts/builds/release/p2-game/`：11.3 MB，28 文件（game_runner/assetc/pack/3 文档）；
- `build-info.txt`：版本 0.1.0、构建时间、rustc 1.98.0；`deps.txt`：299 项依赖清单；
- 目录隔离自测通过：`p2 release test <ts>\p2-game\game_runner.exe --pack ... --check` exit 0（含空格路径 + 无源码环境）；
- 缺失资源时 `--check`/`--pack` 均非零退出并报资源名。
