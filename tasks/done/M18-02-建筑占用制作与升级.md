## 风险

- 建筑不能覆盖道路、出口、已耕地、作物和既有建筑。
- 放置失败必须无副作用，且显示具体冲突格。
- 建筑占用状态必须进入地图快照并支持版本化。

## 实现记录

- **纯数据注册表**：`data/buildings.lua`（version=1 + `validate_all`）声明 `w/h` footprint、`ground_tiles` 可建地表白名单、`levels` 各级贴图与尺寸、`upgrade_cost`、`station`；`data/recipes.lua`（version=1 + `validate_all`）声明 `station/inputs/output/minutes/min_level`，校验跨文件引用（station 必须存在于建筑、物品必须存在、min_level ≤ 该 station 建筑最大等级、错误含文件/对象/字段路径）。新增建筑或配方只改数据，Rust 核心零改动（headless 章节 i 在运行期动态追加「工坊 + 制板」并完成放置/制作/收取验证）。
- **占用校验**（`building.lua`）：锚点格 + `w×h` footprint 逐格判定，冲突原因固定顺序 `out_of_bounds → farm_plot → building → ground → solid → exit → road`（农田在夯土上，先于 ground 判定才能给出准确原因；出口先于道路，避免石板出口被报成 road）。判定数据源：GroundMap `tile`/`solid`、`data.maps` 当前图出口触发格、`farm.is_plot`（新增只读辅助）。`preview(facing)` 返回 footprint 格列表 + 逐格冲突（HUD 与 headless 共用，验收项①）。
- **放置/拆除/升级**：`place` 先校验再落库——失败零副作用（不写 map.state、不生成实体、不改阻挡）；成功后写 `map.state("buildings") = {version=1, seq, list}`、生成 `Building:<id>:<seq>` Sprite 实体（`sprite.set` 组件串含贴图/尺寸/pivot/sorting_layer=world）、对 footprint 全格 `tilemap.set_solid(..., true)`。`remove` 支持多格命中，制作任务进行中拒绝 `crafting_pending`。`upgrade` 满级返回 `max_level`、材料不足返回 `not_enough`（均不扣材料），成功换 level 贴图。
- **重载一致性**：`on_enter(map_id)` 从 map.state 重放——重生视觉（先 `entity.is_alive` 判活，幂等不重复生成）、重打 footprint 阻挡；`capture/restore` 只写内存与地图快照，视觉统一走 on_enter（吸取 farm.lua 陈旧 farm_id 的教训，杜绝跨场景 id 复用）；`farm.redraw_all` 同步加固为判活 + `tilemap.get` 双重校验。
- **制作设施**（`crafting.lua`）：时间模型 = `clock` 游戏分钟绝对量 `(day-1)*1440 + minute_of_day`，job 记录 `done_abs`（跨天自动进位，不依赖真实时间）；`start` 原子校验（`unknown_recipe`/`no_building`/`no_station`/`station_level`/`busy`/`not_enough`，失败无副作用）；`collect` 未到点返回 `{"crafting", 剩余分钟}`，背包满用 `inv.add` leftover 判定并保留 job；`map.state("crafting")` 持久化，读档后按 clock 重推剩余时间。药庐（herb_hut）level1 → `pill_refine`（灵芝×2→回复药），level2 → `tonic_refine`（灵芝×1+稻谷×2→行气散）。
- **接入**：interaction 注册 `building_station`（priority 10，介于农田 0 与商店 20）：prompt 显示「E: 制作 X / E: 制作中（剩余 N 分钟）/ E: 收取 X」；input 增加 B（建造模式开关）、F（面向格放置，冲突写入 last_action 含格坐标）、X（拆除）、U（升级）、建造模式下 Q 切换建筑（非建造模式保持原「修炼」语义），HUD 建造模式追加「建造[名称] 可放置 N 格 / 占用冲突 reason@x,y」文案；main.lua 新增 building/crafting 存档 provider、`data.buildings`/`data.recipes` 加载期校验、`new_game` 复位、`enter_playable_map` 在 `farm.init` 后接线（`set_job_guard` 打通拆除保护）。
- **附带同步（示例重组改名 main→manor 的遗留）**：`jhyt_m17.rs` 出口动作断言 `exit_main`→`exit_manor`；`jhyt_m17_shop.rs` 货摊 stock 3→4、rows 3→4（木料上架）；`scenes/manor.scene` 头部 `name=main`→`name=manor`（否则 `scene.reload()` 与地图键不一致导致 `is_playable` 判定失败、整局无法进入玩法地图）。
