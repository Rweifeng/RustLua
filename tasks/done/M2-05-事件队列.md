## 实施内容

- 新增 `engine_core::events::EventQueue`。
- 使用 `TypeId + Any` 保存多种类型事件，事件值要求 `Send`，便于后续系统边界扩展。
- 支持发布事件、按类型读取、按类型消费、清空当前帧事件和统计待处理数量。
- 使用 current/next 双缓冲明确帧边界：本帧发布的事件不会被本帧消费，只在下一次 `begin_frame` 后可见。
- 同类型事件保持发布顺序。
- `drain` 消费后事件不会再次出现；下一帧边界会丢弃上一帧未消费事件，避免旧事件无限滞留。

## 主要 API

```rust
EventQueue::new()
EventQueue::send(event)
EventQueue::begin_frame()
EventQueue::frame()
EventQueue::read::<T>()
EventQueue::drain::<T>()
EventQueue::clear_current()
EventQueue::len::<T>()
EventQueue::pending_len::<T>()
```

## 设计边界

本任务实现的是单线程调用模型下的类型化、双缓冲事件队列。当前不包含跨线程无锁队列、事件订阅器、事件持久化、按实体索引和 Command 队列；这些能力留给后续任务，在系统通信需求明确后再扩展。
