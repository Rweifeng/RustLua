## 批次风险

- **M72-01 改 `.scene` 格式会打断 `jhyt_m59`…`jhyt_m71` 八道 UI prefab 黄金表**。
  这些门比对的是 UI 实体层，理论上不受 tilemap 编码影响，但**必须逐门跑一次确认**，不能假设。
- **变体哈希必须确定性**，否则每帧抖、所有画面类门必红（见 M72-02）。
- **图集预算口径未定**：`51` 定的是"每图 ≤1 张 1024×1024"，而 `manor` 加完地表/农田/湿润/作物
  装不下。这条在 M72-04 的前置里解决，不能等接完线才发现超预算。
- **像素字体子集后仍有缺字风险**：游戏当前字表 471 字（`examples/game_jhyt/chars.txt`），
  新增文案会踩缺字契约（`49`），M72-03 的门要覆盖"逐字有非空字模"。
- 新增 `jhyt_m72_*` 用例**必须同步登记进 `verify.ps1` 的 MVP 清单**，否则门直接 throw。
