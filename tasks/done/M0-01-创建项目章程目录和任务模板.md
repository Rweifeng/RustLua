# M0-01 创建项目章程、目录和任务模板

## 状态

ACCEPTED

## 目标

建立项目范围、技术基线、AI 协作规则、目录结构和后续任务管理方式。

## 实施内容

- 创建项目基线目录；
- 创建项目章程；
- 创建技术决策记录；
- 创建验收矩阵；
- 创建风险登记表；
- 创建 M0 里程碑文档；
- 创建任务模板和当前任务记录。

## 不做什么

不创建 Cargo workspace，不引入 Rust 依赖，不实现窗口、渲染、Lua 或 ECS，不修改总计划内容。

## 验收标准

- [x] 项目章程包含目标、非目标、技术基线和成功标准；
- [x] 项目目录已创建；
- [x] 任务模板包含目标、范围、方案、验收和测试字段；
- [x] 已建立验收矩阵和风险登记表；
- [x] 新 AI 会话能够根据文档理解当前状态；
- [x] 没有删除或覆盖已有计划文件。
