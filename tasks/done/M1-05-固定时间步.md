# M1-05 固定时间步

- 状态：`ACCEPTED`
- 完成日期：2026-08-20
- 里程碑：M1 基础运行时

## 目标

为引擎建立可重复、可控的固定时间步调度：模拟逻辑默认以 60Hz 更新，渲染仍按窗口实际重绘频率执行，并在低帧率时限制追赶，避免螺旋死亡。

## 实现范围

- 新增 `engine_core::time_step::FixedTimeStep`、`StepReport` 和 `TimeStepError`；
- 默认 game runner 使用 60Hz，固定 `dt = 1.0 / 60.0`，即约 `0.016667s`；
- 每次墙钟时间推进最多执行 8 个追赶步；超出部分丢弃并累计统计；
- Lua `update()` 通过 `time.delta()` 接收固定 `dt`；
- 渲染与模拟解耦，渲染继续使用实际帧率；
- 暂停/恢复时清空 accumulator，不重放暂停期间积累的旧时间；
- 输出本次步数、固定 dt、accumulator、总步数和丢弃步数。
