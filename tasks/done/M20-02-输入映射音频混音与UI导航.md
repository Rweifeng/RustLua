（`FocusRing` / `ScrollState`）**接入运行时 UI**，使样板游戏 `game_jhyt` 的背包、
任务、对话、商店、暂停面板能用方向键上下移动与滚动，满足 Alpha 可用性要求。

> 范围变更（2026-09-13）：原任务书中的「可配置动作映射 + 基础手柄/重绑定」被切分为
> `M20-07`（Lua `input.action*`/`pad*`、`ActionMap` 注入与设置持久化）、
> `M20-08`（编辑器重绑定面板、`game_jhyt` 命名动作迁移、`jhyt_m20_gamepad`）、
> `M20-06`（gilrs 设备层）。本文件只覆盖收窄后的范围，契约（绑定文本用
> `Binding::to_text`、按钮索引表、死区约定）与 M20-06/07/08 对齐。

## 风险（执行前评估）

- 扩展输入公共 API 可能影响既有 WASD/WebGL 行为 → 方向键用 `InputKey::Other(<非 ASCII 码位>)`
  常量实现，**不新增枚举变体**，`key:other:<code>` 绑定文本语义不变。
- 面板导航改动可能打挂 M17/M18/M19 的 headless 断言 → 所有面板保留既有 1 基 API 与
  W/S 行为，焦点环只作为「方向键 + 既有键位」的共同实现，引擎缺 API 时自动降级为旧语义。
- 音频分组不得阻塞玩法逻辑 → 无输出设备时 `play_on/play_music` 返回 `Ok` 只记日志。

## 实现记录

### 1. 工程设置文件（`core/settings.rs`，新增）

- `ProjectSettings`：`volume/set_volume/from_audio/apply_to/from_toml/to_toml/path_in/load_from/save_to`。
- 解析宽松（未知段/键、非法数值忽略并保留默认 `1.0`，不 panic）；写入保序
  （`upsert_audio_section` 只替换/补齐 `[audio]` 段内四个键，注释与其他段原样保留，
  追加键插在下一个表头之前）。
- 无新依赖（离线环境无法拉取 crates），逐行手写解析。

### 2. `audio` Lua API（总线与持久化）

- 新增：`buses()`、`set_bus_volume(bus,v)`、`bus_volume(bus)`、`effective_volume(bus)`、
  `play_on(bus,name)`、`settings_text()`、`apply_settings(text)`（版本头
  `rustlua-audio-v1`，不符返回 `false, reason`；非法行忽略）、`settings_path()`、
  `load_settings()`（缺失文件返回 `false, "missing"`）、`save_settings()`。
- 未知总线名报 Lua 错误（拼写错误可定位）；`play/volume/music/stop_music` 语义不变。
- `AudioBus` 派生 `PartialOrd, Ord`（设置文件用 `BTreeMap<AudioBus, f32>`）。
- `AudioSystem::play_on/play_music`：设备缺失 → 静默降级返回 `Ok(())`（M19-02 策略），
  只有缺文件/解码失败才 `Err`；这是保住 `audio.sfx(...)` 在无设备机器上仍返回 true 的关键。

### 3. `ui` 焦点与滚动（`ui_navigation` 运行时接线）

- `ScriptState` 新增 `focus_rings: BTreeMap<String, FocusRing>` 与
  `scroll_states: BTreeMap<String, ScrollState>`；`process_scene_transition` 时清空。
- Lua API：`focus_open(id,count[,columns])`（0 基，`columns` 支持网格）、`focus_select`、
  `focus_index`、`focus_move`（方向键到边界环绕；未知方向报错）、`focus_cycle`、
  `focus_count`、`focus_close`；`scroll_open/extents/by/lines/page/offset/max/to_visible/
  visible/close`（偏移钳制、最小滚动；区间字段为 `{start, stop}`，避开 Lua 关键字 `end`）。
- 新增物理方向键 `InputKey::ARROW_UP/DOWN/LEFT/RIGHT`（非 ASCII 码位常量），
  `parse_key("up"/"down"/"left"/"right")`、`game_app.rs` 与编辑器 Play 预览同源映射。

### 4. 游戏侧接线（`examples/game_jhyt/scripts/`）

- `panel_nav.lua`（新）：把 0 基引擎 API 封装成 1 基面板调用（`open/select/index/move/cycle/
  window/close`），引擎缺 API 时静默降级（调用方回落旧语义）。
- `audio.lua`：`master/bgm/sfx/ui` 总线；`sfx` → SFX 总线、新增 `ui` → UI 总线、BGM 走
  `music`；`set_bus_volume/adjust_bus_volume/effective_volume/play_on/settings_text/
  apply_settings/load_settings/save_settings`；主音量读取仍以模块本地缓存为准（保住
  M19-02 的 `0.45` 往返断言），分组音量以 settings.toml 为准。
- `pause_menu.lua`：新增「设置」子页（主音量/BGM/音效/界面音效 ± 、保存设置、返回），
  主菜单行数保持 5（M19-02 回归），Esc 在子页返回主菜单、P 直接继续。
- `input.lua`：五个面板加方向键分发（`move_dir`），暂停态 Esc 区分设置页/主菜单。
- `inventory_ui/quest_ui/shop/dialogue`：`move` 改为焦点环步进（引擎不可用时回落原钳制
  语义）、新增 `move_dir`、渲染前同步焦点环；`quest_ui` 与 `shop` 用 `nav.window` 做
  按选中行的滚动窗口；面板 UI 音效改走 UI 总线。
- `main.lua`：boot 时 `audio.load_settings()` 应用 settings.toml；`jianghu_status()`
  增加 `buses` 与 `settings_path` 只读字段。

### 5. 编辑器「项目设置」音频小节

- 四滑块（0..=1 + 百分比）+ settings.toml 路径展示；与 project.toml 一起保存；
