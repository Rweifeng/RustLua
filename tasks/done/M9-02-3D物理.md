# M9-02 3D 物理

## 状态

ACCEPTED

## 目标

在 `engine_core` 增加 3D 物理：`rapier3d` 刚体、碰撞体（球/盒/胶囊）、触发器、射线/重叠查询，碰撞事件进 Lua，固定时间步推进，与 Transform3D 双向同步；复用 2D 物理 API 形态，2D 路径不回归。

## 背景

M8 只做了 2D 物理（`rapier2d`）。3D 可玩游戏（M9-04）需要 3D 碰撞/射线/触发器。ADR-0008 已批准 rapier3d 选型。

## 输入

- `docs/27-M9-3D可玩垂直切片实施计划.md`（M9-02）
- `docs/02-technical-decisions.md`（ADR-0007 坐标系 / ADR-0008 物理选型）
- `engine_core/src/physics.rs`（2D 参考实现）
- `engine_core/src/script.rs`（物理 Lua 绑定与场景实例化）
- `engine_core/src/transform3d.rs`（Transform3D）

## 不做什么

- 不修改 2D 物理路径与 Lua `physics.*` API；
- 不做连续碰撞检测、软体、角色控制器内置组件等高级物理能力；
- 不破坏 v0.8 场景格式与发布路径。

## 技术方案

- 新模块 `engine_core/src/physics3d.rs`：`ColliderShape3d`（Ball/Cuboid/Capsule）、`ColliderDesc3d`（含 `dynamic`/sensor/layer/mask，`from_component_str` 解析 `Collider3d` 组件串）、`PhysicsWorld3d`（add_body/remove_body/set_velocity/velocity/set_position/step/drain_contacts/raycast/overlap）。复用 2D 的 `PhysicsError`/`PhysicsContact`；重力默认 `(0,−9.81,0)`；增删 body 后刷新 `query_pipeline.update` 保证查询即时有效。
- 依赖：`rapier3d = "0.22"`（与 rapier2d 同版本）。
- script.rs 集成：`ScriptState.physics3d`；场景 `Collider3d` 组件 → `add_body(id, pos, desc.dynamic, vec![desc])`；`step_physics3d` 写回 Transform3D；场景切换重置；实体销毁移除 body；Lua 表 `physics3d`（set_velocity/get_velocity/set_position/events/raycast/overlap）。
- runtime_scene.rs `run_script_steps` 增加 `step_physics3d` 调用。

## 风险

- rapier3d 与 rapier2d API 差异：先做最小 3D 刚体冒烟再扩展；
- 3D 同步破坏渲染坐标：仅同步 translation，rotation/scale 不动；
- 2D 回归：不触碰 `physics` 字段与 `physics.*` 表。
