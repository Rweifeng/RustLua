# 任务：多地图与场景生命周期

- 任务 ID：M17-01
- 状态：已实现（headless 验收通过）
- 关联里程碑：M17
- 创建日期：2026-09-09

## 目标
为 `game_jhyt` 建立山庄、云泽村、青云山道及室内场景的地图注册、出口传送、进入/离开生命周期和跨地图状态管理。

## 影响文件

- `examples/game_jhyt/scenes/`
- `examples/game_jhyt/scripts/main.lua`
- `examples/game_jhyt/scripts/` 下新增 `map_manager.lua`、`transition.lua` 或等价模块
- `examples/game_jhyt/scripts/data/` 地图和出口数据
- 相关地图灰盒资源

## 风险

- 地图 ID、入口 ID 和出生点必须冻结并写入数据校验。
- 切图期间锁定输入，避免重复加载和重复生成玩家。
- 场景加载失败必须保留当前状态并输出地图 ID、入口 ID 和资源路径。

## 实现记录

- 引擎侧新增 2D 传送 API `physics.set_position(id, x, y)`（`core/physics.rs` 的 `PhysicsWorld::set_position`，`core/script.rs` 注册 Lua 绑定）：同步刚体与 ECS `Transform` 后清零后续物理写回覆盖，供切图落点与读档恢复使用。`map.goto(map, x?, y?)` 在 M17-01 收口为：校验 `scenes/<map>.scene` 存在后写入 `save_data["__map"]` 与 `__map:spawn:x/y`（世界坐标），排队 `scene_pending_load`，真正切图在 `process_scene_transition` 应用并重跑全局 `on_create`。
- 新增 `scripts/data/maps.lua` 地图注册表：登记 `main`（山庄）与 `village`（云泽村）两张图的 `display/title/spawn/exits`；以 `cell`（0-index、y 朝上，与 tilemap/farm 同约定）+ `TILE=32` 换算世界坐标，并提供 `M.get`/`M.exits`（出口 id 反查）/`M.to_world`/`M.entrance_to`。
- 新增 `scripts/map_manager.lua` 统一生命周期入口：`on_enter(map_id)` 负责落点（`map.spawn()` 优先，其次注册表默认 `spawn`）与当前图标记；`ensure_exits(map_id)` 幂等注册本期出口到 `interaction`，出口 `query` 用玩家所在 cell 与出口格比对（走到格子上按 E 触发），`interact` 调 `map.goto` 切图并在切图期间经 `state.set_mode("Transition")` 锁定输入。
- `scripts/main.lua` 收敛为多地图分发：标题 `on_click` 记录 `entry`（new/continue）并 `scene.load` 到目标图；`continue` 先 `save_manager.peek_map()` 只读存档地图再切换（非固定山庄）；首次进入玩法地图做一次性引导（`inventory.setup` + provider 注册 + new/continue 处理），跨图往返只走 `on_enter`（不重建背包、不重读档）；`on_day_start` 在当前地图上执行，仅 `main` 做农田日结算。
- 新增场景 `scenes/village.scene` 与灰盒生成器 `tools/gen_village_scene.py`（复用 `assets/art/greybox/manor_ground.png` 的 6 色灰盒调色）。
- 跨地图状态：`save_manager` 捕获 `scene.map`（`map.current()` 优先）与 `main` 的 `map_state.farm_plots`；`__mapstate:*` 键随 `save.commit` 全量落盘，跨图 continue 据此回到正确地图并恢复农田明细。
- 玩家位置快照改为记录所在地图 id + 世界坐标（`player.capture/restore`），恢复时用 `player.teleport`（`physics.set_position`）同步刚体，避免 `transform.set` 被下一帧物理回写覆盖。
