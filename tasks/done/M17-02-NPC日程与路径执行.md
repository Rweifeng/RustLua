## 目标
实现可由纯数据驱动的 NPC 实体、日程、地点切换和 A* 路径跟随，支持跨天和天气替代日程。

- `engine/crates/game/examples/jhyt_m17_npc.rs`（新增：headless 验收）

## 风险

- NPC 必须使用稳定 PersistId，切图和重载不能复制实体。
- 日程冲突、不可达地点和跨午夜区间必须有确定的诊断。
- 不在本任务内实现复杂群体 AI，先完成时段状态和路径移动。

## 实现记录

- **引擎能力零改动**：全部能力（`entity.spawn(name, persist_id)` 稳定 PersistId、`entity.find_id`/`persist_id`/`is_alive`/`destroy`、`tilemap.find_path` A*、`tilemap.set_solid`、`sprite.set`、`transform.get/set`、`clock.now/set`、`time.delta`、`map.current`）在引擎侧已存在，本任务未修改任何 Rust 核心代码（验收项①）。
- **`schedule.lua`**：`get(id)` 懒加载 `data/schedules/<id>.lua`；`format_minute` 输出 `HH:MM`；`resolve(id, minute, rainy)` 返回 `{place, activity, block, index, minute}` 或 `nil, reason`，雨天用 `rain_place` 替换地点；`validate`/`validate_all` 校验时段覆盖与字段引用。时段 `contains`：`from<to` 为普通区间，`from>to` 为跨午夜区间。
- **`npc.lua`**：按 `clock` 分钟 + 天气解析日程 → 目标地点；地点在本图时用 `tilemap.find_path` 求 A* 路径，**逐帧 `transform.set` 推进**（移动预算 `speed*dt`，可跨多个 waypoint，guard<64）——因为 Lua 侧没有创建 2D 刚体的 API，对 NPC id 调 `physics.set_position` 会报 `UnknownBody`。目标换图时销毁本图实体（逻辑上"去了别的地图"），等玩家进入目标图 `on_enter` 时按 PersistId 经 `entity.find_id` 去重重建，**不复制实体**。路径失败按 `REPATH_TICKS` 节流重算，避免每帧 A* 与刷屏。
- **诊断（验收项③）**：不可达 / 未知地点 / 时段缺失统一经 `target_line` 输出 `npc=`/`persist_id=`/`window=HH:MM-HH:MM`/`map=`/`place=`/`cell=x,y`/`activity=`，失败追加 `reason=`；`report` 去重后既写 `log.warn` 又累积到模块级 `diagnostics`，供 `M.diagnostics()` 查询。
- **跨图语义**：`npc.on_enter(map_id)` 重新绑定本图 `GroundMap`，清空旧实体 id 记录后 `M.sync()` 按逻辑地图重建本图 NPC；`tick_actor` 在目标图 ≠ 当前图时 `despawn` 并同步清理过期 `pending_pos`。
- **存档（验收项④）**：`M.capture` 记录 `{day, npcs=[{persist_id, map, place, activity, cell, pos}]}`；`M.restore` 写回逻辑状态，本图已有实体立即 `transform.set` 到存档坐标，他图实体等 `on_enter` 重建；由 `main.lua` 注册为 `save_manager` 的 `"npc"` provider。
- **修复（headless 运行发现）**：`data/npcs.lua` 的 sprite 字符串原为 `"__white__;size=..."`，缺少首字段 `texture=` 前缀，`SpriteComponent::from_component_str` 要求第 0 个字段形如 `texture=<path>`，导致 `sprite.set` 报 `invalid sprite field: __white__`、NPC 无外观。已改为 `"texture=__white__;size=..."`（与 `scenes/*.scene` 写法一致）。
