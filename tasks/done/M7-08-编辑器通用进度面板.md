# M7-08：编辑器通用进度面板（导入/发布非阻塞 + 可复用）

- 状态：ACCEPTED（待 M7 里程碑汇总验收）
- 验收日期：2026-08-22
- 前置任务：M7-07（发布集成）、M5（编辑器）

## 目标

1. 编辑器导入游戏项目时展示进度面板，不阻塞主进程；
2. 打包发布时不弹额外终端窗口，在编辑内展示进度面板，不阻塞主进程；
3. 进度面板做成**通用组件**，后续进度信息复用。

## 实施

- 新增通用 `ProgressPanel` 组件（main.rs）：标题、状态、确定进度条（`Option<f32>`）/不定进度动画、日志滚动区、完成状态与「打开目录」「关闭」；
- 事件 `ProgressEvent::{Line, Progress(f32), Finished{success, result}}`，后台任务经 mpsc 通道流式转发，UI 每帧 `poll()` 非阻塞排空；
- **发布**改用 `ProgressPanel`：后台线程执行 `scripts/package.ps1`，`CREATE_NO_WINDOW` 保证不弹终端窗；结束落盘 `publish-last.log`；
- **导入**改用 `ProgressPanel`：后台线程 `open_project` + 加载文档 + 扫描资源，结果 `ImportOutcome`（含 project/document/recovery/resources）经 `Finished.result` 回传，主线程 `apply_progress_result` 应用——UI 不再卡顿；
- 兼容处理：脚本路径去 `\\?\` 前缀、子进程 PATH 补 cargo（沿用 M7-07 修复）。

## 验收结果

- 发布端到端（删 p2-game → spawn_publish → 完整生成）；导入端到端（spawn_import → ImportOutcome 生成）。
