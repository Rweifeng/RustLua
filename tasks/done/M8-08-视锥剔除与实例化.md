# M8-08 视锥剔除与实例化

## 状态

ACCEPTED

## 目标

使用包围球和 Camera3D 视锥平面做 CPU 剔除；对相同 Mesh/材质提供实例数据缓冲；先保证结果正确再测量收益；提供无剔除/无实例化回退路径。

## 验收目标

- 视锥内外分类边界有单测；
- 剔除不会改变可见结果；
- 实例数、绘制数和 CPU/GPU 时间有基线；
- 无剔除/无实例化回退路径可用。

## 实现

### engine_core（camera3d.rs）

- `Frustum::planes()`：从 view-projection 提取 6 个世界空间裁剪平面（Gribb–Hartmann，z∈[0,1]），法线归一化。
- `Frustum::contains_sphere(center, radius)`：任意平面 `signed_distance < -radius` 即剔除；接触边界保守保留。
- 单测：`frustum_sphere_culling_respects_radius`、`frustum_planes_agree_with_point_classification`。

### game_runner

- 每个 CachedPrimitive 缓存局部包围球（顶点 AABB → 球心+半径）；按实体 model 变换为世界球（半径乘最大轴缩放）做 CPU 剔除。
- 静态网格按 (mesh_path, primitive) 分组成实例；材质 uniform 去掉 model，实例 model 存入 storage buffer（`instance_models`），`draw_indexed(..., instance_count)`。
- 蒙皮网格单独绘制（每实例 1 palette）；无剔除/无实例化经 `--no-cull` / `--no-instance` 回退。
- 每 120 帧输出 `[render] 3D baseline draws/instances cull=.. instancing=..` 基线日志。

### Demo

- `demo3d.lua` 生成 8×8=64 个相同 triangle 实例网格（触发实例化 + 剔除基线）。

## 基线（真实窗口，RTX 3060）

| 配置 | draws | instances |
|---|---|---|
| 默认（剔除+实例化） | 12 | 48–55 |
| `--no-cull`（实例化开） | 12 | 76 |
| `--no-instance`（剔除开） | 55 | 55 |
| `--no-cull --no-instance` | 76 | 76 |

- 实例化：76 实例 → 12 次绘制（65 个相同 triangle 合并为 1 次）。
- 剔除：76 → 48–55 实例（相机可见范围外被剔除，可见结果不变）。
