# M0-05 M0 里程碑验收

## 状态

ACCEPTED

## 目标

对 M0-01 至 M0-04 的项目基线进行一次完整回归验收，确认项目可以安全进入 M1 基础运行时开发。

## 验收范围

- 项目章程、目录和任务模板；
- Cargo workspace 和最小运行器；
- 本地质量门、测试、Debug/Release 构建入口；
- 验收矩阵和风险登记；
- 文档 UTF-8 编码和控制字符完整性；
- 当前已登记风险和未完成项。

## 不做什么

- 不接入 wgpu、Lua、ECS、窗口或其他 M1 功能；
- 不将尚未在远程 GitHub Actions 上执行的 CI 记录虚报为通过；
- 不关闭仍然存在的 PATH 持久化风险；
- 不修改两个总计划文件。

## 实际验收命令

在 `C:\GitHub\p2` 执行：

```powershell
$env:PATH = "C:\Users\Administrator\.cargo\bin;" + $env:PATH
./scripts/verify.ps1
./scripts/verify.ps1 -Release
./scripts/test.ps1
./scripts/build-release.ps1
./scripts/run-demo.ps1
./scripts/run-demo.ps1 -Release
```
