# M7-03：崩溃日志

- 状态：ACCEPTED（待 M7 里程碑汇总验收）
- 验收日期：2026-08-22
- 前置任务：M7-02

## 目标

Release 构建下 panic 时写出可定位的崩溃报告。

## 实施

- `engine_core::logging::install_crash_handler(path)`：`std::panic::set_hook` 写入 `crash.log`（version/timestamp/thread/panic/location/backtrace），然后调用默认 hook；
- `game_runner`：`crash.log` 写在游戏日志同目录（exe 相对解析）；
- `editor`：`crash.log` 写在编辑器可执行文件同目录。

## 验收结果

- 单元测试 `crash_handler_writes_report_with_payload_and_version` 通过：`catch_unwind(panic!("boom"))` 生成含 `P2 crash report`/`panic=boom`/`version=`/`backtrace:` 的报告；
- Release 构建同样生效（hook 不依赖 Debug）；
- 正常退出不产生 crash.log。
