# M5-05：资源浏览器与刷新

## 目标

在编辑器中提供项目资源的递归扫描、类型识别、筛选、刷新和失败状态展示，并复用 M4 `ResourceDatabase` 保留资源身份。

## 实施条目

- [x] 新增 `ResourceBrowserState`、`ResourceEntry` 和 `ResourceKind`。
- [x] 递归扫描项目 `assets/` 目录。
- [x] 支持纹理、Lua、场景、预制体、图集和未知文件类型识别。
- [x] 将支持的资源注册到 `ResourceDatabase`，保持 AssetId 稳定。
- [x] 对未知扩展名生成可见失败条目。
- [x] 实现不区分大小写的路径筛选。
- [x] 实现刷新并识别新增资源。
- [x] 显示资源数据库、扫描和资源目录错误。
- [x] 接入编辑器底部资源浏览器 GUI。
- [x] 更新验收矩阵和使用手册。

## 验收方案

1. `cargo fmt --manifest-path engine/Cargo.toml --all -- --check` 通过。
2. `cargo clippy --manifest-path engine/Cargo.toml --workspace --all-targets --all-features -- -D warnings` 通过。
3. `cargo test --manifest-path engine/Cargo.toml --workspace --all-features` 通过。
4. `assets/` 下新增、删除或嵌套目录中的文件可被刷新发现。
5. 筛选条件对路径不区分大小写，清空筛选后恢复全部条目。
6. 已注册资源重复刷新时 AssetId 不变。
7. 未知扩展名、缺失 `assets/` 和扫描失败均有可见错误状态。
8. `git diff --check` 通过。

## 边界

本任务不实现资源预览、纹理解码、Lua 编译、导入缓存重建和拖拽引用；这些属于后续导入或编辑器任务。
