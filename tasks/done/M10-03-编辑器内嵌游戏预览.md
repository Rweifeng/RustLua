# M10-03 编辑器内嵌游戏预览

## 状态

ACCEPTED

## 目标

编辑器 Game 视图实时显示游戏画面：Play 真正运行 Lua + 物理 + 渲染（离屏），Stop 恢复编辑场景。这是编辑器对标 Unity/Godot 的核心一步。

## 背景

M10-01 抽取 engine_host，M10-02 实现 Renderer offscreen 渲染目标。M10-03 把运行时嵌入编辑器：单一 wgpu 设备（ADR-0012），Play 时创建运行时渲染到离屏纹理，egui 显示。

## 输入

- `docs/28-编辑器强化实施计划.md`（M10-03）
- `docs/02-technical-decisions.md`（ADR-0012）
- `engine/crates/engine_host/`（Renderer/RuntimeScene）
- `engine/crates/editor/`（egui/eframe）

## 不做什么

- 不引入跨设备渲染或多适配器；
- 不改变 game_runner 窗口渲染行为；
- 编辑器 3D 透视视口（M10-04）另做。

## 技术方案

- **engine_host**：`Renderer::new_offscreen(device, queue, ...)`（外部设备/queue，无 surface）；`copy_texture_to_cpu`（RGBA8 同步回读）；`RuntimeScene::from_scene`（实例化指定场景，供编辑器运行当前编辑场景）。
- **editor**：从 eframe `wgpu_render_state` 克隆 device/queue（单一设备）；`NativeOptions` 改用 `Renderer::Wgpu` + eframe `wgpu` feature；Play 时 `create_preview`（RuntimeScene::from_scene + Renderer::new_offscreen + 离屏纹理）；每帧 `update_preview`（固定步进 + 构建 SceneMesh/Scene3d + render_into_texture + copy_texture_to_cpu + egui TextureHandle 更新）；Game 视图按纵横比显示；Stop 丢弃 preview。

## 修改范围

- `engine/crates/engine_host/src/renderer.rs`（offscreen 模式 + copy_texture_to_cpu + 离屏测试）
- `engine/crates/engine_host/src/runtime_scene.rs`（from_scene）
- `engine/crates/editor/src/main.rs`（内嵌预览）
- `engine/crates/editor/Cargo.toml`、`engine/Cargo.toml`（eframe wgpu feature）

## 验收标准

- 编辑器 Game 视图实时显示游戏（Play 运行 Lua+物理+渲染）；Stop 恢复编辑场景；
- 离屏渲染 + 回读产生有效像素（自动化测试）；
- game_runner 窗口渲染行为不回归；
- Debug/Release 质量门通过。

## 验收证据

- engine_host 离屏集成测试（render_into_texture + copy_texture_to_cpu 产生有效像素）；
- 编辑器以 wgpu 渲染器启动无崩溃；
- 283 测试/质量门通过。

## 风险

- 单一设备与 egui 共用：离屏渲染不干扰 egui（render_into_texture 提交独立 encoder）；
- 回读每帧同步性能：640×360 预览可接受，优化留待后续；
- Play 画面观感需负责人实机确认。
