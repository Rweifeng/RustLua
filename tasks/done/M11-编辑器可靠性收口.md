## 状态

ACCEPTED（代码/自动化/实机验证，2026-08-24 归档）；G02 150% DPI、G03 分辨率切换与 G04 Stop 真实点击仍待负责人实机手动（无真实指针/系统缩放环境限制）。

## 目标

按 [30-编辑器可靠性-2D工作流-资源系统闭环实施计划](../docs/30-编辑器可靠性-2D工作流-资源系统闭环实施计划.md) 执行

## 背景

M10 强化了编辑器基线与 GUI/GPU 证据规范（`v0.10-editor`）。M11 针对可靠性隐患（Play 状态漂移、卡键、
offscreen 缓存与尺寸不一致、编辑器与运行时提取路径分叉、恢复/字体内存/错误不可见）逐项收口，并修复
Game 预览 3D 场景帧率过低（24fps）的实机性能问题。

## 不做什么

- 不改场景文件格式、不重设计运行时渲染架构；
- 不把自动化覆盖的边界（Stop 往返、DPI）描述为已实机点击验证；
- 不做 M12 资源系统闭环（阶段 2 依赖图、M12-03~M12-05）。

## 技术方案

- **M11-00 基线冻结与故障复现包**：以 `fc7ba0a`（engine_core/engine_host 合并）为基线，汇总可靠性故障复现；
- **M11-01 PlaySession 状态机**：`PlayState`（`Editing → Starting → Playing / StartFailed → Stopping → Editing`）；
  仅预览初始化全部成功才置 PlaySession 并进入 Playing，失败保持编辑态，Stop 经 Stopping 清理后回 Editing；
- **M11-02 输入快照与帧边界**：跨帧持久 `InputSnapshot`，`mem::take` 取快照、`finish_frame()` 清除边沿，
  失焦/Play-Stop 时 `clear_all()` 防卡键；
- **M11-03 Offscreen/readback/缓存一致性**：`ReadbackSlot` 用 `map_result`+`map_error` 捕获映射失败，
  `poll_readback` 区分 NotReady/Ready/Failed；Scene 视图缓存 key 记录实际渲染尺寸，仅回读成功后提交，
  失败清缓存 + 用户可见错误 + 请求重绘；
- **M11-04 场景解析与运行时提取统一**：`scene_3d_with_camera(aspect, camera_override)` 让编辑器 3D 视图与
  运行时共用同一条 ECS drawable 提取路径；相机覆盖为视图参数、不改场景数据，无 ECS 时回退 serialized extractor；
- **M11-05 恢复、字体内存与错误可见性**：recovery 带版本/校验和/时间戳，损坏文件进 invalid 可丢弃；
  `FontAtlas` 满后 glyph/像素/插槽内存有界；控制台标题带项目名、脚本诊断含阶段/路径/行号/建议动作，
  GPU/场景/资源错误经 tracing 汇入控制台；
- **M11-06 实机 GUI/GPU 质量门**：G01 启动/场景加载/中文 SDF 渲染、G02 150% DPI、G03 resize、G04 Play/Stop；
- **M11-07 里程碑验收**：P0 全关、输入/缓存/恢复稳定、状态与代码一致，归档证据；
- **后续性能修复**（`cbbb09b`）：Game 预览帧率 24→50fps——根因是 `PREVIEW_FRAME_INTERVAL` 33ms 硬节流 +
  egui 与 60Hz vsync 对齐；修复为 16ms（60fps 节流），清理临时诊断保留轻量 fps 打点。

## 修改范围

- `engine/crates/editor/src/main.rs`（PlayState 状态机）、`panels/game_view.rs`（输入快照/帧边界/Play 启动门）、

- `engine/crates/engine/src/host/renderer.rs`（ReadbackSlot 状态机）、`host/runtime_scene.rs`（`scene_3d_with_camera`）、

- `editor/src/recovery.rs`、`panels/console.rs`（错误可见性/建议动作）。

## 验收标准

- Play 状态机：GPU 失败不进入 Playing；100 轮 Play/Stop 往返无编辑态漂移；
- 输入：按下边沿不跨 tick 重发；失焦/Play-Stop 清空防卡键；
- 缓存：回读失败清缓存并给用户可见错误；缓存 key 记录实际渲染尺寸；
- 提取统一：编辑器 3D 视图与运行时 drawables 一致，相机覆盖不改场景数据；
- 恢复/内存/错误：损坏文件可丢弃不碰主文件；FontAtlas 满后内存有界；控制台诊断含阶段/路径/行号/建议；
- 实机：G01 GUI/GPU PASS、G04 Play/运行态不写回 PASS；G02/G03 与 G04 Stop 真实点击待负责人。
