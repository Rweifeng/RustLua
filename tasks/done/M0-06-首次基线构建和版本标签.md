ACCEPTED

在 M0-01 至 M0-05 已完成的基础上，执行首次可复现基线构建，整理生成物和忽略规则，并创建 Git 标签 `v0.0.1-baseline` 作为后续开发的回滚点。

- [x] `.gitignore` 排除 Rust 构建目录和生成的发布产物；
- [x] Debug 质量门通过；
- [x] Release 质量门通过；
- [x] Release 运行器生成并可运行；
- [x] 基线变更已提交；
- [x] Git 标签 `v0.0.1-baseline` 已创建并指向基线提交；
- [x] 标签工作树状态干净；
- [x] 未把未授权计划副本或临时生成物加入基线。
