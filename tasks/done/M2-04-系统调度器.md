## 实施内容

- 新增 `engine_core::scheduler` 模块。
- 固定运行阶段：`Input`、`Script`、`Physics`、`Animation`、`Transform`、`Render`。
- 支持注册带名称、阶段、依赖和回调的系统。
- 使用拓扑排序校验依赖并生成确定性执行顺序；同阶段按注册顺序稳定执行。
- 拒绝重复系统、缺失依赖、跨越后续阶段的非法依赖和循环依赖。
- 执行每个系统时记录耗时，并汇总 `ScheduleReport`。
- 将系统返回错误包装为系统名和阶段上下文；捕获 panic 并转换为 `SystemPanicked`。
- 拒绝负数、NaN 和无穷大的调度 delta time。

## 主要 API

```rust
ScheduleStage::{Input, Script, Physics, Animation, Transform, Render}

System::new(name, stage, dependencies, callback)

Scheduler::new()
Scheduler::add_system(system)
Scheduler::execution_order()
Scheduler::run(&mut world, delta_seconds)

ScheduleReport::executed_systems()
```

## 设计边界

本任务实现的是单线程、确定性、阶段化调度器。当前不包含并行系统执行、读写资源访问声明、运行时动态增删系统、事件队列和 Command 队列；这些能力留给后续 M2 任务，在 API 需求和性能数据明确后再扩展。
