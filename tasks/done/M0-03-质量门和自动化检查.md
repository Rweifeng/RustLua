# M0-03 质量门和自动化检查

## 状态

ACCEPTED

## 目标

建立可重复的本地质量门、测试入口、Debug/Release 构建入口和 CI 检查，防止 AI 在未验证的情况下提交不可构建代码。

## 实施内容

- 创建统一 `verify.ps1`；
- 创建 `test.ps1`；
- 创建 `build-release.ps1`；
- 创建 `run-demo.ps1`；
- 创建 workspace Cargo 配置；
- 创建 Windows CI workflow；
- 更新 engine README；
- 记录任务和验收命令。

## 不做什么

- 不接入 wgpu、Lua、ECS、物理或编辑器；
- 不引入测试框架或外部运行时依赖；
- 不执行发布包安装器制作；
- 不将未运行的命令标记为通过。
