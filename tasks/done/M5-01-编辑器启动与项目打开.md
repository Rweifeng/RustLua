## 目标

新增独立 `editor` Cargo crate 和最小编辑器入口，能打开项目目录、检查项目结构并显示状态，同时提供无窗口检查入口供自动化验收。

## 输入

- `docs/00-project-charter.md`
- `docs/02-technical-decisions.md`
- `docs/24-M5编辑器MVP实施计划.md`

## 不做什么

不实现场景树、Inspector、资源浏览器、Gizmo、Undo/Redo；不修改场景格式；不把编辑器逻辑加入 `game_runner`；不删除或重命名资源。

## 实施条目

1. 在 workspace 新增 `editor` crate；
2. 锁定编辑器 UI 依赖版本，优先 `egui` + `eframe`；
3. 实现项目路径解析和结构检查；
4. 支持 `--project <path>`、`--check`；
5. 合法项目显示根目录、基线和关键目录状态；
6. 非法路径返回非零退出码和可读错误；
7. 增加单元测试、CLI 验收和使用说明。
