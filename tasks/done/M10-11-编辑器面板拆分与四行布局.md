# M10-11 编辑器面板拆分与四行布局

## 状态

ACCEPTED（代码与自动化验证）；真实 GUI 布局、DPI、resize 和长会话交互待专项实机确认。

## 目标

将编辑器从大体量单文件结构拆分为职责清晰的面板、状态和辅助模块，并落地四行布局，为后续编辑器功能迭代提供稳定边界。

## 背景

M10-10 的 `v0.10-editor` 标签覆盖编辑器强化基线和既有功能。随后编辑器继续进行模块化重构，提交 `0b781a6` 大幅拆分 `main.rs`，新增面板、动作、几何和状态模块。该增量需要独立记录，避免把后续代码误认为已包含在 M10-10 标签中。

## 输入

- `docs/28-编辑器强化实施计划.md`；
- `tasks/done/M10-10-编辑器验收与性能.md`；
- `v0.10-editor` 标签对应的 M10-10 提交；
- 当前 editor crate 及其面板模块。

## 不做什么

- 不改变场景文件格式；
- 不重新设计运行时渲染架构；
- 不把模块拆分本身描述为 GUI 交互或视觉验收；
- 不覆盖 M10-12 的 SDF 字体和编辑器优化改动。

## 技术方案

- 将编辑器主循环和状态协调保留在 `editor/src/main.rs`；
- 将 Header、Toolbar、Console、Hierarchy、Inspector、Resource Browser、Scene View、Game View 拆分到 `editor/src/panels/`；
- 将编辑器动作、几何命中、Inspector 状态、资源浏览器状态和场景树状态拆分为独立模块；
- 采用 Header/Menu、Console、左侧资源/层级、中央场景/Game、右侧 Inspector 的四行/分区布局组合；
- 通过现有 `history`、`document` 和状态模块维持编辑行为与 Undo/Redo 边界。

## 修改范围

主要对应提交 `0b781a6`：

- `engine/crates/editor/src/main.rs`；
- `engine/crates/editor/src/panels/`；
- `engine/crates/editor/src/actions.rs`；

- `engine/crates/editor/src/inspector_state.rs`；
- `engine/crates/editor/src/resource_browser_state.rs`；

- `engine/crates/editor/src/lib.rs`；
- `engine/crates/engine_core/src/logging.rs`；
- `docs/23-工程目录功能说明.md`。

## 验收标准

- editor crate 能通过 fmt、Clippy、workspace 测试和 Debug/Release 构建；
- 原有文档、场景树、Inspector、资源浏览器、Scene View、Game View 和 Console 的代码入口保持可定位；
- 面板职责不再全部集中在 `main.rs`；
- 四行/分区布局代码可追溯到 editor 主界面和 panels 模块；
- 当前自动化测试不出现回归；
- 真实窗口布局、DPI、resize、面板拖拽和长会话稳定性单独记录为待实机验收项。

## 风险

- 大规模文件拆分可能引入状态传递或事件路由回归；
- 面板之间共享的编辑器状态仍由主循环协调，后续新增功能需要遵守模块边界；
- 单元测试无法覆盖所有 egui 事件和真实窗口行为。
