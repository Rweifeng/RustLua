# M1-01 窗口与应用生命周期

## 状态

ACCEPTED

## 目标

创建 Windows 优先的最小窗口运行器，建立初始化、运行、暂停、退出和已退出状态，并处理关闭、缩放、最小化/不可渲染尺寸和恢复事件。

## 背景

M0 只有命令行运行器。M1-01 为后续 wgpu、Lua 和固定时间步提供稳定的应用事件循环，不在本任务中接入渲染器或脚本系统。

## 输入

- `docs/AI驱动RustLua游戏引擎实施计划.md` 中 M1-01 条目；
- M0 基线 Cargo workspace；
- `winit 0.30` 官方 API。

## 不做什么

- 不接入 wgpu、Surface、GPU 清屏；
- 不接入 Lua、ECS、输入快照或资源系统；
- 不实现编辑器窗口和多窗口管理。

## 技术方案

- 使用 `winit 0.30` 的 `ApplicationHandler` 和 `EventLoop`；
- 在 `engine_core::window` 中定义与平台无关的 `AppLifecycle` 状态机；
- 使用 `Resized` 和 `Occluded` 事件判定是否存在可渲染尺寸；宽或高为 0 时进入 `Paused`；
- `CloseRequested` 和 Escape 触发 `Exiting`，退出事件循环后进入 `Exited`；
- 通过标准输出记录窗口创建、生命周期变化、暂停/恢复和关闭顺序。
