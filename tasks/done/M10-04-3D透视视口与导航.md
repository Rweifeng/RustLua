# M10-04 3D 透视视口与导航

## 状态

ACCEPTED

## 目标

编辑器 3D 场景视图从 XZ 俯视平面升级为透视视口：编辑器轨道相机（中键轨道 / 右键平移 / 滚轮缩放）渲染编辑场景；平移 Gizmo 在透视视口内工作。这是对标 Unity/Godot Scene 视图的关键一步。

## 背景

M10-03 已实现离屏渲染（`Renderer::render_into_texture` + `copy_texture_to_cpu`）与内嵌游戏预览。M10-04 复用同一离屏渲染能力，用编辑器相机渲染当前编辑场景到 egui 纹理，替代 M9-03 的俯视平面视图。

## 输入

- `docs/28-编辑器强化实施计划.md`（M10-04）
- `docs/02-technical-decisions.md`（ADR-0013）
- `engine/crates/engine_host/src/renderer.rs`（离屏渲染）
- `engine/crates/editor/src/main.rs`（draw_scene_view_3d）

## 不做什么

- 不做多视口、编辑器相机书签；
- 不改变游戏内相机与运行行为；
- 俯视模式保留（View3D 模式现在是透视视口）。

## 技术方案

- `EditorCamera`（yaw/pitch/dist/target）编辑器轨道相机，与游戏相机分离（ADR-0013）；
- 编辑器字段：`scene_renderer`（离屏）、`scene_texture`、`scene_preview_tex`；
- `ensure_scene_renderer`（按视图尺寸重建离屏纹理）、`build_scene3d`（从编辑场景 Transform3D+MeshRenderer + 编辑器相机构建帧）、`render_scene_view`（渲染+回读+egui 纹理）、`project_to_screen`（世界→屏幕投影）；
- `draw_scene_view_3d` 重写为透视视口：中键轨道/右键平移/滚轮缩放导航；实体标记投影；点选；平移 Gizmo 投影 + 相机地面平面拖拽；
- 修复 `copy_texture_to_cpu` 的 `bytes_per_row` 256 对齐（任意宽度场景视图触发 wgpu 校验错误崩溃）。

## 修改范围

- `engine/crates/engine_host/src/renderer.rs`（copy_texture_to_cpu 对齐 + 去填充）
- `engine/crates/editor/src/main.rs`（透视视口）

## 验收标准

- 3D 场景视图为透视视口，轨道/平移/缩放导航可用；
- 平移 Gizmo 在透视视口内可拖拽移动实体；
- 俯视模式/2D 视图不回归；
- Debug/Release 质量门通过；任意视图宽度不崩溃。
