# M8-07 骨骼动画

## 状态

ACCEPTED

## 目标

导入 glTF skin、joint hierarchy 和 animation sampler/channel；GPU 蒙皮（joint palette 调色板）；先支持一个动画状态与循环播放；接入 Lua 查询/切换动画状态。

## 验收目标

- 动画时间推进、循环、暂停和非法关节引用有单测；
- Demo 中角色确实运动（KayKit CC0 骷髅战士播放 Idle/Running/攻击剪辑）；
- 停止/重启/切场景不残留旧动画状态；
- 自制蒙皮四边形 + 真实 CC0 角色 glTF 均能导入与播放。

## 实现

### glTF 导入（gltf_asset.rs，`IMPORTER_VERSION=gltf-m8-07`）

- `GltfPrimitive` 增加 `joints: Vec<[u16;4]>`、`weights: Vec<[f32;4]>`（JOINTS_0/WEIGHTS_0，二者必须成对）。
- `GltfNode` 增加 `skin`，bind 变换改为 TRS（translation/rotation/scale）。
- 新增 `GltfSkin { joints, inverse_bind_matrices }`、`GltfChannel { node, path, times, values, step }`、`GltfAnimation { name, channels }`。
- 支持 LINEAR/STEP 插值；cubic spline 与 morph target 明确拒绝。
- 单测：自制四边形（2 关节 1 通道）、KayKit 战士（95 剪辑 1 skin）导入与关键帧校验。

### 蒙皮网格（mesh3d.rs）

- `MeshVertex` 增加 `joints:[u32;4]`、`weights:[f32;4]`（64 字节）；非蒙皮顶点用 `[0;4]` + `[1,0,0,0]`（恒等骨通过）。
- `MeshPrimitive` 增加 `skinned` 标记；`MAX_BONES=128`。

### 动画运行时（animation3d.rs）

- `Animation3D` 组件：bind TRS 层级、skin joints + inverse bind、命名 clips、time/paused/looped。
- `joint_matrices()` 每帧计算 `global(joint) * inverse_bind(joint)` 调色板；`bind_palette()` 供 shadow 使用。
- `Animation3dDescriptor` 场景字符串：`mesh=<path>;clip=<name>;looped=true|false`。
- 单测：推进/循环/钳制、暂停冻结、切剪辑重启、非法剪辑/非蒙皮资产拒绝、调色板 bind pose 恒等。

### Lua（script.rs）

- `instantiate_scene` 解析 `Animation3D` 组件（先设 project_root 再实例化）。
- 新增 `animation3d` 模块：`get`（当前剪辑）、`set`（切换）、`list`、`paused`、`set_paused`、`time`。
- 宿主每帧 `advance` 3D 动画；场景切换重置世界即无残留。

### game_runner（GPU 蒙皮）

- MESH3D/SHADOW shader 增加 `joint_palette` uniform 与蒙皮顶点分支（material.surface.z 标记）。
- 材质 bind group 增加 palette 绑定（128×mat4）；静态网格绑恒等 palette。
- `Scene3dDrawable.palette` 每帧从 `Animation3D.joint_matrices()` 取，材质 uniform 上传。

### Demo

- `game/scenes/main.scene` 增加 `SkeletonWarrior`（MeshRenderer + Animation3D clip=Idle）。
- `demo3d.lua` 每 6 秒经 `animation3d.set` 切换剪辑（Idle→Running_A→攻击→Idle）。
