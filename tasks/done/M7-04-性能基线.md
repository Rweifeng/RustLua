# M7-04：性能基线

- 状态：ACCEPTED（待 M7 里程碑汇总验收）
- 验收日期：2026-08-22
- 前置任务：M7-03

## 目标

建立可跨版本对比的性能基线：ECS 压力 + 精灵批处理吞吐 + Release 稳定性。

## 实施

- `engine_core/examples/sprite_stress.rs`：无窗口 SpriteBatch CPU 基准（1000 精灵 push/build 吞吐）；
- `scripts/bench.ps1`：运行 `ecs_stress`（10000 实体，可配置秒数）+ `sprite_stress`，结果归档到 `docs/acceptance-evidence/m7/`；
- 复用现有 `ecs_stress`（JSON 压力报告）。

## 验收结果

- **ECS 基线（60 秒）**：`ecs-stress-60s.json`：10000 实体 / 60005ms / final=min=max=10000（无泄漏、无崩溃）；
- **精灵批处理（1000 精灵）**：`sprite_stress_ok sprites=1000 push_ms=0.024 build_ms=0.199 vertices=6000 draw_batches=8`；
- 快速冒烟：10 秒 ECS 报告同样稳定；
- 基线数据归档 `docs/acceptance-evidence/m7/`，可跨版本对比。

## 证据

- `docs/acceptance-evidence/m7/ecs-stress-60s.json`、`ecs-stress-*.json`、`sprite-stress-*.txt`
