# M10-05 2D 场景视图实时渲染

## 状态

ACCEPTED

## 目标

2D 场景面板从「色块占位」升级为实时渲染编辑场景（精灵/图块/文本），与 3D 透视视口一致。

## 背景

M10-03/04 实现了离屏渲染 + 3D 透视视口。M10-05 复用同一离屏渲染能力渲染 2D 场景（编辑场景，不跑游戏脚本）。

## 技术方案

- `RuntimeScene::from_scene_edit(project_root, scene)`：实例化场景但不执行 main.lua（渲染编辑态，无游戏逻辑）；
- `RuntimeScene::set_camera_2d`：编辑器可设置 2D 相机，匹配编辑器 pan/zoom；
- 编辑器 `scene_runtime`（当前编辑场景的 2D 运行时）+ `render_scene_view_2d`（构建 SceneMesh → 离屏渲染 → egui 显示）；
- 2D 场景视图背景改为实时渲染场景；实体只画选中轮廓 + 名称；
- 修复：`ensure_depth_view` 尺寸 clamp ≥1（空尺寸面板崩溃）；`copy_texture_to_cpu` 256 对齐（M10-04）。

## 修改范围

- `engine_host/src/runtime_scene.rs`（from_scene_edit / set_camera_2d）
- `engine_host/src/renderer.rs`（ensure_depth_view clamp）
- `engine/crates/editor/src/main.rs`（2D 场景实时渲染）

## 验收标准

- 2D 场景面板显示真实渲染的精灵/图块/文本；
- pan/zoom 作用于渲染视图；选中实体有轮廓；
- 空尺寸/任意宽度不崩溃；质量门通过。
