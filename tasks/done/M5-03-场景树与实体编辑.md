# M5-03：场景树与实体编辑

## 状态

- 状态：DONE
- 依赖：M5-02
- 开始日期：2026-08-21
- 完成日期：2026-08-21

## 目标

在编辑器文档模型之上提供可测试的场景树状态和实体编辑能力：显示实体名称、ID、父子关系；支持单选、创建、删除子树、重命名和设置父节点；编辑后同步 dirty 状态。

## 实施范围

- 新增 `SceneTreeState`，维护当前选择和树操作；
- 使用 `engine_core::Scene` 的实体和父子关系，不改变 M4 场景格式；
- 所有成功编辑操作标记 `SceneDocument.dirty=true`；
- 非法实体 ID、重复名称不作为错误，重复 ID、缺失父节点、循环父子关系明确拒绝；
- 删除实体时删除整个子树，并清理父节点 children；
- GUI 提供最小场景树和编辑按钮，后续 M5-04 再接入 Inspector。

## 验收方案

```powershell
cargo fmt --manifest-path engine/Cargo.toml --all -- --check
cargo clippy --manifest-path engine/Cargo.toml --workspace --all-targets --all-features -- -D warnings
cargo test --manifest-path engine/Cargo.toml --workspace --all-features
cargo build --manifest-path engine/Cargo.toml --workspace
cargo build --manifest-path engine/Cargo.toml --workspace --release
git diff --check
```

验收标准：

- 创建、重命名、删除、设置父节点后树结构正确；
- 删除父实体会删除完整子树；
- 选择无效 ID 返回明确错误，选择有效实体可读取；
- 不能设置自身或后代为父节点；
- 成功编辑后场景 dirty；
- 保存并重新加载后名称和父子关系一致；
- editor 与 engine_core 全量质量门通过。
