### 本轮增量：候选审阅面板 + 切图入口 + 图集页体积（2026-10-24）

- **候选图条**（`editor/src/panels/ui_studio.rs`）：`UiStudio::asset_candidates()`
  把「已登记 `assets[]`」与「只有 provenance 边车」的候选按 key 合并；面板横向缩略图条
  直接解码 `assets/generated/ui/<key>.png`（缺图显式占位），点击切换详情。
- **来源详情与人工审阅**：展示 source/provider/model/seed/prompt 前缀/许可/审阅状态/
  `used_by`；许可输入框按候选回填；「标记已审阅」调 `UiStudio::review_asset`
  写 `ui/provenance/<key>.json`。生成候选**不必先登记进 `assets[]`** 就能审阅
  （`promote_asset` 放行已有边车）；不重填许可时保留旧值，只更新 `reviewed`。
- **切图表单**：源图 + 输出目录 + 逐行 `name,x,y,w,h`（空行/`#` 注释跳过），
  解析失败在生成任何文件前拒绝；成功后提示 `slices.json` 与源尺寸。
- **资产缓存**：审查要装箱图集并扫全工程，面板不能每帧跑；按 Studio revision 缓存
  candidates + error/warning/字节数，审阅/切图成功或点「刷新」后失效。
- **图集页级体积**：`UiSpecStore::atlas_page_costs` 用 `atlas.json` 真实装箱
  （`collect_png_files` → `plan_pages` → 按页 `format` 编码）得到 `(页 id, region) →
  页字节`；`AssetEntry.atlas_page` 让同一页被多个区域引用时只计一次，总包与
  `max_atlas_bytes` 都按页算。页 id 用 `sanitize(spec_name)-index`，与 cook 写出的
  `.atlas` 文件名同源（首版按未清洗的 spec 名做键，区域引用查不到页成本，测试抓出后修正）。
- **区域引用不重复计单件**：`asset_details` 对 `...#region` 不再把 `.atlas` 本体长度
  当单件体积；查不到页成本时记「未知」而不是错算。

### 已交付

- **AssetPlan 校验**（`rustlua-ui-spec/src/asset.rs`）：key 为空、`path`/`generate`
  同时给或都不给、prompt 为空、variants=0、九宫格边距和 ≥ 尺寸，全部是 error。
- **来源门 + 体积门**（同文件）：`review_assets(entries, limits)` 产出
  `AssetReviewReport`；缺 provider/model/prompt_hash = error，缺 license/未 reviewed =
  warning，未审阅且被引用 = error；单件/图集页/总包超限 = error；生成资产全部进
  `generated` 清单。体积门与来源解耦（人工导入的图同样计入）。默认上限 4/16/64 MiB。
- **出图 Provider**（`rustlua-editor-ai/src/image_provider.rs`）：
  - `LocalImageProvider`：由 prompt+尺寸+种子哈希出确定性棋盘格 PNG，离线、无需密钥；
  - `RemoteImageProvider`：OpenAI 兼容 `/images/generations`，密钥只从
    `RUSTLUA_AI_IMAGE_API_KEY`（或宿主注入的 `key_source`）读取，不存字段、`Debug` 脱敏；
    `max_attempts` + `retry_delay_ms` 覆盖 429/5xx/传输失败，4xx 不重试；只接受内联
    `b64_json`，只给 URL 的结果直接拒绝（不代下载模型给的链接）；
  - 录制/回放沿用 `RecordingImage` / `ReplayImage`（M76-01 已有）。
- **切图**（`rustlua-ui-spec/src/slice.rs`）：等分/网格、手框（边界+重名校验）、
  透明边界连通块（4 邻接、可扩 padding）、九宫格 9 区域；区域顺序按 (y,x) 稳定。
  `slice_rgba` 在纯数据半边裁像素，保证「屏幕上量到的区域」与「写出去的文件」同一套边界。
- **切图落盘**（`ui_spec_host::slice_asset` + `rustlua-assets-import::decode_png_rgba`）：
  读源 PNG → 解码 RGBA8 → 裁像素 → 写 `{output_dir}/<name>.png` + `slices.json`（源尺寸、
  每块 rect/字节数、工程内相对路径）。清单最后写；中途 IO 失败会删掉本次新建的文件，
  不留「清单说有、磁盘没有」的半套产物。文件名走 `sanitize_asset_key`，清洗后重名直接拒绝
  （否则两块会互相覆盖）；源图/输出目录都必须限制在工程内。
- **出图落盘**（`editor/src/ai_host.rs` + `ui_spec_host.rs`）：`ui_generate_assets`
  校验计划 → 调 Provider → 写 `assets/generated/ui/<key>.png` → 写 provenance
  （`reviewed=false`，provider/model/prompt_hash/seed）；默认本地 Provider，
  `RUSTLUA_AI_IMAGE_PROVIDER=remote` 才联网；单次张数默认上限 4，超限拒绝不截断。
- **切图 tool**（`rustlua-editor-ai/src/ui_tools.rs` + `surface.rs` + `editor/src/ai_host.rs`）：
  `ui_slice_asset`（T2）接手工矩形列表 → `UiSpecStore::slice_asset`，返回源尺寸与每块
  `name/path/rect/bytes`。与 `ui_generate_assets` 共用 tier 确认门与 MCP 通道；

- **审阅与发布门接口**：`UiSpecStore::review_assets` 跨文档按 key 合并引用（节点上的

  `reviewed=true` 才写边车。
- **工程级发布门**（`editor/src/review.rs::review_project` +

切图落盘的反面对照（`ui_spec_host::tests::slice_asset_rejects_bad_inputs_without_writing_anything`）：
越界区域 / 清洗后重名 / 空区域 / 源图逃出工程 / 输出目录逃出工程 → `InvalidArgument`；
源图不存在 → `NotFound`；非 PNG 内容 → 解码失败，且输出目录不会被创建。正向用例断言：
裁出的 PNG 字节等于源图对应行的重编码结果、`slices.json` 可反序列化且逐项字节数对得上、
同输入重跑清单与文件字节完全一致。

反面对照（都写成断言）：未审阅被引用 → `asset.unreviewed_used`；单件/图集/总包超限 →
三个 error 同时出现；九宫格边距和 ≥ 尺寸 → `asset.nine_slice_margins`；远程 provider 缺
密钥 → `image.key_missing`；只给 URL → `image.remote_url_unsupported`；4xx 只尝试 1 次、
5xx 重试 2 次成功。工程门额外跑了两条真实反面对照（临时改示例工程、跑完原样恢复）：
删掉资产文件 → 门 exit 101、`error 1`；把 provenance 改成 generated + 未审阅 →

本轮新增反面对照：候选审阅 `ui/missing`（既无 `assets[]` 登记也无边车）→ `NotFound`；
只更新审阅不重填许可 → 旧许可保留；`read_asset_bytes` 对 `../`、空串、绝对路径都返回
`None`；切图行少列/负数/缺名字 → 解析错误且不写文件；图集页 id 首版用未清洗的

## 未完成项 / 已知限制

- **审阅面板是列表条不是大图切换**：缩略图 48×48、详情是文字字段；没有放大/对比视图，
  也没有「多候选选一」的自动重命名与登记动作（切完/审完仍要人工把产物写进 `assets[]`）。
- **资产缓存靠 revision + 手动刷新**：面板只在 Studio revision 变化、审阅/切图成功或点
  「刷新」时重算；工程文件被外部会话改动时需手点刷新。
- **图集只算体积、不写盘**：页装箱与编码复用 `atlas_plan`（与 cook 同源），编辑器只读取
  结果算体积；真正产出 `.atlas`/页图仍由 `assetc cook` 对打包产物执行。同输入同字节由
  既有图集门负责，本轮没有重跑那条门。
- **远程 provider 未做真实服务活体测试**：无密钥、无外网出口，只测脚本化 transport；
  超时上限透传 curl，但没有实测“超时确实中断”。
- **系统密钥库未接**：只支持环境变量与宿主注入 `key_source`。
- **发布门只挡 error**：warning（例如无 provenance 的人工资产缺许可）会打印条数但不阻断；
  三宿主未测固定按 3 项/文档输出，不参与 `is_green`。

## 目标

打通「意图 → AssetPlan → 出图 → 审阅 → 切图/九宫格 → 图集 → `assets[]` 登记 → Spec 引用」，
每个生成资产带 `AssetProvenance`，体积与许可进发布门。

## 交付项

1. **AssetPlan**：角色、尺寸、风格令牌、九宫格需求、预算、key 稳定。
2. **ImageProvider**：本地/远程/录制三种；密钥只读环境变量/系统密钥库；重试与超时上限。
3. **审阅**：候选图网格、许可/模型/种子展示；未审阅不可提升。
4. **切图**：等分/透明边界/网格/手框；产物区域清单与九宫格边距校验（和 < 尺寸）。
5. **图集**：复用现有 atlas 管线；同输入同字节；`atlas#region` 引用可解析。
6. **provenance 门**：缺 provider/model/prompt_hash = error；缺 license/未 reviewed = warning；
   发布清单包含全部生成资产。
7. **体积门**：单图/图集/总包上限，超限阻断发布。

## 风险

- 外部图像 API 不稳定/成本：默认禁用，测试全走录制；预算与人工逐项确认。
- 许可与训练来源不可核：只记录声明，不替用户做法律判断；发布清单暴露风险。
- 图集重新打包可能改字节：必须走现有可复现门，不手改缓存。
