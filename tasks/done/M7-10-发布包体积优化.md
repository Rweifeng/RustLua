# M7-10：发布包体积优化（Phase 1-3、5）

- 验收日期：2026-08-22
- 前置任务：M7-09（压缩加密）、M7-01

## 目标

执行体积优化方案 Phase 1-5（Phase 4 压缩/加密已完成于 M7-09）：字体子集化、exe 瘦身、音频压缩、发布包裁剪。

## 实施与效果

| Phase | 措施 | 前 | 后 | 节省 |
|---|---|---|---|---|
| 1 字体 | `scripts/subset-font.py`（fonttools）把 NotoSansSC 子集化为游戏字符集（268 中文+ASCII+标点，387 字符） | 17.4MB | **0.24MB** | -98.6% |
| 2 exe | `[profile.release] opt-level="s" + lto="fat" + codegen-units=1 + strip`（不启用 panic=abort，保留崩溃日志） | 10.6MB | **7.5MB** | -3.1MB |
| 3 音频 | `wav2ogg` 示例（`vorbis` crate）bgm.wav→bgm.ogg（96kbps） | 1.0MB | **0.09MB** | -91% |
| 5 裁剪 | 发布包移除 assetc.exe（仅运行器 + pack + 文档） | 0.5MB | 0 | -0.5MB |

发布包总大小预计：~30MB → **~8MB**。

## 验证

- 子集字体 `CJK font atlas ready` 正常，游戏运行无报错；
- bgm.ogg `music started` 正常；
- 加密发布包 Release 运行（脚本/场景/require 解码成功）；
- 目录隔离自测通过（后台打包完成后确认）。

## 风险与说明

- 子集字体仅含游戏脚本中出现的中文字符；后续新增中文显示需重跑 `subset-font.py`；
- LTO + codegen-units=1 使 Release 构建变慢（约 4 分钟），属预期；
- 未启用 `panic=abort`（避免影响崩溃日志/回溯）。
