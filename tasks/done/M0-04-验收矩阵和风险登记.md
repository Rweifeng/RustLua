# M0-04 验收矩阵和风险登记

## 状态

ACCEPTED

## 目标

建立可持续维护的验收矩阵和风险登记表，明确每项工作如何验证、当前状态如何表达，以及项目风险如何跟踪和复查。

## 实施内容

- 修复并统一验收矩阵编码；
- 补充验收状态定义；
- 补充 M0-04 文件完整性验收项；
- 修复并统一风险登记表编码；
- 增加触发条件、负责人和复查时间；
- 增加工具链和文档编码风险；
- 记录 M0-04 验收结论。

## 不做什么

- 不执行 cargo、Rust 编译或 CI 命令；
- 不将 M0-02/M0-03 当前的工具链阻塞标记为通过；
- 不修改 Rust 代码、Cargo 配置或质量门脚本；
- 不关闭仍然存在的工程风险。

## 验收标准

- [x] `docs/04-acceptance-matrix.md` 使用正确 UTF-8 中文；
- [x] 验收矩阵包含 ID、功能、前置条件、操作、预期结果、自动化测试、证据、状态和版本；
- [x] 验收矩阵区分 PASS、BLOCKED、PENDING 和 FAIL；
- [x] M0-04 有独立的文件完整性验收项；
- [x] `docs/05-risk-register.md` 使用正确 UTF-8 中文；
- [x] 风险表包含概率、影响、应对策略、触发条件、负责人、状态和复查时间；
- [x] 当前 Rust 工具链阻塞已登记；
- [x] 当前文档编码风险已登记；
- [x] M0-04 验收结论已写入文档。
