# M10-06 组件增删

## 状态

ACCEPTED

## 目标

Inspector 支持添加/移除组件（Transform3D、MeshRenderer、Camera3D、Light、Collider3d、Sprite、LuaScript 等），经 history 可撤销；组件顺序（BTreeMap 键序）保持现状，重排留待格式变更。

## 背景

阶段二 P1 第一项。当前 Inspector 只能编辑已有组件，无法添加/移除。对标 Unity/Godot Inspector 的组件管理。

## 输入

- `docs/28-编辑器强化实施计划.md`（阶段二）
- `engine/crates/editor/src/main.rs`（draw_inspector_panel）
- `engine/crates/editor/src/inspector.rs`（set_* / clear_*）

## 不做什么

- 不做组件重排（BTreeMap 键序格式限制，需场景格式变更）；
- 不做组件属性级模板/预设。

## 技术方案

- Inspector 顶部「添加组件」ComboBox（Transform3D/Camera3D/Light/Collider3d/MeshRenderer）+ 按钮；
- Sprite/LuaScript 通过已有文本编辑 + Apply 添加；
- 各组件区块加「移除」按钮；
- `add_component`/`remove_component` 经 `history.execute`（CommandKind::Property）可撤销。

## 修改范围

- `engine/crates/editor/src/main.rs`

## 验收标准

- 可添加/移除组件（默认值），撤销/重做正确；
- 保存重开一致；质量门通过。
