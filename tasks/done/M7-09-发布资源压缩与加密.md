# M7-09：发布资源压缩与加密（面板勾选，默认开启）

- 状态：ACCEPTED（待 M7 里程碑汇总验收）
- 验收日期：2026-08-22
- 前置任务：M7-08（发布进度面板）、M7-01（assetc）

## 目标

发布打包时对游戏资源（Lua/场景）压缩 + 加密，作为编辑器发布面板的勾选项配置，默认勾选。

## 实施

- `engine_core/pack.rs`：`P2PK1` 头 + 标志 + nonce + payload；`encode`（gzip 压缩 + chacha20poly1305 加密）与 `decode`（自动检测，明文原样返回）；
- **运行时解码**：`Scene::load`、`script.rs` 读取 Lua 源码（`read_project_script`）、require 模块（自定义 searcher 读字节→解码→编译）均支持压缩/加密文件；开发明文与发布加密包同用一套代码；
- **assetc**：`package --compress --encrypt` 对 Lua/场景编码；
- **package.ps1**：`-Compress`/`-Encrypt` switch 透传 assetc；
- **编辑器**：发布区「压缩」「加密」勾选框（默认勾选）→ `-Compress -Encrypt` → package.ps1；发布进度面板沿用 M7-08。

## 验收结果

- 加密包（`--compress --encrypt`）构建成功，`main.lua` 头为 `P2PK1`；
- 加密发布包用 Release 运行时加载：`project script loaded` + `scene 'main'` + BGM 正常（脚本/场景/require 模块全部解码成功）；
- fmt/clippy/workspace 测试全过（含 pack 编解码、加密项目+require、发布/导入端到端）；
- 发布包自测（目录隔离 `--check`）通过。

## 说明与限制

- 压缩/加密作用于 Lua 与场景（文本类）；PNG/OGG 等媒体已自带压缩，不重复处理；
- 当前游戏包体 30MB 主要来自字体（NotoSansSC 17MB，见优化方案 Phase 1 字体子集化）与 exe（10.6MB，Phase 2 strip/LTO）——两项为独立优化，未含在本任务；
- 密钥内嵌 exe，客户端加密的固有局限是密钥可被提取（仅提高门槛）。
