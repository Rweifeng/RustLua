# M3-01 坐标约定

## 状态

- 状态：PASS
- 完成日期：2026-08-20
- 前置任务：M2 里程碑 `v0.2-ecs`

## 实施结果

- 新增 `engine_core::math2d` 模块；
- 固定右手世界坐标：X 向右、Y 向上；
- 固定左上角原点屏幕坐标：X 向右、Y 向下；
- 实现 `Viewport`、`Camera2D` 世界/屏幕坐标互转；
- 固定世界单位约等于米，zoom 表示像素/世界单位；
- 实现标准 sRGB 与线性 RGB 转换，alpha 保持线性；
- 固定颜色纹理使用 sRGB 语义，法线/材质数据纹理使用线性语义；
- 补充 API 文档与单元测试。

## 边界

M3-01 不实现 PNG/JPEG 解码、wgpu 纹理创建或屏幕颜色测试图；这些能力属于后续渲染任务。M3-02 及之后必须复用本任务的坐标和颜色语义。
