# M10-13 质量门与编辑器实机证据

## 状态

PENDING（自动化质量门已补强；真实 GUI/GPU 证据需负责人使用 Windows 实机归档）

## 目标

补齐 CI 与本地质量门的工程/资源完整性检查，并为编辑器真实窗口的 GUI/GPU、DPI、resize、Play/Stop 验收提供可复核记录格式。

## 修改范围

- `.github/workflows/quality.yml`：扩大 `game/**`、`docs/**`、`tasks/**` 触发范围，增加 `git diff --check`、`game_runner --check`、`editor --check`。
- `scripts/verify.ps1`：本地复用同一组根目录检查。
- `scripts/build-release.ps1`、`scripts/package.ps1`：发布包复制并验证 `fonts/NotoSansSC-VF.ttf`，修正文档元数据。
- engine 资源测试：字体、真实模型和 `ui_test.scene` 缺失时失败，不再静默跳过。
- `docs/acceptance-evidence/m10/m10-13-quality-and-gui-evidence.md`：人工证据规范。

## 验收标准

1. `git diff --check`、workspace fmt/clippy/test、Debug/Release 构建通过。
2. 游戏项目和编辑器 `--check` 在 CI 与本地入口均执行且失败可阻断流水线。
3. 发布包包含非空 `fonts/NotoSansSC-VF.ttf`，隔离目录自测通过；缺失字体时明确失败。
4. 字体、模型和 UI 场景资源缺失时测试失败，而非输出 skip 后通过。
5. GUI/GPU、100%/150% DPI、resize、Play/Stop 的原始截图/录屏/日志按证据文档归档后，才可将 M10-A13 标记为 PASS。

## 验证命令

```powershell
git diff --check
./scripts/verify.ps1 -KeepLog
./scripts/build-release.ps1
./scripts/package.ps1 -SelfTest
```

真实窗口证据保存到 `artifacts/acceptance/m10-13/<case>/`，并在证据文档中填写环境、commit、GPU/driver、DPI、窗口尺寸和结论。
