# M6-00：运行时场景实例化与玩家移动

- 状态：ACCEPTED
- 验收日期：2026-08-21
- 所属里程碑：M6 2D 游戏能力与样板游戏
- 前置任务：M5 编辑器 MVP（v0.5-editor-mvp）

## 目标

让 `game_runner --project <game>` 打开窗口后，场景中的玩家实体可见且可用 WASD 移动；移动由 `game/scripts/main.lua` 通过现有 `transform`/`input` Lua API 驱动；`scenes/main.scene`、渲染世界、Lua 脚本世界三者合一。这是通往 M6 样板游戏（俯视角 Roguelite）的第一块地基。

## 背景

此前 `game_runner` 只渲染一个写死的蓝色方块；`scenes/main.scene` 的实体**没有实例化进 ECS World**；Lua 脚本操作的是 `ScriptState` 内部一个独立且不渲染的 World（`engine_core/src/script.rs`），与渲染世界完全断开。`game/scripts/main.lua` 只打印日志，WASD 输入无人消费。

## 输入

- `engine/crates/game_runner/src/main.rs`（运行时主循环）
- `engine/crates/engine_core/src/script.rs`（Lua 运行时）
- `engine/crates/engine_core/src/transform.rs`（Transform 组件）
- `game/project.toml`、`game/scenes/main.scene`、`game/scripts/main.lua`

## 不做什么

- 纹理渲染（用纯色四边形代替，red-1x1 视觉等价）
- Tilemap、物理碰撞、动画、UI/音频/存档
- 编辑器 Game 视图重做（编辑器 Play 维持现状）
- 场景格式改动

## 技术方案

1. **共享 World**：`LuaRuntime` 保持 `ScriptState.world` 所有权，新增 `with_world`/`with_world_mut` 让宿主（渲染器）读写同一 World。不改动任何 Lua API 闭包，风险最小。
2. **场景→World 实例化**：`LuaRuntime::instantiate_scene(&Scene)` 遍历场景实体，用 `Transform::from_component_str` 解析 Transform 组件字符串并插入 World，有 Sprite 组件的实体插入默认 `Sprite`（128x128，按实体顺序取自 6 色调色板以区分），并把实体名登记进 `names` 表（`entity.find` 可命中）。
3. **渲染**：`RuntimeScene` 重构为持有 `LuaRuntime` + `SpriteBatch` + `Camera2D`，`vertices()` 用 `with_world` 遍历 `entities_with2::<Transform, Sprite>` 生成彩色四边形，复用现有 SpriteBatch→OverlayVertex 管线。
4. **玩法**：`game/scenes/main.scene` 实体 2 命名 Player 并加 Sprite；`main.lua` 每帧读 `input.axis("horizontal"/"vertical")`（D−A、W−S）乘以速度与 dt，`transform.move` 驱动玩家。
5. **可观测**：`run_script_steps` 记录每帧 update 返回值（含玩家位置）；`game_runner` 新增 `--log-filter` 参数便于验收调试。
6. **引擎单独模式**：无 `--project` 时诊断场景实体补上 Transform/Sprite，保持 M1 单精灵显示。

## 风险与应对

| 风险 | 应对 |
|---|---|
| Lua 脚本世界与渲染世界不同步 | 单 World 共享，`with_world` 只读渲染，脚本更新与渲染顺序执行无并发借冲突 |
| `transform.move` 语义（直接加位移，不乘 dt） | main.lua 内自行乘以 `speed*dt`；headless 测试固定 |
| 场景 Transform 字符串损坏 | `Transform::from_component_str` 严格校验并返回明确错误 |
| 编辑器 Play 未接入真实运行循环 | 明确为非目标，后续迭代处理 |

## 已知限制

- Sprite 渲染为纯色四边形（纹理渲染未做），颜色取自固定调色板而非资源
- 场景 Sprite 组件的纹理引用暂未用于渲染
- 编辑器 Play 视图仍是占位，运行游戏请用 `game_runner --project`
- `transform.move` 由脚本自行乘 dt，引擎 API 语义是"直接位移"
