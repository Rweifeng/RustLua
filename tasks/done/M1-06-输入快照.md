# M1-06 输入快照

- 状态：`ACCEPTED`
- 完成日期：2026-08-20
- 里程碑：M1 基础运行时

## 目标

将平台窗口事件转换为可被固定逻辑帧读取的输入快照，避免游戏逻辑直接依赖 winit 事件时序。支持键盘、鼠标、光标和焦点状态，并通过 Lua 暴露稳定查询 API。

## 实现范围

- 新增 `engine_core::input::InputSnapshot`、`InputKey` 和 `MouseButton`；
- 键盘与鼠标分别维护 held、just_pressed、just_released 三类状态；
- `W/A/S/D` 提供 `horizontal`、`vertical` 两个轴值；
- 记录光标位置和累计移动量；
- 快速按下/释放会保留到逻辑帧消费，不因高渲染帧率丢失；
- 窗口失去焦点或进入暂停时清空输入状态，避免恢复后卡键；
- Lua API：`input.is_down`、`input.just_pressed`、`input.just_released`、`input.axis`、鼠标查询和光标查询；
- game runner 接入 winit `KeyboardInput`、`MouseInput`、`CursorMoved`、`Focused` 事件。
