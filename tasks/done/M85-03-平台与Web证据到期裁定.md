## 目标

在 2026-12-31 之前对两处"有到期日的受限登记"做出**有理由的裁定**（升档 / 换 runner / 带理由改期），
并补上"**到期机制自己不会被绕过**"这个洞：让矩阵门对"绿着但过期"的 advisory cell 也判红，
且让到期裁定有一个**自动执行入口**（现在只有本地手工 `-Check`）。

## 背景与证据

### 1. Web 运行时证据：BLOCKED 且 2026-12-31 到期

[web-evidence.json](../../metrics/web-evidence.json)：

- `status=blocked`、`since=2026-11-16`、`review_by=2026-12-31`、owner `M83-04`；
- 原因：**CI runner 无可用硬件 WebGL2**——无头 Edge 只报 `gpu=initializing`；强制 SwiftShader 后
  产物层可过，但 render-probe 在 `glTexStorage3D` 处被拒（wgpu 缺所需能力）；
- 登记里已写明三条解锁条件：①换有 GPU/硬件 WebGL2 的 runner；②SwiftShader/软件光栅能通过能力预检；
  ③渲染器降到软件 WebGL2 可承载（需渲染设计评审）；
- 门：[check-web-evidence-policy.mjs](../../scripts/verify/check-web-evidence-policy.mjs) 在
  `blocked && 过期` 时判 2，CI 的 `lint` job 已跑 `--check` + `--self-test`
  （[quality.yml:136-140](../../.github/workflows/quality.yml#L136)）⇒ **这条到期会真的变红**。

### 2. 四个 advisory 矩阵 cell：同为 2026-12-31 到期

[promotion.json](../../metrics/promotion.json)：`linux-native` / `linux-wasm` / `macos-native` / `macos-wasm`
四条 `tier=advisory, experimental=true, owner=P4, review_by=2026-12-31`。
晋升条件写在 registry comment 与 [M83-04](../../tasks/done/M83-04-跨平台与浏览器运行时验证升级.md)：
**连续 2 次 main 绿 + 无 flaky 记录 → `experimental=false` 并写理由**。

### 3. 到期机制有两个洞（比到期本身更该修）

[check-matrix-policy.ps1](../../scripts/verify/check-matrix-policy.ps1)：

- **洞 A：CI 路径只对"红 + 到期"判 2。**
  `-Summarize` 分支里（[:52-57](../../scripts/verify/check-matrix-policy.ps1#L52)）只有
  `$r -ne "success"` 的 advisory 才会进入 `$advisoryRedExpiring`；**绿着但过期**的 cell 不会红。
  而脚本头 [:4](../../scripts/verify/check-matrix-policy.ps1#L4) 自己写的判据是
  "到期仍 advisory/红 -> 判 2"——即**到期仍处 advisory 就该红**，与实现不一致。
- **洞 B：能判"绿 + 到期"的 `-Check` 没有任何自动化入口。**
  `-Check`（[:73-98](../../scripts/verify/check-matrix-policy.ps1#L73)）实现是对的（对全部 advisory 判到期），
  但全仓无人调用：CI 只走 [`matrix.yml:190`](../../.github/workflows/matrix.yml#L190) 的 `-SummarizeFile`；
  `verify.ps1` 里没有 `check-matrix-policy` 引用。
- 后果：2026-12-31 之后如果四个 cell 都绿，**CI 不会红**——"到期由机器强制"的口径落空，
  这条到期就变成靠人记。

## 动作拆分

1. **先决定 web 证据的处置（三选一，写进 §实现记录）**
   - **A（推荐，若能拿到环境）**：换有硬件 WebGL2 的 runner（或本地/云 GPU 机）跑
     `verify.ps1 -Web` 与 `verify-webgl-bundle.ps1`，取得 `boot=ok` + 帧/像素证据后
     把 `status` 改 `ok`、删 `blocked` 段、`review_by` 置空。
   - **B（推荐，若 12 月拿不到环境）**：明确改期（例如 `2027-03-31`），**同时**写清
     "这 3 个月做什么、由谁做"（对应 `unblock_conditions` 中的哪一条），并在
     [docs/70](../../docs/70-性能与测试度量.md) 登记这条受限项；不允许只改日期。
   - **C（不推荐）**：把 Web 运行时证据移出质量门——与 README/docs/32 的宣称冲突，
     需要负责人书面裁定后才能做。
   - 验收：`node scripts/verify/check-web-evidence-policy.mjs --check` 通过；
     `--self-test` 通过；json 的 `updated/owner/reason` 与新状态一致。

2. **裁定四个 advisory cell**
   - 取最近 2 次 `main` 上 `matrix` 的真实结论（M85-02 会把 CI 证据补齐）；
   - 若两轮绿且无 flaky：`experimental` 改 `false`，`reason` 写"连续 2 次绿 + 无 flaky（run 链接）"，
     `review_by` 置空（或改成下次评审日）；
   - 若仍有红/不稳定：**带理由改期**，`reason` 必须写清失败现象与下一步；不允许"日期一改了事"。
   - 验收：`pwsh scripts/verify/check-matrix-policy.ps1 -Check` exit 0；
     `-List` 输出 cell 数与档位正确。

3. **补洞 A：`-Summarize` 对"绿 + 到期"也判红**
   - 在 `-Summarize` 分支为**所有** advisory cell 计算到期（不限于 `$r -ne "success"`），
     单独累加 `$advisoryExpired`，命中即 `exit 2` 并打印
     `"[RED] advisory cell … 观察期已过（review_by=…）仍为 advisory"`；
   - 保留现有"红 + 到期"信息，避免把"红"和"过期"混成一条；
   - 验收：用 `-SummarizeFile` 喂一份全 success 且把某条 advisory 的 `review_by` 改成昨天
     （用临时 `promotion.json`，见动作 4）时，脚本 exit 2。

4. **补洞 B：给 `-Check` 一个自动入口 + 可测入口**
   - 给脚本加一个测试用参数（如 `-PromotionFile <path>`，默认仍读 `metrics/promotion.json`），
     否则负反对照只能改被跟踪文件；
   - 在 CI 增加一步 `pwsh … check-matrix-policy.ps1 -Check`：可挂在 `matrix-summary` job 的
     `-SummarizeFile` 之后（同一 job 里跑，零新增依赖），或在 `lint` job 加一步（秒级）；
   - 加一条自测（PowerShell 内联或 `scripts/verify/` 下的 self-test）：
     临时 promotion 文件写一条 `review_by=2000-01-01` 的 advisory → 必须 exit 2；
     正常文件 → exit 0。**正反两面都要有**。
   - 验收：CI 上该步在正常日期时绿；把日期改成过去后红（反面对照记录进实现记录）。

## 风险

- **"改期不干事"**：改 `review_by` 是合法动作，但必须有 owner、理由、下一步与新的截止日；
  只改日期等于把问题往后推 3 个月，且下次到期时仍然没有环境。
- **洞 A 的语义变化会立刻生效**：补完后，任何"到期仍 advisory"的 cell 会让 CI 红。
  当前 4 条到期都在 12-31，不会立即红；但如果先改期到过去日期做负反对照，**记得改回**并在同一提交里完成。
- **matrix 的 advisory cell 结果依赖 runner**：linux GUI/音频、macOS 编译都有环境依赖，
  升档前必须确认不是"偶尔绿一次"（要求连续 2 次 + 无 flaky 记录）。
- **不要顺手改 blocking cell**：`windows-native` / `windows-wasm` / `windows-wasm-gpu2d-off` 是合并门，
  本包只动 advisory 的到期与门实现。
