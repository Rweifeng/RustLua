## 实现记录

1. **音频资源（离线可复现）**
   `tools/gen_audio.py` 纯 Python 标准库（`wave`/`math`/`array`/`struct`）合成 16-bit / 22050 Hz / 单声道 WAV：
   4 个可无缝循环 BGM（`bgm_title` 16s、`bgm_manor` 14s、`bgm_village` 14s、`bgm_wilds` 16s，均 <2 MB）+ 11 个 ≤0.6s 音效
   （`ui_click/ui_confirm/ui_cancel/sfx_hoe/sfx_plant/sfx_water/sfx_harvest/sfx_hit/sfx_quest/sfx_sleep/sfx_craft`）。
   脚本**不使用 `random`**（噪声走固定种子手写 LCG、整数相位波表），重复运行字节一致（脚本打印 SHA256）；
   生成后重新读回自检（RIFF 头 / 声道 / 采样率 / 位深 / 帧数 / 时长 / 体积 / 非静音 ≥1%），失败即 `exit 1`；
   成功末行 `gen_audio_ok files=15`。许可证与使用位置登记在 `docs/THIRD_PARTY.md`。

2. **`scripts/audio.lua`（音频运行时）**
   `play_bgm(map_id)` 按 `MAP_BGM` 选曲、**同一曲目不重启**、未登记地图回落 `bgm_wilds`；`play_title()`；`stop_bgm()`；
   `sfx(name)` 包装 `audio.play`；`set_volume/adjust_volume/volume`（0..1）；`capture/restore` 经 `save_manager.register("audio", ...)`
   存 `{ volume }`。所有引擎调用都被 `pcall` 包裹：缺文件 / 无设备 / 无 asset 目录只记一次日志（引擎无 `log.debug`，回落到 `log.info`），
   **不中断玩法**。`main.lua` 在 `enter_playable_map` 起播地图曲、标题门面 `play_title()`、`new_game` 复位。

3. **HUD（`scripts/hud.lua`）**
   右上固定面板（996,8,276×300）显示生命(气血)/体力/内力/时间(第N天·季·时:分)/天气/金钱/地图/快捷栏（武器·工具·种子×数量）；
   顶部键位提示；左下提示区把 `state.last_action` 映射为可读中文（`not_enough`/`tired`/`wrong_season`/`full`/`crafting`/`no_seed`/
   `need_hoe`/`need_watering_can`/`already_watered`/`wrong_land`/`build_blocked_<reason>@x,y` 等；未知取值原样显示便于诊断）；
   `hud.clip()` 按「CJK 记 2 单位」截断防中文溢出；`hud.text()` 单行文案保留建造 footprint 预览（`building` 字面量 → M18-02 既有断言不回归）。

4. **三个面板（沿用 `shop.lua` 的纯键盘范式，`ui.text_at/panel/hide` 每帧整体重绘）**
   - `inventory_ui.lua`：`W/S/A/D` 或数字键选择、`U`/空格使用（`inventory.use`）、`E` 装备到 tool/weapon 槽、`C` 设为当前种子、
     显示容量与负重、失败原因就地显示；`I`/`Esc` 关闭。
   - `quest_ui.lua`：只读列出五态与选中任务的目标进度（`quest.list()`/`progress()` 只读接口）；**不在此交付**，交付仍走对话单一入口（M17-03）；`L`/`Q`/`Esc` 关闭。
   - `pause_menu.lua`：继续 / 保存 / 读取 / 音量 ±10% / 返回标题；`空格` 确认、`Esc`/`P` 继续；保存/读取走 `save_manager.save()/load()`，
     读档后经 `jianghu_reload_map()` 重放本图 overlay，返回标题经 `jianghu_return_to_title()`（复位一次性引导标志）。
   - `state.lua` 模式机新增 `Quest`；`input.update` 在 `not Playing` 早退前分发五类面板，并新增**模式自愈**（mode 停在 UI 态但面板未打开时复位 Playing，修掉读档后输入被永久吞掉的既有隐患）。
   - 顺带加固：`dialogue` 支持 `W/S` 上下选择、`shop` 支持 `W/S` 选择。

5. **新手引导（`data/tutorial.lua` + `tutorial.lua`）**
   纯数据十步：`till → plant → water → sleep → goto_village → talk_npc → accept_quest → deliver → craft → done`（末步 `match.kind="finish"` 为终止标记）；
   进度写 `state.vars["tutorial_step"]`（随 `state` provider 存档恢复，无需新 provider）；每次事件至多推进一步（**幂等**，重复触发同一步不重复推进）；
   一次性奖励锚点 `state.vars["tutorial_rewarded"]`（回复药 ×1）；老档（无 `tutorial_step`）`prompt()` 返回 `nil` 且零写入；
   `validate_all` 校验步骤 id/文案/match 白名单与引用（地图、任务、奖励物品），并登记进 `scripts/validate_data.lua`。

6. **关键操作音效（只在成功路径，全部 `pcall` 保护）**
   翻土/播种/浇水/收获（`farm.lua` 各成功分支）、命中/受击（`combat.lua` 结算处）、任务交付（`quest.deliver`）、
   买卖成功与失败（`shop.buy/sell` + `shop.confirm`）、对话打开/选择/结束（`dialogue`）、面板开闭与操作结果（三个面板模块）、
   睡觉（`input.lua` T 分支）、建造放置/升级（`building.place/upgrade`）、制作开工/收取（`crafting.start/collect`）。

7. **补齐 MVP 闭环缺口（内容修正，最小改动）**
   新档 `inventory.setup()` 发放 1 把水壶。原因：`farm.act` 浇水要求 tool 槽装备 `watering_can`，但商店不售工具、无任务奖励，
   且 `weather` 永远不会转 `rainy`（无天气调度）——此前作物**永远无法成长**，导致「播种→浇水→睡觉→收获→交付→制作」剧本不可完成。
   引导第 3 步同时教会「按 I 打开背包 → 选中水壶 → E 装备」，把该修正变成一次背包/装备交互的验收路径。

8. **headless 验收（`engine/crates/game/examples/jhyt_m19_ui.rs`）**
   照 `jhyt_m18_build.rs` 骨架，八章：①15 个 WAV 的 Rust 侧独立复核（RIFF/声道/采样率/位深/帧数/非静音）+ Lua 调用路径 `pcall` 不抛错、
   同曲目不重启、未登记地图回落到 wilds、音量存档往返；②HUD 关键字与 9 行字段；③背包打开→选择/使用/装备→关闭（含 UI 输入不下沉世界、面板可见性）；
   ④任务面板列出五态与目标进度；⑤暂停菜单音量 ± 与保存/继续；⑥错误文案映射（含未知值原样显示与中文截断）；⑦引导幂等/十步剧本/奖励一次性/存档往返/老档不打扰；
   ⑧回归锚点（农田循环、建造预览 `building` 文案、统一数据校验）。

### 与任务文档的偏差（已在文档中说明）

- 任务书举例「返回标题用 `scene.load('title')`」，但 `project.toml` 的 `startup_scene` 当前是 `scenes/main.scene`
  （并行场景批次把门面从历史上的 `scenes/title.scene` 收敛到 `main.scene`，`title.scene` 已从工作区移除），
  故实现为「优先 `scene.load("title")`，返回 false（场景不存在）时回落 `scene.load("main")`」，两种布局都可用。
- 引擎输入层当前只暴露字母键 / `Space` / `Escape`（无方向键、Enter、Tab），故「方向键选择」以 `W/S/A/D` 实现、确认以 `空格` 实现；
  对话/商店的「上下键选择」为可选加分项，已一并实现（`W/S`）。
- 引擎未暴露 `log.debug`（仅 `info/warn/error`），音频降级日志用「优先 `log.debug`，缺失回落 `log.info`」的兼容写法，并对同一调用名只记一次。
- 任务面板需要一个 UI 模式才能继承 M16-01 语义，故在 `state.lua` 的 `VALID_MODES` 追加 `Quest`（纯追加，不影响既有模式）。

## 未完成项 / 已知限制

- 无富文本、无滚动列表、无鼠标点击面板（沿用纯键盘范式）；背包「网格」用两列 × 10 行文本槽位实现，未接入 `assets/art/ui/backpack/ui_quality_frame_*` 图标与品质框。
- 任务日志只读，不支持放弃任务 / 追踪筛选 / 分页（任务量增长后需要滚动）。
- 音频只有主音量：引擎的分组音量（BGM/SFX/UI）属 M20-02 的 Rust 改动，本任务按要求不改 `engine/crates/**`；面板音量即主音量。
- 「返回标题」后重新进入会重新走 `boot_game`（重新建背包/读档）；暂停菜单的「读取进度」仅在存档地图与当前地图一致时直接恢复，跨图读档提示回标题继续（标题页 `BtnContinue` 路径已支持跨图）。
- 天气不会转雨（无天气调度），因此 `rain_watered` 分支当前只在测试中可达；水壶发放是本任务为闭环做的最小内容修正，天气排程建议另立内容任务。
- 引导没有「跳过 / 重播」入口（`tutorial.disable()` 已预留），也未按玩家已有进度做条件跳过（老档一律不打扰）。
- `scripts/input.lua`、`scripts/main.lua`、`data/*.lua` 属并发会话共享文件：本任务改动均保持追加式最小改动，并在改动前重新读取磁盘现状。
