# M9-04 3D 样板游戏垂直切片

## 状态

ACCEPTED

## 目标

用 Lua 实现一款小 3D 游戏：玩家碰撞移动、至少一种敌人 AI 追击、拾取物、血条 HUD、胜负条件与重开；玩法逻辑全部由 Lua 驱动；可在 Release 中独立玩通。

## 背景

M9-02 提供 3D 物理（rapier3d + Lua API），M9-03 提供编辑器 3D Gizmo。M9-04 用一款可玩的 3D 游戏验证「3D 引擎能力绑定游戏需求」。ADR-0011 已锁定玩法范围。

## 输入

- `docs/27-M9-3D可玩垂直切片实施计划.md`（M9-04）
- `docs/02-technical-decisions.md`（ADR-0011）
- `engine_core/src/script.rs`（physics3d/camera/health/ui Lua API）
- `engine_core/src/physics3d.rs`（Collider3d 组件）
- `game/scenes/demo3d.scene`、`game/scripts/demo3d.lua`（3D 资产参考）

## 不做什么

- 不做多关卡、存档、成长系统、Boss、联网；
- 不做 3D 音效空间化；
- 不破坏 demo3d 技术演示与 2D 游戏。

## 技术方案

- **引擎补充**：新增 `camera.set(id, x,y,z, tx,ty,tz, [fov])` Lua API（更新 Camera3D 组件，先校验后写入），支撑跟随相机。
- **game3d.scene**：Ground（静态 cuboid）+ 四面隐形墙 + Player3d（胶囊动态体 + warrior 网格 + 动画）+ Enemy1/2（固定传感器体 + AI）+ Pickup1..3（固定传感器）+ Camera3d + Sun。
- **game3d.lua**（全部玩法逻辑）：
  - 玩家：WASD → `physics3d.set_velocity`（Y 置 0 抵消重力贴地行走；**仅输入变化时设置速度**，减少贴墙抖动）；Running/Idle 动画切换；
  - 敌人 AI：朝玩家步进（**固定传感器体，不物理推挤玩家**；`transform3d.set` + `physics3d.set_position` 运动学移动，手动夹紧竞技场边界）；
  - 碰撞事件：敌人接触伤害（冷却 1s）/ 拾取传感器收集，全收集胜利、血量归零失败；
  - 跟随相机：`camera.set` 置于玩家后上方看向玩家；
  - HUD：`ui.text_at` 血条/目标/终局；R 重开 `scene.load`。
- **接入**：main.lua require game3d（门控 Player3d 存在）；F4 循环 main→arena→game3d→main。

- 玩法手感需实机验收。
