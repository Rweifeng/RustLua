# M1-04 日志与错误

状态：`ACCEPTED`

## 目标

为运行时接入统一的结构化日志和上下文错误诊断：同时输出控制台与文件日志，支持按模块过滤，并让 Lua、渲染和后续资源错误包含可理解的操作建议。

## 实现与验收

- 接入 `tracing`、`tracing-subscriber` 和 `tracing-appender`。
- 提供 `engine`、`editor`、`game`、`script`、`asset` 五类日志模块。
- 控制台与 `engine/artifacts/logs/game.log` 双路输出。
- 默认过滤器为 `info,wgpu_hal=warn,wgpu_core=warn,naga=warn`。
- `EngineError` 提供模块、操作、上下文、原始原因和解决建议。
- Lua 加载/执行、渲染初始化和 GPU 内存不足路径已接入上下文错误。
- `cargo test --workspace`：10 passed、0 failed。
- Debug 质量门：`engine/artifacts/logs/quality/verify-20260820-151137.log`。
- Release 质量门：`engine/artifacts/logs/quality/verify-20260820-151819.log`。
- 真实 Demo：`engine/artifacts/logs/M1-04-logging-session-final.stdout.log`，标准错误为空，窗口/GPU/Lua 均成功。

## 已知限制

日志初始化为进程级一次性初始化，文件为追加模式，过滤器仅启动时配置；`editor` 和 `asset` 分类已定义但待对应模块接入。
