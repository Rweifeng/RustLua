# M6-04：UI / 音频 / 粒子

- 状态：ACCEPTED
- 验收日期：2026-08-22
- 所属里程碑：M6 2D 游戏能力与样板游戏
- 前置任务：M6-03 Rapier 物理（碰撞/触发器事件驱动玩法反馈）

## 目标

提供 UI（血条、提示文本）、音效（攻击/受击）、粒子（受击爆发）三类能力，用一条可玩的反馈链打通：空格=攻击音效+粒子 → 走进触发器=受击（血条下降+受击音效+受击粒子）。

## 背景

M6-00~03 玩家可移动、有动画、被墙阻挡、碰撞事件进 Lua，但没有血条、声音、粒子。M6-04 补齐玩法反馈三件套。

## 输入

- `engine/crates/engine_core/src/particle.rs`、`audio.rs`（新模块）
- `engine/crates/engine_core/src/script.rs`（Lua API）
- `engine/crates/game_runner/src/main.rs`（渲染与推进）
- `scripts/gen-audio.ps1`、`game/assets/{attack,hit}.wav`、`game/scripts/main.lua`

## 不做什么

- 完整 UI 框架/布局系统（egui 编辑器 UI 之外，游戏内 UI 用简单元素）
- 音乐播放与多轨混音（仅短音效）
- 编辑器粒子/UI 可视化编辑

## 技术方案

1. **粒子**（`particle.rs`）：`ParticleSystem` 池（`burst` 生成、`step` 更新+回收，确定性 LCG 保证可复现）；`Particle{position, velocity, life, size, color}`，`fade()` 计算透明度。
2. **音频**（`audio.rs`）：rodio 播放——`AudioSystem` 懒打开输出设备（无设备降级警告不崩溃）、WAV 按名缓存（`set_asset_dir`）、主音量、播完回收 sink。
3. **UI**：`UiText` 增加位置；`ui.bar(name,x,y,w,h,ratio,r,g,b)`（血条）、`ui.text_at(id,x,y,text)`（提示文本）；`ui.text` 默认位置。
4. **Lua API**：`particles.burst(x,y,count)`、`audio.play(name)`、`audio.volume(level)`、`ui.bar`、`ui.text_at`；LuaRuntime 快照访问器 `with_ui`/`with_particles`、`step_particles`、`set_audio_asset_dir`。
5. **渲染**（game_runner）：粒子进 SpriteBatch（世界空间白纹理四边形）；血条为屏幕空间 NDC 背景+填充；文本经内置 5x7 字形图集（`TextLayout::build`）采样；哨兵纹理路径 `__white__`/`__builtin_text_atlas__` 由渲染器解析为内置纹理；每固定步推进粒子。
6. **游戏工程**：`gen-audio.ps1` 生成 attack.wav（440Hz）/hit.wav（160Hz）；main.lua 血条随 health 更新、空格=attack、触发器=受击（`health.damage`+粒子+hit 音效）。

## 风险与应对

| 风险 | 应对 |
|---|---|
| 无音频设备崩溃 | rodio 懒打开，失败降级 `tracing::warn`，不阻断游戏 |
| 文本图集每帧重建 | `TextAtlas::built_in()` 便宜（静态字形位图），渲染路径已隔离 |
| 粒子随机性破坏确定性 | 确定性 LCG（固定种子） |
| UI 元素与场景遮挡 | UI 追加在场景网格之后，draws 顺序保证 UI 在上层 |
