# M10-08 多选 / 对齐 / 快照

## 状态

ACCEPTED

## 目标

场景视图多选实体（shift 点选/框选已有）；对齐工具（对齐网格 / 水平对齐 / 垂直对齐）；2D 平移网格吸附。

## 背景

阶段二 P1 第四项。3D 吸附已在 M10-07 完成。M10-08 补 2D 吸附与对齐工具。

## 技术方案

- 多选：`scene_state.selected`（BTreeSet）已支持 shift 点选/框选，确认保留；
- 对齐：工具栏「对齐网格」「对齐H」「对齐V」按钮 → `align_selected(mode)`：网格（全部吸附到 snap_step 网格）、H（对齐到首个选中 Y）、V（对齐到首个选中 X），经 history 可撤销；
- 2D 平移吸附：2D drag 的 Move 工具在 snap_enabled 时把 position_x/y 吸附到网格。
