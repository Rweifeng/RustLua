# M18-04 动物系统

## 状态
BACKLOG

## 类型
[玩法]

## 目标
动物购买、喂养、产出、心情，数据驱动。

## 背景
缺口清单 3.x 提到动物产出（2.2）与动物。这是农场长期资源循环的一环。

## 输入
- `data/animals.json`（品种/价格/产出/心情规则）、`data/feed.json`
- M17-05 商店（购买）、M16-08 每日（产出结算）、M18-00 体力
- 容器/物品（收产出）

## 不做什么
- 不做动物动画/好感培养深度；
- 不做疾病系统；
- 不做自动喂食机。

## 依赖
M17-05、M16-08、M18-00

## 验收标准
1. 动物可购买并放置（绑定地图持久化，M17-01 复用）。
2. 每日按心情/喂养结算产出（蛋/奶），产物进容器，玩家可收取。
3. 心情受喂养/天气/关棚影响，数据化规则。
4. 改 animals/feed 表重载生效，卖出动物回收资金。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：买动物→喂养→次日产出→心情变化→卖动物。

## 风险
- 每日产出与多处结算 → 统一挂 `on_day_start` 结算回调；
- 动物数量膨胀 → 每张图动物数量上限。
