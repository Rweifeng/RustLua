# M18-08 完整 UI 交互

## 状态
BACKLOG

## 类型
[引擎+玩法]

## 目标
键盘/手柄焦点、拖拽、tooltip、日历/任务/选项/存档菜单、滚动区域等完整 UI 交互。

## 背景
缺口清单 4.5 要求鼠标点击、键盘/手柄焦点、拖拽、Tooltip、背包网格、对话框、交易面板、日历、任务日志、选项菜单、存档菜单、滚动区域。`ui` 动态面板已有基础，本任务补齐交互完备性。

## 输入
- `ui` API（panel/image/grid/tooltip/modal/drag）、`input`
- M16-07 背包/容器、M17-03 对话框、M17-09 日历、M18-06 任务、M18-07 技能

## 不做什么
- 不做复杂动画 UI；
- 不做游戏手柄具体设备适配细节；
- 不做 UI 皮肤系统。

## 依赖
M16-07、M17-03、M17-09

## 验收标准
1. 键盘/手柄焦点：Tab/方向在按钮与面板间移动，回车确认，焦点环可见。
2. 拖拽在背包/容器/快捷栏/商店间统一工作（复用 M16-07）。
3. 新增面板：日历、任务日志、选项（音量/速度/分辨率占位）、存档菜单（多槽）、滚动区域。
4. Tooltip 在所有可悬停元素上一致（M16-07 扩展）。
5. 面板打开/关闭不互相阻塞，模态层正确（`ui.modal`）。

## 测试命令
```powershell
cargo fmt --all -- --check && cargo clippy --workspace --all-targets --all-features -- -D warnings && cargo test --workspace --all-features && cargo build --workspace --release
```
实机：纯键盘走完「开背包→拖拽→关背包→开选项→调音量」流程。

## 风险
- 焦点系统与既有鼠标交互冲突 → 焦点模式与鼠标模式互斥切换；
- 面板嵌套层级管理 → 统一面板栈 + 模态计数。
