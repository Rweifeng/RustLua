# 任务：跨平台与浏览器运行时验证升级

- 任务 ID：M83-04
- 状态：待办
- 关联里程碑：M83
- 创建日期：2026-11-16

## 目标

将当前 Windows、Linux/macOS、WASM 编译和浏览器运行时的验证能力、阻断级别与证据口径显式化；优先补足真实浏览器运行证据，而不把 `cargo check` 当作运行时通过。

## 影响文件

- `.github/workflows/matrix.yml`
- `.github/workflows/quality.yml`
- WebGL 验证脚本和平台文档

## 风险

- Linux/macOS 或浏览器环境可能存在硬件/工具链差异；变更阻断等级前需有稳定、可诊断的基线。
- Web 证据步骤不应被无关格式/文档门完全遮蔽。

## 验收方式

1. 列出每个平台的 build、test、浏览器运行时验证及 blocking/advisory 状态。
2. 为 WASM 保留真实浏览器启动、首帧、绘制和宿主 API 契约证据。
3. 将稳定的非 Windows 核心单元升级为阻断，或记录不可升级的明确环境原因与复审条件。
4. CI 失败日志可被收集和定位。

## 未完成项 / 已知限制

- 尚未开始；不在没有稳定基线时直接把 advisory 单元改为阻断。
