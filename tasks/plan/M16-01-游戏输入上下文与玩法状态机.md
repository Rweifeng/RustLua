# 任务：游戏输入上下文与玩法状态机

- 任务 ID：M16-01
- 状态：进行中
- 关联里程碑：M16
- 创建日期：2026-09-09

## 目标
将 `game_jhyt` 的固定按键分支升级为可切换的玩法输入上下文和游戏状态机，隔离游玩、对话、背包、商店、暂停和场景切换输入。

## 影响文件

- `examples/game_jhyt/scripts/input.lua`
- `examples/game_jhyt/scripts/main.lua`
- `examples/game_jhyt/scripts/state.lua`
- `examples/game_jhyt/scripts/` 下新增输入/状态模块（如确有必要）
- 相关 headless 测试或示例

## 风险

- 旧存档中的状态字段不能因状态机接入而失效；保留默认 `Playing` 状态。
- 不在本任务内改动引擎公共输入 API；需要手柄、重绑定时另立引擎任务。
- 输入边沿在固定步追赶时只能消费一次，避免重复触发。

## 验收方式

- headless 测试覆盖状态切换、输入屏蔽和重复按键不重复触发。
- 手工启动 `game_jhyt`：游玩状态可移动/交互；进入暂停、对话、背包后玩家移动和世界交互被屏蔽；退出后恢复。
- `cargo test -p game` 或相关测试通过；`cargo build -p editor` 通过（若未改 Rust 则执行适用的游戏 Debug 构建）。

## 实现记录

已完成最小玩法状态机：`state.lua` 提供 `get_mode`、`is_mode`、`set_mode`、`toggle_pause`、`toggle_inventory`，支持 Playing、Dialogue、Inventory、Shop、Pause、Transition 六种状态；状态字段纳入存档并对旧存档默认回退 Playing。`input.lua` 使用小写边沿键 `p/i` 作为暂停/背包入口，保持既有小写 `e/t/q` 与大写 WASD 查询行为；非 Playing 状态停止玩家并跳过移动、农田交互、睡觉、修炼。`main.lua` 在标题进入主场景时标记 Transition，初始化完成后恢复 Playing。
