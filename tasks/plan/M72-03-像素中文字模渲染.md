## 目标

让中文以 1 位硬边点阵渲染，替掉现在压在像素美术上的平滑矢量 Noto Sans。
这是单条观感收益最大的一项——`project.toml` 现在 `text_render_mode = "vector"` + `NotoSansSC-VF.ttf`，
而引擎只有 `auto / vector / sdf` 三档（`editor/src/panels/project_settings.rs:37-39`）。

## 字体选型（已定）

**缝合像素字体 Fusion Pixel Font · 12px Monospaced · TTF · tag `2026.09.25`**

- 授权：**MIT**，2026-10-08 经 `api.github.com/repos/TakWolf/fusion-pixel-font` 的
  `license.spdx_id` 权威确认。MIT 无 Reserved Font Name 约束，商用嵌入比 OFL 更干净，
  满足 `51`"未授权素材不得漏进发布包"与 `60` 遗留的"资源授权表 ⚠️外部"。
- 只入**一款**：标题用整数倍 2× 放大，不引第二款字体（两款像素字混用会立刻露馅）。
- monospaced 而非 proportional：UI 网格对齐是本轮 P3 的主要诉求。

⚠ **未核验项**：2026-10-08 尝试下载时 `objects.githubusercontent.com` 在 302 后不可达
（本机已知间歇现象，同日重试通常成功）。**本包第一步就是把它下下来验表结构**。

## 现状（实测）

- 栅格化：`ab_glyph` 出轮廓 → `bymsdfgen_core::generate_sdf` 转 MSDF
  （`rustlua-render/src/font.rs:7-12`、`sdf_rect_from_shape :900-940`）。
- 固定尺寸 `font.rs:18 RASTER_SCALE = 96` px/em；显示尺寸 `EM_PX*scale`，
  `tex_scale = base_px / RASTER_SCALE`（`text.rs:434`）。
- **quad 角用 float 次像素定位**：`text.rs:468-471`（`x0 = x + bounds[0]*tex_scale`），
  **从不吸附**（只有 UI image 吸附，`ui.rs:274`）→ 像素字现在会糊。
- 着色器**已有一条硬阈值路径**：`shader.rs:110-114` 的 `sdf==2` = `select(0,1,d>=0.5)` + Nearest 采样，
  今天只服务 ASCII 5×7 位图（`text.rs:15-79 TextAtlas::built_in`、`:273 build_bitmap`）。
  **CJK 走不到那条路**，因为没有外部位图字体导入器。
- 子集化通道现成：`font_subset::subset_ttf`（TrueType glyf 子集器，重建 loca/glyf/cmap-fmt4/hmtx/
  head/hhea/maxp，丢 `gvar/fvar` → 静态字重），打包期由 `assetc/src/lib.rs:736-745` 调用，
  也可 `cargo run -q -p engine --example subset_project_font` 手动重生成。
- 字表现量：`examples/game_jhyt/chars.txt` = **471 字**。

   （带位图表也别高兴——`ab_glyph` 只读轮廓，不读位图）。
   **失败退路**：若 `-ttf` 不合用，退到 `-bdf`/`pcf` 路线就得自写字模图集导入器（工作量大得多），
   或换 Zpix / pixfont 重走一遍核验。
2. 字体入库 + `project.toml` 换 `font =`，跑一次子集化，记录子集后字节数（471 字，预期远小于

3. 整数吸附 + 阈值档接线。
4. 门。

## 风险

- **12px 中文在 96 px/em 栅格下是否真能落整数格**：`RASTER_SCALE=96` 而像素字设计网格是 12px
  → 8 倍关系，理论上每个像素单元正好落在整数设备像素上，**但这是推算，不是实测**。
  吸附做完必须用像素直方图验，别用"看起来挺清楚"验。
- 标点与数字在 12px 下偏挤，长段落可读性下降——像素风固有代价。`51` 的"正文 10–12px"档
  可能要上调到 14px，届时窗口内可用文字区变小。
- 缺字：新增文案超出 471 字就踩 `49` 的缺字契约。
- 三宿主都要验：Web/微信的字体加载路径与桌面不同（`Global` 剔除、真机缺 `TextEncoder` 那类坑）。

## 验收方式

- `jhyt_m72_pixel_font`：12px 渲染"山庄炼药"四字，取字形覆盖像素，**alpha 直方图只有 0/255 两档**
  （±1 容差）。复现口径要写进门注释。
- 缺字门：`chars.txt` 471 字逐字断言有非空字模。
- **反面对照**：把整数吸附关掉（还原 `text.rs:468` 的 float 定位），直方图门必须红——
  证明这条门真的在测吸附，而不是在测字体本身。
- 子集体积：记录子集后字体字节数，与 Noto 那份对比，写进 `58` 台账。
- 三宿主目验：桌面 / 编辑器 Play / Web（微信按 `70` 的跑测用例）。
