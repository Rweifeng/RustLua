## 目标
将 `game_jhyt` 从文本调试 HUD 提升为可完成 MVP 的基础游戏界面，并接入必要的音乐、音效和新手引导。

- `examples/game_jhyt/scenes/main.scene`

## 风险

- UI 输入不能与世界输入同时生效，依赖 M16-01 状态机。
- 中文文本必须检查字体覆盖、换行和溢出。
- 新增音频资源必须登记许可证和使用位置。

## 验收方式

- HUD 显示生命、体力、内力、时间、天气、金钱和快捷栏。
- 背包、对话、任务、商店、暂停菜单可打开、操作和关闭。
- 关键操作有明确提示、错误反馈和音效；至少有 BGM 与场景音效。
- 新玩家无需查看源码即可完成 MVP 验收剧本。
