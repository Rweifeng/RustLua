## 目标

HUD 现在和弹窗是两套质感。弹窗用的是质量达标的真切图，HUD 用的是半透明纯色块。

## 现状（实测）

- `assets/art/ui/common/ui_panel_main_9s.png` 实测 **96×96**：木框 + 四角金色括号 + 深色内底，
  被 7 个 prefab 引用（弹窗类）——**这条线是达标的**。
- 但 `assets/prefabs/hud.prefab` 里面板底是纯色块：
  ```
  component 2 Image  texture=__white__;color=0.930,0.750,0.350,0.900   # HudAccent
  component 3 Image  texture=__white__;color=0.080,0.090,0.120,0.620   # HudBox
  component 4..13   texture=__white__;color=…                           # HudChip1..6 等
  ```
  → HUD 的框、条底、状态片**全是 `__white__` 染色矩形**。
- UI 切图总量：`assets/art/ui/` 102 张，分 14 个子目录（common 24 / hud 21 / skills 10 /
  touch 11 / menu 13 / …）。**素材不缺，缺的是接线**。

## 影响文件

- `examples/game_jhyt/assets/prefabs/hud.prefab`（`__white__` → `ui_panel_main_9s` /
  `ui_slot_9s` / `ui_bar_frame_9s` 系）
- `examples/game_jhyt/scripts/ui/hud.lua`（运行期 `set_rect`/`set_visible` 的目标不变，
  但载体从色块换切图）
- `engine/crates/game/examples/jhyt_m70_hud_prefab.rs`（**136 行黄金表要重刷**）

## 设计要点

1. **只换载体，不动几何**。`hud.prefab` 头部注释写得很清楚：行序 = 绘制序 = 实体槽位升序，
   且要复刻迁移前动态层的 id 字典序（`ScriptState` 是 `BTreeMap`，`mesh_ui.rs:239` 迭代 `.values()`），
   门 `covering_account` 的排序键依赖它。**换贴图不许改槽位号与行序**。
2. 特别注意注释里那条坑：`bar_fill` 必须排在 `bar_frame` **之前**（fill 先画、边框盖在填充上），
   换切图时若把 fill 也换成带底的九宫格，会盖死边框或反之。
3. `HudBox` 换成九宫格后，原来的 `color=…0.620` 半透明要保留 → 依赖 M64a 那条
   "实体层 Image 的 color 接 RGBA 单字段"（`95921e9`），已具备。
4. 状态片 `HudChip1..6` 是**彩色小方块**，换切图要确认换成什么：
   倾向换成 `ui_status_*` 图标（已有 7 张）而不是继续色块——色块读不出"中毒/流血"。

## 风险

- **`jhyt_m70_hud_prefab` 的 136 行黄金表必红**（画面确实变了，这是预期的红）。
  按 `project-native-golden-bless` 的流程：先红、再逐行确认每一处变化都是"应当变"、然后重刷。
  **不许**为了让门绿而调整几何。
- 九宫格拉伸失真：这是 **M72-10** 的主题，本包只做 HUD，边距契约在 10 里定。
  若本包先撞上失真，记录到 10 的输入里，别在两个包里各修一半。
- 与并行会话撞 `hud.prefab`（最近 `e585fec`/`c5a23a6` 都在动 UI 层序）。

## 验收方式

- 目验：HUD 与 `references/stardew/` 的 HUD 截图并排（ Stardew 的 HUD 是木框+羊皮纸）。
- 量化判据：`hud.prefab` 里 `texture=__white__` 的 Image 组件数 **13 → 0**（或明确保留清单+理由）。
- `jhyt_m70_hud_prefab` 重刷后绿，且**逐行说明**每处黄金表变化对应哪块视觉改动
  （按 `feedback-doc-claims-need-evidence`：结论要挂证据）。
- **反面对照**：故意把某个 frame 的槽位挪到 fill 之前，门必须红（证明门还守着层序）。
- 三宿主：HUD 在 Web/微信宿主要一并目验（`ui-elements`/`drawn` 不计 prefab 实体那条口径限制要写清）。
