## 目标

补齐可配置动作映射、基础手柄/重绑定能力、BGM/SFX 音量分组以及 UI 滚动和焦点导航，满足 Alpha 版本的可用性要求。

## 影响文件

- `engine/crates/engine/src/core/input.rs`
- `engine/crates/engine/src/core/audio.rs`
- `engine/crates/engine/src/core/ui.rs`
- `engine/crates/engine/src/core/ui_layout.rs`
- `engine/crates/engine/src/core/ui_events.rs`
- `engine/crates/editor/src/panels/project_settings.rs`
- `examples/game_jhyt/scripts/input.lua`
- `examples/game_jhyt/scripts/` UI 与音频模块

## 风险

- 扩展输入公共 API 可能影响现有 WASD 和 WebGL 行为；必须保留默认映射和旧输入路径。
- 手柄和焦点导航在不同平台行为差异较大；先实现最小跨平台抽象，未覆盖平台记录为限制。
- 音频分组不可阻塞玩法逻辑，设备不可用时应保持静默运行。

## 验收方式

- 在桌面运行时验证动作映射、重绑定、失焦清理和 UI 焦点循环。
- 验证 BGM、SFX、UI 音效可独立调节并保存设置。
- 在 `game_jhyt` 的背包、对话、商店和暂停界面完成键盘与基础手柄操作。
- 执行相关 Rust 单元测试、游戏手工回归和 WebGL 编译检查。
