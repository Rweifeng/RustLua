# M73-02 · 删旧世界的**分账**（先分账、再立门、最后删）

这份是"删旧世界"的**第一步**：把 `plugins/webgl/lua_api_overrides.json` 那本账逐条判成
"**跟着删**"还是"**必须留**"，并写清每条的判据、风险与删除顺序。

**为什么要先分账**：这本账不是"旧世界的替代品清单"，它混着三种性质完全不同的东西 ——
删错了一类会**静默丢功能**（平台后端），删错另一类会**静默变 nil**（占位），
而第三类本来就该删（旧世界的 Lua 侧镜像）。三者在这本账里长得一模一样。

## 0. 口径与依据

| 项 | 数 | 说明 |
|---|---|---|
| `groups`（覆盖点） | 76 条 / 11 模块 | 函数式覆盖：补丁在 JS 侧提供同名实现 |
| `replacements`（整表替换） | 28 模块 | 补丁把整张 Lua 表换掉（`input = {…}` / `ui = {}` 再填） |
| 其中 `dropped` | **43 条** | 引擎有、补丁版**没提供** ⇒ web 上是 `nil` |
| 其中 `invented` | 2 条（`inv.open`、`log.debug`） | 补丁多给的名字，引擎没有 |
| 其中 `referenced` | 3 条 | `dropped` 里**发包工程正在引用**的：`audio.apply_settings` / `audio.settings_path` / `audio.settings_text` |

判据来源：各模块 `note` 字段（逐条记录了补丁为什么这么写）+ 本会话在浏览器门与微信开发者工具上的实测。

## 1. 三类归口（43 条 dropped 的总额）

| 类 | 条数 | 归口 |
|---|---|---|
| **A. 状态自存** | **15** | 跟着删，改走引擎实现（`input` 1 / `map` 2 / `tilemap` 3 / `transform` 3 / `physics3d` 6） |
| **B. 平台性差异** | **20** | **必须留**（`ui` 16 / `audio` 4）——web 侧它们是**唯一**实现 |
| **C. 纯占位** | **8** | 删，但必须同时决定"谁接管"（`animation3d` 5 / `mesh` 2 / `transform3d` 1） |

三类的**删除动作完全不同**：A 是"删掉补丁、让引擎接管"，B 是"把实现从 JS 挪到引擎的 web 后端"（不是删），
C 是"删掉占位、由引擎真实现接管或显式报缺"。

### A. 状态自存类 —— **跟着删**（删后自动改走引擎实现）

补丁把这些状态存在 Lua 侧 `__rustlua_*`，引擎那份在 `ScriptState` / ECS 里。删掉 JS 世界后
**自动**改走引擎实现 —— 所以"能不能删"不是问题，**风险在语义差异**。

| 模块 | dropped | 删后谁接管 | 主要风险 |
|---|---|---|---|
| `entity` `inv` `tag` `light` `sprite` `transform` `health` | 0（除 `transform` 3 条） | 引擎 ECS / `ScriptState` | 只有 web 侧写过的数据，删后**存档/快照消费者才第一次看见它**（`tag` 的 note 明说这个后果） |
| `transform` | `attach` `space` `world` | 引擎组件 | 补丁只存平面 x/y，没有父子/局部-世界两套 ⇒ 删后行为**变了**（不是缺失） |
| `scene` `map` | `go` `goto` | 引擎场景加载 | web 上 `scene` 只记账不换场景；删后**真换** ⇒ 首次真正走场景链 |
| `item` `shop` `interact` `container` `prefab` | 0 | `ScriptState` | `interact.query` 的排序规则是**照引擎抄的、抄的过程没测试** |
| `grid` `tilemap` | `create` `get_meta` `set_meta` | 引擎 tilemap | `tilemap` 的解算在 Lua/JS/Rust **三份镜像**里逐位对齐过；删掉 Lua/JS 两份后只剩 Rust 一份（好事，但要对拍一次） |
| `save` | 0 | 引擎 `rustlua-gameplay::save` | **最大风险点**：补丁版是"第三份后端"，payload 与引擎 v2 同形但**值层更保真**（长度前缀 vs JSON）。删后 PC `.sav` 与浏览器 `localStorage` 的差异会变成"只剩引擎一种格式" |
| `event` `physics` `animation` | `animation`: clips/events/time | 引擎 | `event` 的回调顺序/重入 emit 只有 L3 契约用例钉着；`animation` 依赖**时间基**（见 §2） |
| `log` | `invented: debug` | 引擎 log | `log.debug` 是补丁多给的；`core/audio.lua:109` 用 `(log.debug or log.info)` 取它 ⇒ 删后仍安全，但**直接调 `log.debug` 的脚本只在 web 跑得通** |
| `input` | `pointer_count` | 引擎 InputState | 多指字段刚落地（本会话）；删后 `input.press_position(i)`/`pointer_count()` 是**唯一**来源 ✓ |
| `time` | 0 | 引擎时钟 | 见 §2：这不是平台差异，是**接线缺口** |

### B. 平台性差异类 —— **必须留**（只是从"JS 补丁"改成"引擎的 web 后端"）

web 侧没有对应后端，补丁提供的不是"替代品"而是**唯一的实现**。删掉 = 直接丢功能。

| 模块 | 必须留的理由（note 原文口径） |
|---|---|
| `ui` | 屏幕 UI 由 Canvas 2D 适配层绘制（引擎版依赖 wgpu 提交与 GPU 字体度量）。`ui = {}` 整表替换丢掉的 20 条（拖拽四件套/模态/tooltip/网格格/滚动细则/`text_get`/`focus_cycle`）在 web 上仍是 `nil` |
| `audio` | 实际发声经 `__rustlua_audio_js_*` 调 JS 后端（微信 `wx.createInnerAudioContext`，浏览器 HTML5 Audio）⇒ 后端两侧都是**真的** |
| `camera` `camera2d` `quad` `mesh` `particles` `transform3d` `world_text` `visibility` | 渲染侧状态**不回 Lua**；这些表是"宿主镜像/占位"，删掉只会让调用形态断掉 |

### C. 纯占位类 —— **要删，但必须同时决定"谁接管"**

`set(...) return true`、没有任何 Lua 侧状态：`animation3d`（5 条 dropped）、`camera`、`camera2d`、
`mesh`（2）、`particles`、`quad`、`transform3d`（1）、`visibility`、`world_text`。

删它们**不等于**少写几行 —— 是"这些名字从此由引擎真实现接管，**或者**显式缺失"。
**绝不能留下"静默变 nil"**：那正是这本账存在的意义（`dropped` 里的名字现在就是 nil，且不进控制台）。

## 2. 删之前**必须先补**的两个缺口（否则删完行为还是错的）

1. **web 时间基**（`docs/51` 记的缺口，`time` 的 note 直说"这不是平台没有"）：
   `time.delta()` 恒返回 `1/60`、`clock` 的倍率在 web 上是空的、`animation` 的 `clips/events/time`
   **没有可用状态源** —— 根因是 **web 帧循环从没把 delta 经桥喂进 Lua**。
   删旧世界前必须让宿主把真实 delta 喂进去，否则这三处删完仍是错的。
2. ~~`audio` 设置文件那三条~~ —— **已核查，无需改动（B2 降级为"已满足"）**。
   原先这里写的是"`settings_path` 有一处无判据调用（`scripts/main.lua:410`）"，**那是错的**：
   - `scripts/main.lua:85` 是 `local audio = require("core.audio")` ⇒ 所有 `audio.*` 调用走的是**包装器**；
   - 三条包装全带判据：`core/audio.lua:272`（`settings_path`，`type()=="function"` + `pcall`，取不到 `return nil`）、
     `:314`（`settings_text`，同）、`:324`（`apply_settings`，不支持时 `return false, "unsupported"`）；
   - 而**引擎侧三条都在**（`rustlua-scripting/src/script/api/audio.rs:90/95/108`）⇒ 删掉 JS 世界后它们**自动可用**。
   所以 `referenced` 那三条是"**带判据的引用**"，不是"会撞 nil 的调用"——这正是本项目"不留静默 nil"里
   **可接受的那半**：不可用时返回**有类型的兜底值**，而不是崩。
   （仍缺的不是代码而是一条**静态门**：确保"游戏侧不直接调 `audio.settings_path` 这类可能缺失的名字"——
   归到 N7 的静态检查里，与本文件 §3 的 B7 同一批。）

宿主每帧拿默认输入 ⇒ 不崩溃不报错只是人钉死）。本会话已经做完：宿主自产输入链 + 微信侧每指接线

## 4. 必须先立起来的门（"删完仍应成立"的断言）

删之前把这些写成会红的用例，否则删除过程没有判据：

1. **平台后端仍在**：`ui.*`（Canvas 2D 绘制那 29 个名字）、`audio.*`（含三条 `referenced`）在删除后
   **仍被提供**（值级断言，不是"函数存在"）。
2. **A 类的语义不变**：`save` 的 payload 形状（`save_version=2` 头 + 键名对齐）、`interact.query` 排序、
   `event` 回调顺序 —— 各来一条契约用例（`lua_api_contract.lua` 是现成的载体）。
3. **不留静默 nil**：C 类删掉后，每个名字要么可用、要么**显式报缺**（进控制台/进读数），
   不再出现"`type(x)=='function'` 悄悄跳过"。
4. **体积与形态**：主包 ≤ 4 MB 硬门 + `main_of_limit` 下降幅度记录（预期 55.9% → ≈49.4%）。

## 5. 不能删的清单（一句话版）

`ui`（Canvas 2D 绘制 + 焦点/布局）、`audio`（JS 音频后端 + 设置文件后端）、
`camera`/`camera2d`/`quad`/`mesh`/`particles`/`transform3d`/`world_text`/`visibility`（渲染侧镜像）、
以及 §2 两个缺口补完之前**任何**涉及时间与设置的删除。

## 6. 这份账的边界（诚实交底）

- `note` 字段是**人工维护**的账（`docs/51` 明说逐名登记与过期检测是 L2 的已知缺口），
  所以每一条的"留/删"最终都要**核对 JS 侧实现与游戏侧引用**，不能只信 note。
- 本文件**只做分账**，没有改动任何运行期代码。
- 体积与体积门的数字取自 M73-01 的实测（`web-runtime.js` 414,881 B；主包 2,291 KB/55.9%）。
