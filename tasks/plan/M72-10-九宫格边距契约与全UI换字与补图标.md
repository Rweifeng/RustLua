## 设计要点

1. **边距契约**：每张 `_9s` 图登记 margin（像素）与**最小可用尺寸**，
   由 prefab 加载侧读取而不是脚本里各写一个数。母图 96×96 的边框实际占多少像素要先量出来。
2. **量化失真判据**：面板边长 / 母图边长 的比例超阈值就报错，而不是靠肉眼说"看着还行"。
3. 全 UI 换字 = M72-03 的字体在项目设置里生效 + 逐屏目验；
   `font_size` 吸附到整像素后，**原来靠 float 微调对齐的排版会全部错位**（`text_fit.lua` 是活的），
   这条要在验收里显式测。
4. 图标按 `51` 契约：alpha 二值化（>127→255）+ 6bit/通道量化，32×32 基准、大攻击 64×64。

## 风险

- **换字会打断几乎所有 UI 黄金表**：`jhyt_m59`…`m71` 八道 + `66`/`69` 两道黄金对账门
  都含文字矩形。字宽一变，文本槽位宽度、`text_fit` 的折行结果全变。
  → 这是本轮**红得最多**的一包，要预留重刷时间，且逐道归因。
- "85 真图 / 64 色块"这笔账对不上，说明台账不可信 → 先重数再定工作量，
  否则排期是空的。
- 补 16+64 张图标是纯美术量，可能压不动 → 允许拆成 M72-10a（契约+换字）/ M72-10b（补图标）。
