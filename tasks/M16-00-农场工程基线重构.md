# M16-00 农场工程基线重构

## 状态
DONE

## 类型
[工程]

## 目标
把 `game_farm/scripts/main.lua` 玩具原型拆成模块化脚本组织，建立 `data/` JSON 数据目录与加载约定，删除硬编码 `soil_positions`。

## 背景
`main.lua` 是单文件玩具：9 块固定 `soil_positions`、物品/体力/商店全硬编码、无模块划分。垂直切片（M16-03~M16-10）要在其上叠加系统，必须先拆出可维护的地基。

## 输入
- `game_farm/scripts/main.lua`（现状）
- `docs/18-lua-api.md`（Lua API 约定）
- `docs/23-工程目录功能说明.md`（工程目录约定）
- `engine/crates/engine/src/core/script.rs`（API 注册）

## 不做什么
- 不改玩法行为（行为等价迁移）；
- 不做任何新引擎 API；
- 不新增玩法系统（作物/商店/存档系统由 M16-03~M16-10 负责，此处只迁现有逻辑）；
- 不碰编辑器。

## 依赖
无（垂直切片并行线的共同入口，必须先做）。

## 验收标准
1. `scripts/` 按职责拆分：`game.lua`（编排）、`state.lua`（共享状态）、`player.lua`（移动/交互）、`farm.lua`（农田/作物现有逻辑）、`inventory.lua`、`shop.lua`、`save_manager.lua`、`hud.lua`；`main.lua` 仅作入口转发 `on_create/update`。
2. 行为等价：重构后实机 WASD / Q / E / R / F / T / G / F1 / F2 与重构前逐项一致。
3. `data/` 目录建立（可含 README 说明数据表约定）；`main.lua` 中硬编码 `soil_positions` 移除。
