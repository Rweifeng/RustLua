# RustLua 游戏引擎工程目录功能说明

- 项目根目录：`C:\GitHub\p2`
- 当前阶段：M6 2D 游戏能力与样板游戏（M0–M6 已完成）；最近标签 `v0.5-editor-mvp`
- 适用平台：Windows 优先
- 引擎核心：Rust stable
- 游戏脚本：Lua 5.4
- 图形与窗口：`wgpu` + `winit`

本文说明工程每个主要目录和文件的职责，方便独立开发、AI 会话恢复、代码定位和后续维护。

## 4. Rust 引擎目录

### `engine`

Cargo workspace 根目录，三个成员 crate：

```text
engine/
├── .cargo/config.toml   # 统一构建参数（target-dir = "target"）
├── crates/
│   ├── assetc/          # 资源构建 CLI（扫描/导入/清理/打包，M7-01）
│   ├── engine/          # 引擎 crate（core/ 纯逻辑 + host/ GPU 渲染）
│   ├── game/            # 桌面运行器（wgpu + winit）
│   └── editor/          # egui/eframe 编辑器
├── Cargo.toml           # workspace 成员、统一依赖版本
├── Cargo.lock           # 依赖锁定
├── README.md            # workspace 质量门/构建/测试说明
└── rust-toolchain.toml  # 固定 Rust stable + rustfmt/clippy
```

`engine/target/` 为 Cargo 构建缓存（`engine/target/release/game.exe`、`editor.exe` 等），不入库。

## 5. `engine/crates/engine`

合并后的引擎 crate（原 `engine_core` + `engine_host`）：`src/core/` 提供纯逻辑模块（无桌面窗口/GPU 依赖），`src/host/` 提供 GPU 渲染与运行时场景（wgpu + winit）。外部统一以 `engine::core::*` 与 `engine::host::*` 引用。

```text
src/
├── lib.rs            # crate 入口：pub mod core / pub mod host，再导出 version 与 PROJECT_WORK_DIR
├── core/             # 纯逻辑模块（原 engine_core；模块名 core 遮蔽标准库 core，代码内用 std::）
│   ├── mod.rs        # 模块注册入口 + PROJECT_WORK_DIR(".cache") 常量
│   ├── entity.rs     # Entity ID 与 generation 句柄
│   ├── world.rs      # ECS World 与组件存储
│   ├── commands.rs   # 延迟命令队列（安全 Spawn/Despawn/组件变更）
│   ├── events.rs     # 帧边界事件队列
│   ├── scheduler.rs  # 系统调度器（阶段/依赖/耗时）
│   ├── transform.rs  # Transform/Velocity + 积分系统 + 场景组件解析
│   ├── time_step.rs  # 60Hz 固定时间步
│   ├── input.rs      # 输入快照（键盘/鼠标/轴）
│   ├── window.rs     # 平台无关生命周期状态
│   ├── logging.rs    # tracing 日志 + 错误上下文
│   ├── performance.rs# FPS/耗时采样
│   ├── math2d.rs     # 2D 向量/相机/坐标/颜色约定
│   ├── math3d.rs     # 3D 数学原语（Vec3/Quat/Mat4/Aabb3）
│   ├── texture.rs    # PNG 解码与纹理资源
│   ├── sprite.rs     # Sprite 几何（含 SpriteAsset 纹理引用组件）
│   ├── sprite_batch.rs # CPU 侧批处理
│   ├── atlas.rs      # 图集区域与 UV
│   ├── text.rs       # 文本布局与内置字形图集
│   ├── resource_db.rs # 资源数据库（.cache/resources.db）
│   ├── import_cache.rs # 导入缓存（.cache/import-cache.db、.cache/cache/）
│   ├── scene.rs      # 版本化场景格式
│   ├── scene_extract.rs # 3D 渲染组件抽取
│   ├── prefab.rs     # 预制体
│   ├── script.rs     # Lua VM 桥接 + 全部 Lua API + 场景实例化/切换
│   ├── animation.rs  # 动画状态机（M6-02）
│   ├── animation3d.rs # 3D 骨骼动画（glTF skins/clips）
│   ├── physics.rs    # Rapier 2D 封装（刚体/碰撞体/触发器/事件，M6-03）
│   ├── physics3d.rs  # Rapier 3D 封装
│   ├── particle.rs   # 粒子系统（M6-04）
│   ├── audio.rs      # rodio 音效播放（M6-04）
│   ├── font.rs       # CJK/任意字形动态图集（ab_glyph 栅格化，M6-08）
│   ├── pack.rs       # 发布资源编解码（gzip 压缩 + chacha20poly1305 加密，运行时自动检测解码）
│   ├── save.rs       # 版本化存档编码/解码（M6-05）
│   └── tilemap.rs    # 网格地图（视觉层 + 碰撞层）
└── host/             # GPU 渲染与运行时场景（原 engine_host）
    ├── mod.rs        # 模块注册 + Renderer/RuntimeScene/SceneDraw 等 re-export
    ├── frame.rs      # 帧数据结构（OverlayVertex/SceneDraw/SceneMesh 等）
    ├── renderer.rs   # wgpu 渲染器（2D/3D pass、offscreen、readback 指标）
    ├── runtime_scene.rs # 场景实例化 + 每帧渲染数据
    └── shader.rs     # shader 资源
```

`examples/ecs_stress.rs`：ECS 压力测试；`examples/sprite_stress.rs`：精灵批处理 CPU 基准（M7-04）。

## 6. `engine/crates/game`

桌面运行器，把 `engine` 的 core 逻辑连接到真实 Windows 窗口与 GPU（经 `engine::host`）。

- `src/main.rs`：窗口、wgpu 渲染、固定时间步、Lua 驱动、场景实例化与渲染、粒子/UI/文本渲染、存档路径、`--project`/`--pack`/`--check`/`--log-filter` 参数；`windows_subsystem = "windows"`（双击不弹终端）、无 `--project` 时自动探测游戏项目、日志按 exe 目录解析；启动期资源完整性校验（`--pack` 缺失即拒绝启动），panic 写 `crash.log`。
- `examples/`：15 个可重复 Demo（`texture_upload`、`sprite_demo`、`sprite_batch_demo`、`camera_demo`、`atlas_demo`、`text_demo`、`demo_2d`、`resource_db_demo`、`import_cache_demo`、`scene_format_demo`、`prefab_demo`、`lua_api_demo`、`lua_hot_reload_demo`、`lua_script_debug_demo`、`scene_script_demo`）。

## 7. `engine/crates/editor`

egui/eframe 编辑器（M5 完成，M10 面板拆分）。`src/`：

- `main.rs`：入口 + `EditorApp` 状态定义 + `update()` 组合调用各面板（不再含面板 UI 逻辑）
- `lib.rs`：状态模型模块声明与 re-export（`inspector_state`/`resource_browser_state`/`scene_tree_state`/`document`/`history`/`recovery`）+ 项目检查（`--check`）、打开
- `panels/`：每个面板一个文件（`impl EditorApp` 块）
  - `header.rs`：标题栏 + 菜单栏（项目/帮助）+ 恢复提示 + 版本说明
  - `hierarchy.rs`：层级面板（场景切换/新建 + 实体树）
  - `resource_browser.rs`：资源面板（扫描/筛选/缩略图/拖放）
  - `console.rs`：控制台（实时日志 + Lua 输出 + 诊断）
  - `inspector.rs`：属性面板（组件管理/Transform/Camera/Light/Collider）
  - `scene_view.rs`：Scene 视图（2D/3D 渲染/Gizmo/框选/拖放生成）
  - `game_view.rs`：Game 视图 + Play/Stop 运行生命周期
  - `toolbar.rs`：中央工具栏（Play/Stop、工具、吸附、对齐、Undo/Redo）
- `actions.rs`：跨面板共享编辑命令（撤销/重做/保存/实体/对齐/同步）
- `progress.rs`：**通用进度面板 ProgressPanel**（导入/发布均后台线程执行 + 非阻塞进度窗口，发布不弹终端窗）
- `publish.rs`：发布/导入后台任务
- `geometry.rs`：几何/变换工具
- `util.rs`：通用工具（路径清理/CJK 字体/目录选择）
- `inspector_state.rs`：Inspector 状态模型（组件编辑与校验）
- `resource_browser_state.rs`：资源扫描与注册状态模型
- `scene_tree_state.rs`：实体树状态模型
- `document.rs`：场景文档与 PlaySession 隔离
- `history.rs`：Undo/Redo 命令系统
- `recovery.rs`：自动保存/闪退恢复（写入 `game/.temp/`）

## 8. 游戏工程目录

### `game`

独立游戏工程（数据型，非 Rust crate），通过 `--project` 由运行器加载。`game/project.toml` 声明名称、`main_script`、`startup_scene`。

```text
game/
├── project.toml        # 游戏工程清单
├── scenes/
│   ├── main.scene      # 地牢主场景（玩家/史莱姆/金币/Tilemap）
│   └── arena.scene     # 竞技场场景（F4 切换）
├── scripts/
│   ├── main.lua        # 游戏主入口（require 各职责模块并转发生命周期回调）
│   ├── game.lua        # 流程编排（场景初始化/每帧更新/事件分发/胜负）
│   ├── state.lua       # 共享状态与工具函数（find_all/is_in/alive_count）
│   ├── player.lua      # 玩家（移动/攻击/血量/动画）
│   ├── enemies.lua     # 史莱姆（收集/追击）
│   ├── coins.lua       # 金币（收集/拾取）
│   ├── save_manager.lua# 存档（启动自动恢复/存/读）
│   └── hud.lua         # HUD（血条/目标文本）
├── assets/
│   ├── textures/       # PNG：精灵（hero/slime/coin）、图块集、测试纹理
│   ├── audio/          # OGG/WAV：attack/hit/pickup 音效、bgm.wav（循环背景音乐）
│   └── fonts/          # NotoSansSC-VF.ttf（CJK 文本渲染字体）
├── .cache/             # 每项目工作目录：资源库/导入缓存/存档（gitignored）
└── .temp/              # 编辑器自动保存/闪退恢复快照（gitignored）
```
