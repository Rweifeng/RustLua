# 编辑器使用指南

- 适用范围：`engine/crates/editor`（egui/eframe + wgpu 内嵌渲染）。
- 配套文档：[使用手册](22-使用手册.md)、[工程目录功能说明](23-工程目录功能说明.md)、[场景格式](16-scene-format.md)。

## 1. 启动与命令行

```
editor [--project <项目路径>] [--check] [--help]
```

- `--project <path>`：启动时直接打开该工程（跳过目录选择），并自动后台导入资源。
- `--check`：校验工程并输出报告（需配合 `--project`）。
- 无参数启动会打开目录选择器。
- 窗口默认 1280×720；`crash.log` / `editor.log` 写在编辑器可执行文件旁。

环境变量钩子（调试/基准用）：

| 变量 | 作用 |
|---|---|
| `P2_EDITOR_AUTOPLAY=1` | 启动后自动打开场景、切 3D 视图并自动 Play |
| `P2_EDITOR_AUTOPLAY_SCENE=<相对路径>` | 覆盖自动 Play 的场景（默认 `scenes/main.scene`） |
| `P2_EDITOR_THUMBNAIL_BENCH=<n>` | 跑缩略图基准后退出（默认 1000） |
| `P2_EDITOR_PLAYSTOP_BENCH=<n>` | 跑 Play/Stop 基准后退出（默认 100） |

## 2. 项目工作流

- 窗口标题：`RustLua 编辑器 - <项目路径>`。
- 菜单 **项目**：
  - **新建项目**：目录选择后，若目录不是工程则自动搭骨架（`project.toml`、`scripts/main.lua`、`scenes/main.scene`、`assets/`），随后后台导入。
  - **打开项目**：目录选择 → 后台导入（目录必须有 `project.toml`）。
  - **最近项目**：最多 5 个，最新在前，点击即重开。
  - **保存项目**（`Ctrl+S`）：保存当前场景到 `scenes/<场景名>.scene`。
  - **发布项目**：打开发布面板（见第 11 节）。
- 菜单 **编辑**：场景名 + **新建场景**、实体名 + **添加根实体**、添加 Sprite/Tilemap/UI Text/UI Image/3D 实体、**创建预制体**（选中实体树存为 `assets/prefabs/<名>.prefab`）、**收集字体字符**（写 `chars.txt`）。
- 菜单 **帮助**：**使用手册**（打开 `docs/`）、**版本说明**。

## 4. 工具栏

- **Play/Stop 单按钮**：`▶` 开始运行 / `■` 停止运行（无文字，悬停有提示）。未加载工程时禁用。
- **设计分辨率**：预置 640×360、960×540、1280×720、1920×1080；`×` 删除预置，`＋ 自定义…` 添加（宽高 100..7680 × 100..4320）。Play 中修改会实时重建预览。
- **3D 开关**：点亮显示 3D 视图（XZ 俯视），取消回到 2D。
- **吸附**：勾选 + 步长（0.05..10，默认 0.5）；3D 移动同样生效。
- **对齐**：`⊞` 对齐到网格、`↔` 水平对齐、`↕` 垂直对齐、`⇔` 水平等间距、`⇕` 垂直等间距。
- **排序**：`−`/`＋` 调整选中 Sprite 排序层，`⇅` 按 Y 重排 Sprite 排序。
- **缩放**：场景视图缩放滑杆（0.5..2.5）。
- **生活模拟工具**（M19-03）：☑ `出口/地点` 开关 2D 视图的领域只读覆盖层；`域` 打开
  领域数据面板（Lua 校验 / PersistId 注册表）；`调` 打开运行时调试面板（只读）。详见第 14 节。

## 5. 场景视图

### 2D 视图

- 平移 = **中键拖拽**；缩放 = **滚轮**（0.25..4.0，指针需在视图内）。
- 显示设计分辨率 W×H 边界框；打开/切回 2D 时自动适配视图。
- 选择：单击；`Ctrl`/`Cmd` 加选；空白拖拽框选（从左到右 = 完全包含，从右到左 = 相交）。选中实体琥珀色描边 + 名称标签。
- 变换：`✥ 移动` / `⟳ 旋转` / `⤢ 缩放` 直接拖拽（旋转绕选中枢，缩放整体均匀，最小 0.05）；移动开启吸附时按步长吸附。
- **Tile 画笔**：`▦` 工具下左键/拖拽画、右键/拖拽擦；可画视觉层或碰撞层（画笔 0..6）。同一工具的第二行还提供 **矩形填充 / 区域复制 / 区域粘贴**（见第 14.5 节）。
- **领域覆盖层**（工具栏 `出口/地点`，M19-03）：只读显示当前地图的出口格、出生格与 NPC 地点格，悬停看详情（见第 14.4 节）。
- **拖放**（从资源面板，Play 期间禁用）：纹理 → 新建 Sprite 实体（按纹理像素尺寸）；`.prefab` → 实例化预制体；`.glb`/`.gltf` → 新建 3D 实体（Transform3D + MeshRenderer）。

### 3D 视图

- 导航：滚轮缩放（1..100）、**中键拖拽 = 轨道**（yaw/pitch）、**右键拖拽 = 平移**。
- 实体显示为菱形标记 + 名称；点击射线拾取最近实体。
- Gizmo：移动 = X/Z 轴手柄 + Y 高度手柄 + 中心自由拖拽；旋转 = 黄色环（绕 Y）；缩放 = 紫色均匀。

## 6. 层级面板

- 标题 **层级** + 保存状态（`● 未保存` / `已保存`）。
- **场景选择**下拉：列出 `scenes/*.scene`，当前未保存场景显示 `●未保存`，并显示路径。
- 实体树：`▸/▾` 展开/收起子实体，`◉/◌` 隐藏，`⊡/⊠` 锁定，点击行 `"name [id]"` 选中（锁定行不可选）。隐藏/锁定状态持久化到场景元数据（`editor.hidden.<id>` / `editor.locked.<id>`）。
- 无场景时显示「请先新建场景」。

## 7. 属性（Inspector）

- 右侧 **属性** 面板（min 340）。
- 实体元信息：实体 ID、父实体、子实体数量、Prefab 来源与 Override 列表、**持久实体**（「运行时切场景不销毁」）。
- Prefab 根实例操作：**重新应用源 Prefab**、**打开源 Prefab**、**写回源并更新实例**。
- **父级**：输入父实体 ID → **设置父级** / **解除父级**；**重新命名** 改名。
- **添加组件**：可选 `Sprite, Tilemap, Animation, Transform3D, MeshRenderer, Camera3D, Light, Collider3d, Text, WorldText, Image, UiLayout, Container, UiEvents, UiBindings, ButtonStates, UiAnimation`；组件各有 **移除**。
- 可编辑组件：
  - **变换（Transform）**：**一个**面板，按实体实际拥有的空间显示——只有 2D 就显示 2D（位置 XY/旋转/缩放 +
    Reset、复制/粘贴组件），只有 3D 就显示 3D（位置 XYZ、旋转四元数、缩放 XYZ + Reset 3D），
    两种都有时面板顶部给出「编辑：2D / 3D」模式开关，并**始终**标出「空间：2D / 3D / 2D + 3D」，
    因此被切走的那一种不会被误以为不存在。
  - **MeshRenderer**：mesh 路径。
  - **Camera3D**：位置/目标/FOV/近/远。
  - **Light**：方向/颜色/强度。
  - **Collider3d**：形状 Ball/Cuboid/Capsule、sensor、dynamic、尺寸/半径/偏移。
  - **Text**：文本、空间（Canvas/Screen）、锚点 9 预置、位置、字号、颜色。
  - **WorldText**：世界空间文字（锚在实体世界位置、相机移动时跟随世界）——文本、字号、字体、颜色、屏幕偏移、水平居中。
  - **Image**：纹理、空间/锚点、位置/尺寸、九宫格边框、颜色。
  - **Sprite**：纹理、尺寸、Pivot、颜色 tint、水平/垂直翻转、排序层、Order。
  - **Tilemap**：纹理、Tile 尺寸、网格 width×height（1..256）、画笔、碰撞层、内联网格预览（≤24×24）。
  - **Animation**：默认状态、clips（名称/Sheet/列数/FPS/循环）。
  - **LuaScript**：Lua 路径。
- 所有修改可撤销（Ctrl+Z / Ctrl+Y），应用即自动保存场景；Play 期间全部编辑被锁定。

## 8. 资源面板

- 最左侧 **资源面板**，含 **刷新**、`N 项` 计数、过滤框。
- 目录树（顶层默认展开，空文件夹隐藏）。
- 可拖拽类型：**纹理 / 预制体 / 模型**（拖柄 `::`）；纹理与预制体显示 20×20 缩略图（后台线程解码、缓存）。
- 状态标记：`▲` 过期、`✕` 缺失/孤立、`✕`(红) 导入失败、`断链` 依赖失效。
- 双击打开 Scene/Prefab；`Delete` 删除选中资源（当前打开的场景不可删）。
- 待导入资源在后台批量导入，进度窗按项显示；成功自动关闭，失败保留。

## 9. 游戏视图与 Play/Stop

- 未 Play 时显示 `GAME VIEW / Press Play to run the scene`。
- **Play（`▶`）**：以内嵌预览（设计分辨率）运行场景，自动切到游戏工作区；状态机 `Editing → Starting → Playing/StartFailed → Stopping → Editing`，启动失败给出可读错误。
- Play 期间输入桥接进游戏：**全键位**（字母/数字/符号/空格/`Esc`/方向键/`F1·F2·F4`）、鼠标按键、
  光标映射到预览像素、滚轮；被节流跳过的帧与「同一帧内按下+松开」都不丢边沿（见 docs/35 §7）。
- 预览按 ~60fps（16ms）节流渲染，逻辑步用与独立 `game` 相同的 `FixedTimeStep`（60Hz、
  单帧最多补 8 步）**按真实经过时间追帧**：编辑器帧率低于 60fps 时游戏不会慢放
  （`FixedTimeStep::advance(elapsed)`；丢掉超出上限的步数会打 `[preview] dropped catch-up steps` 日志）。
- 失败时红色诊断覆盖层 + readback 指标。
- **Stop（`■`）**：丢弃全部运行时修改，**恢复 Play 前的编辑快照**，清空输入/选中，返回场景工作区。
- Play 期间锁定编辑（拖拽/Gizmo/Inspector/删除/添加/拖放/导入/发布均提示「Play mode locks scene editing; click Stop first」）。

## 10. 控制台

- 底部 **控制台 — <工程名>**；左侧 `⚙` 编辑器日志 / `🕹` 游戏 Lua 日志。
- 过滤框 + 级别 **全部 / Info / Warning / Error**。
- **运行选中脚本**：运行 Inspector 中 Lua 路径对应的脚本。
- 输入行 + **执行**（或 Enter）在内嵌 VM 执行 Lua，回显 `> <源码>` / `<结果>`。
- 脚本诊断显示阶段、文件、行号、信息、出现次数与 **建议**。

## 11. 导入与发布

- 导入在后台线程进行（进度 0.1→0.9），进度窗「导入游戏项目」；成功后切换工程/文档/恢复资源，记录最近项目；失败保留窗口。
- **发布项目**面板（菜单 **项目 → 发布项目**）：
  - **发布平台**：PC / WebGL / 微信小游戏。
  - **发布名**（默认取 `project.toml` 的 `name`）、**压缩**、**加密**、**发布** 按钮。
  - 后台启动 [scripts/package.ps1](../scripts/package.ps1)（`powershell -NoProfile -ExecutionPolicy Bypass`，不弹终端窗），参数 `-ProjectRoot -Platform -PublishName [-Compress] [-Encrypt]`。
  - 输出目录：`<项目>/builds/<平台>/<发布名>`；进度阶段映射：Release 构建 0.15 → assetc 打包 0.55 → 复制运行器 0.7 → 目录隔离自测 0.85 → 就绪 0.95。
  - 完成显示输出目录 + **打开目录**；完整日志存 `artifacts/builds/release/publish-last.log`。

## 12. 崩溃恢复

- 当前场景有未保存修改时每 **10 秒** 自动快照到 `<项目>/.temp/recovery-*.recovery`（原子写入，**从不改动正式场景文件**）。
- 启动/导入后扫描 `.temp`；存在候选时菜单栏出现 **⚠ 恢复**，每个候选可 **恢复** / **丢弃**。
- 恢复 = 把快照作为当前（未保存）场景加载到原路径；成功保存后删除对应快照。
- 损坏/校验失败的快照列入单独 `invalid` 列表，不会导致编辑器崩溃。

## 14. 生活模拟生产工具（M19-03）

面向 2D 生活模拟（`examples/game_jhyt`）的地图 / 交互点 / PersistId / NPC 日程 /
数据引用 / 运行时调试工作流。**编辑器不硬编码任何 NPC、任务、商店或日程规则**：
所有合法性问题文本都来自工程自身的 Lua 校验器（见下），编辑器只做展示、归属、
定位与（PersistId）编辑。

### 14.1 工具栏入口

| 控件 | 作用 |
|---|---|
| ☑ **出口/地点** | 2D 场景视图的领域数据只读覆盖层（默认开启） |
| **域**（点亮） | 打开/关闭 **领域数据（Lua 校验）** 窗口 |
| **调**（点亮） | 打开/关闭 **运行时调试（只读）** 窗口 |

### 14.2 领域数据面板（窗口「领域数据（Lua 校验）」）

- **校验来源只有一个事实来源**：工程提供 `scripts/validate_data.lua`（M20-01）时，
  面板执行该入口并调用 `check({ strict = true })` —— 与游戏启动校验、`game --check`、
  `editor --check` 完全一致；面板标题下方显示当前来源。工程没有该入口时回退为
  「发现 `scripts/data/**/*.lua` + 定义了 `validate_all` 的 `scripts/*.lua`，逐个校验」。
- **重新校验**：每次校验都新建 Lua VM（`require` 有模块缓存），因此**改完数据文件
  点一下就会读到磁盘最新内容**；校验过程只加载数据模块，**不执行 `main.lua`**。
- 校验结果按模块分组：`通过` / `有问题` / `无校验器` / `加载失败`，逐条问题**原样
  保留** Lua 给出的文件、对象与字段路径（例如
  `[maps] data/maps.lua:maps.village.exits[1].to: unknown map ghost`），可直接定位。
- **只读视图**（折叠区）：地图出口（cell → to/to_cell/label）、NPC 地点、NPC 日程、
  商店（keeper/place/stock 单价与限购/buys）、任务与对话索引。每行的 **定位** 按钮把
  `scripts/data/maps.lua:36` 形式的 `文件:行` 复制到剪贴板（再用外部编辑器打开）。
- **PersistId 注册表**（折叠区）：汇总 ① 工程内所有场景的 `entity_meta persist_id`
  与 ② Lua 域数据里的稳定 id（`data.npcs.persist_id`），报告三类问题：
  **重复定义**（含全部来源路径）、**场景/NPC 冲突**（同名 id 会让运行期
  `entity.spawn` 报 `persist_id already in use`）、**引用未定义**（如
  `data/shops.lua: <id>.keeper` 指向不存在的 NPC persist_id）；场景里声明但领域
  数据未提及的 id 作为备注列出（可能是农田/建筑/容器）。

### 14.3 PersistId 编辑（Inspector）

- 属性面板「持久实体」下方新增 **PersistId** 行：输入 → **设置**（或按 Enter / 失焦）
  写入实体自由 meta `entity_meta persist_id`；**清除** 删除该行。
- 改动并入撤销栈（一次提交 = 一条 Undo），保存后场景文本**只增删该 entity_meta 行**，
  **不改变场景格式版本**；同场景重名会被编辑器拒绝并提示。

### 14.4 出口 / 地点覆盖层（2D 场景视图）

- 当前场景名即地图 id：从 `data.maps` 取该图的 **出口格**（绿框 + `exit <id>` 标签）
  与 **出生格 spawn**（橙框）、从 `data.places` 取该图的 **地点格**（蓝框）。
- 鼠标悬停在标记上显示详情（出口 id、cell、目标地图与落点、label；地点名与 label）。
- 左下角显示覆盖层摘要（`领域覆盖（只读）：<map> · 出口 N · 地点 M`）；场景未在
  `data.maps` 注册时给出橙色提示（**前提是它有地编**：场景带 `Tilemap` 才算漏登记）。
  没有地编的纯 UI 场景（如主入口门面 `scenes/main.scene`）按设计不入 `data/maps.lua`
  （见 `examples/game_jhyt/docs/44`），此时只给中性的「非地编场景」说明、不着色告警，
  也不再显示那一行 `出口 0 · 地点 0` 摘要。
- 坐标换算与 Tilemap 网格/实体包围框共用同一套世界→面板映射（`pan`/`zoom`/ppp），
  `cell` 覆盖 `[c*TILE, (c+1)*TILE)`、`TILE` 取自 `data.maps.TILE`（缺失则不绘制）。

### 14.5 Tilemap 批量工具（Scene 视图 → `▦` Tile 画笔）

选中带 `Tilemap` 组件的实体后进入 Tile 画笔，右上角第二行出现模式按钮：

| 模式 | 操作 | Undo |
|---|---|---|
| **单格画笔** | 左键画、右键擦，拖拽连续画（原有行为） | 一次拖拽 = 一条 |
| **矩形填充** | 拖拽框选（反向拖拽同样成立），释放即按当前「画笔值 / 画碰撞层」填充整个矩形；越界部分自动裁剪 | 一次填充 = 一条 |
| **区域复制** | 拖拽框选，释放即把矩形内的 tile 值与 solid 位复制到 Tile 剪贴板（不写文档、不入历史） | — |
| **区域粘贴** | 单击目标格，把剪贴板内容粘贴到该格（右/下溢出自动裁剪；内容相同或全部越界则为无操作） | 一次粘贴 = 一条 |

- 拖拽过程中画面上有黄色（填充）/蓝色（复制）选区预览，左上角显示 `N×M（K 格）`。
- 剪贴板状态（`剪贴板：W×H`）与清空按钮在模式行右侧；剪贴板是编辑器会话状态。
- 纯逻辑（矩形归一化、越界裁剪、复制/粘贴数据生成）在
  `crates/editor/src/panels/tilemap_tools.rs`，带越界、反向拖拽、粘贴溢出裁剪单测。

### 14.6 运行时调试面板（窗口「运行时调试（只读）」）

- 未运行时显示 **无运行态** 占位（并保留上次读取说明），不 panic。
- Play 后点 **刷新**（首次打开自动读取一次）：经 `LuaRuntime::eval_json` 读取
  **当前地图**（`map_manager.current()` + `scene.reload()`）、**玩家坐标**
  （`map_manager.player_cell()` + `player.ensure()` + `transform.get`）、
  **NPC 列表与活动**（`npc.capture()` / `npc.diagnostics()`）、
  **任务状态**（`quest.capture()` / `quest.active()`）、
  **农田地块**（`farm.stats()` / `farm.capture()`）、
  **建筑与制作**（`building.list()` / `crafting.capture()`）、
  **存档摘要**（`save_manager.last_summary()`）、**时间与天气**。
- 每个探针在 Lua 侧用 `pcall` 包裹：缺模块/读取失败只显示错误文本，不影响其它探针；
  单个探针失败不影响面板其余内容。
- 面板**只读**，不修改游戏状态（读档、交易、制作等提交操作仍由游戏输入完成）；
  超长输出格式化显示并按上限截断。

### 14.7 已知限制（M19-03）

- **出口/地点可视化编辑未实现**：只做只读覆盖层 + 校验 + `文件:行` 定位，**不做**对
  `scripts/data/maps.lua` / `places.lua` 的 Lua 源文本外科回写。原因：回写要按
  `id = "..."` / `name = {` 锚点重写 `cell = { x = N, y = M }`，对嵌套表结构脆弱，
  且这类改动无法并入以 `SceneDocument` 快照为单位的 Undo 栈（单条 Undo 语义无法
  成立），而该工程目录正由另一会话并行修改。移动出口/地点请在数据文件里改 cell 后
  点 **重新校验**（覆盖层随即刷新）。
- 回退路径（工程无 `scripts/validate_data.lua`）下只支持明文 Lua 模块：该路径不经
  引擎的压缩/加密模块 searcher。
- 跨场景 PersistId 完整性只做**报告**（重复/冲突/引用未定义），不阻止保存。

## 15. 项目设置：音频小节（M20-02）

`项目` 菜单 →「项目设置…」窗口在既有 project.toml 字段（名称/入口脚本/启动场景/字体/
文本渲染模式）之下新增 **音频** 小节：

- 四个滑块（`0..=1`，显示百分比）：**主音量 / BGM / 音效 / 界面音效**，对应引擎
  `core/audio.rs` 的四条音量总线；实际音量 = 主音量 × 分组音量。
- 小节标题下直接显示写入目标路径：`<工程根>/settings.toml`。
- 点窗口底部 **保存** 时：project.toml 与 settings.toml **一起写回**。settings.toml
  是 M20-02 新增的可选工程设置文件，**只含 `[audio]` 段**，写入采用保序读改写
  （保留注释、未知键与其他段，例如后续任务要用的 `[input]`）；工程原本没有该文件时
  保存会自动创建。
- 读取失败/写入失败（无权限、路径被目录占用等）只在面板内提示，不 panic、不弹崩溃；
  文件内非法数值由引擎解析器忽略并回落默认 `1.0`。
- 运行期同一份数据由 `audio.load_settings()` / `audio.save_settings()` 读写：游戏
  `game_jhyt` 在启动时应用该文件，暂停菜单「设置」页调整后写回。编辑器与游戏共用
  `engine::core::settings::ProjectSettings` 的解析/写回实现，不会出现两种格式漂移。
- 已知限制：面板**不提供试听**（编辑器侧没有打开音频设备），试听请在游戏中调整；
  分组音量的权威来源是 `settings.toml`，编辑器与游戏同写同一文件时以最后一次保存为准。
