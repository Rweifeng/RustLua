## 《江湖有田》游戏音频（M19-02，自研合成）

`examples/game_jhyt/assets/audio/` 下的 16 个 WAV 全部由仓库内脚本离线合成，
**不含任何第三方素材、采样或字体**，许可证随仓库（与引擎源码一致）。生成命令：

```powershell
py -3 examples/game_jhyt/tools/gen_audio.py     # 输出 gen_audio_ok files=15
```

| 文件 | 用途（运行时调用点） |
|---|---|
| `bgm_title.wav` | 标题门面（`scenes/main.scene`，`audio.play_title()`） |
| `bgm_manor.wav` | 山庄地图（`audio.play_bgm("manor")`，`scripts/core/audio.lua` 的 `MAP_BGM`） |
| `bgm_village.wav` | 云泽村 / 药庐内 / 铁匠铺内 |
| `bgm_wilds.wav` | 青云山道 / 寒泉洞 / 演武场（未登记地图的兜底曲目） |
| `ui_click.wav` | 面板打开、对话开始、音量 ± |
| `ui_move.wav` | 菜单/面板换项（方向键 / DPad / 摇杆 / 数字直选；M22，`ui/panel_nav.lua` 统一接线） |
| `ui_confirm.wav` | 对话选择、买卖成功、使用/装备成功、暂停菜单保存/读取成功、标题按钮确认 |
| `ui_cancel.wav` | 面板关闭、操作失败反馈、对话失败跳转 |
| `sfx_hoe.wav` | `farm.lua` 翻土成功 |
| `sfx_plant.wav` | `farm.lua` 播种成功 |
| `sfx_water.wav` | `farm.lua` 浇水成功 |
| `sfx_harvest.wav` | `farm.lua` 收获成功 |
| `sfx_hit.wav` | `combat.lua` 命中/受击结算 |
| `sfx_quest.wav` | `quest.lua` 交付成功 |
| `sfx_sleep.wav` | `input.lua` 睡觉（T） |
| `sfx_craft.wav` | `crafting.lua` 开工/收取、`building.lua` 放置/升级 |

生成脚本自带自检（RIFF 头 / 声道 / 采样率 / 位深 / 帧数 / 非静音 / 时长与体积上限），
任一文件不合规即 `exit 1`。资产为确定性输出：重复运行字节一致（脚本内打印 SHA256）。
