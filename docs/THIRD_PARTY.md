The M8 test triangle GLB and the M8 skin test quad GLB are authored by this project
and contain only generated geometry data. They have no third-party dependency or
attribution requirement. The triangle can be regenerated with
`scripts/gen-m8-test-gltf.ps1`; the skin quad with
`cargo run -p engine_core --example gen_m8_skin_glb`.
