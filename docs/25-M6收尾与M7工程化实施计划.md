## 3. 技术路线

- **assetc**：新增 `engine/crates/assetc` bin crate（不依赖窗口/GPU），复用 `engine_core` 的 `ResourceDatabase`（`.cache/resources.db`）与 `ImportCache`（`.cache/import-cache.db`、`.cache/cache/`）；CLI 子命令 `scan` / `import` / `clean` / `package` / `list`；增量构建只处理变化资源；失败返回非零退出码并输出错误报告；
- **发布配置**：`assetc package` 生成发布资源包（目录结构与运行时加载约定一致 + 版本号/清单）；`game_runner` 支持 `--pack <pack>`（或等价）从包加载 Lua/场景/资源；清理 exe 相对路径假设，使发布包不依赖开发机目录；
- **崩溃日志**：注册 `std::panic::set_hook`，将版本、时间、最后日志上下文与调用栈写入 `crash.log`；`game_runner` 与 `editor` 均接入；Release（无终端）同样生效；
- **性能基线**：复用 `ecs_stress` 与 Sprite 批量基准场景，新增 `scripts/bench.ps1` 记录 FPS、帧耗时、Update/Lua 耗时、Draw Call、活跃实体、场景加载耗时；结果按里程碑归档；
- **干净机器**：组装发布包（exe + 资源包 + 运行说明），在无 Rust/IDE/源码环境下运行；测试路径含空格；发布包内含版本号/构建时间/依赖清单。

### M7-01 assetc 资源构建工具

**实施**：新增 `engine/crates/assetc` bin crate；复用 `ResourceDatabase`/`ImportCache` 做扫描、导入、清理；`package` 输出资源清单与打包目录；增量构建只处理变化资源；构建失败非零退出并输出错误报告。

**验收**：`scan`/`import`/`clean`/`package`/`list` 命令可用；源未变时复用缓存（增量）；源变化后重新导入；失败返回非零且报告可读；生成资源清单；Debug/Release 质量门通过。

### M7-02 发布配置与资源打包

**实施**：`assetc package` 生成自包含发布资源包（含版本号与清单）；`game_runner` 支持从包加载 Lua/场景/资源；缺失资源在启动期给出清晰错误；发布包不依赖开发机目录结构。

**验收**：Release 运行包在无源码/项目目录的环境（或目录隔离模拟）中可加载全部资源；缺失资源启动报错含资源名与原因；从包加载路径可验证；原有 `--project` 开发路径保持兼容。

### M7-03 崩溃日志

**实施**：在 `game_runner` 与 `editor` 注册 `std::panic::set_hook`；panic 时写 `crash.log`（版本、时间、调用栈、最近日志上下文）；Release 构建同样生效。

**验收**：故障注入（测试内触发 panic）生成含调用栈的 `crash.log`；版本/时间字段正确；Release 构建下验证通过；正常退出不产生 crash.log。

### M7-04 性能基线

**实施**：建立基准场景（1000 精灵稳定目标帧率；10000 ECS 实体运行 60 秒无崩溃）；新增 `scripts/bench.ps1` 记录 FPS、帧耗时、Update/Lua 耗时、Draw Call、活跃实体、场景加载耗时；结果归档到里程碑验收证据。

**验收**：1000 精灵达目标帧率；10000 实体 60 秒无崩溃且实体数稳定；无未解释的持续内存增长；基线数据有记录并可跨版本对比。

### M7-05 干净机器测试与安装包

**实施**：组装发布包（exe + 资源包 + 运行说明）；在无 Rust/IDE/源码的环境（或用目录隔离模拟：无 `target`、无 `.cache`、无开发路径假设）验证启动/游玩/存读档/退出全流程；测试 Windows 路径含空格；发布包含版本号/构建时间/依赖清单。

**验收**：完整流程可运行；含空格路径可运行；中文路径行为明确记录；包内含版本与依赖清单；安装/运行/排查说明随包提供。

### M7-06 发布候选版本

**实施**：最终回归（全量质量门）；样板游戏 Release 完整玩通一局 + 30 分钟稳定性；发布包校验；创建 `v0.7` 标签；生成发布报告（版本/平台/功能/性能/已知限制/第三方许可/测试结果/包位置/回滚版本）。
