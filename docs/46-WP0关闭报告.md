# WP0 正式关闭报告

## 关闭范围

WP0 已分四批完成：

1. 固定 ECS / Sprite / Tilemap benchmark 入口与初始画像；
2. `wp0-v2` 统一统计、JSON 输出与 `RenderFrameMetrics`；
3. 纯 3D 100 / 1,000 / 10,000 Mesh 阶梯和 CPU allocation；
4. 可选异步 GPU timestamp、3D semantic golden 与重复基准比较。

## 关闭判定

WP0 的目标是建立可信、可重复、不会伪造 GPU 数据的测量与回归基础，不是一次性完成所有未来场景 benchmark。当前证据已足够支撑 WP1/WP2 prototype：

- 性能优化可以使用统一 percentile 报告对照；
- 3D draw/geometry 变化会被结构门阻断；
- 画面回归由容差型 semantic golden 检查；
- GPU timestamp 按 capability 启用；
- 现有质量门保持通过。

后续新增 UI 密集、粒子、骨骼和场景加载专项时，沿用 WP0 schema 和比较脚本增量扩展，不重新打开 WP0。

## 未阻断后续工作的限制

- 同机重复误差阈值当前为比较脚本 warning，积累至少两组稳定环境数据后再升级为 blocking；
- semantic golden 不使用跨 GPU 精确 hash；
- 已知 GPU bytes 不是驱动实际驻留显存；
- GPU timestamp 样本异步滞后一帧，首帧可为 pending。
