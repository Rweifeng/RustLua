# WP0 第三批：3D 基准与证据

## 范围

本批补齐 WP0 的纯 3D 阶梯证据，不改变 3D 渲染语义：

- 新增 `wp0_3d_stress`，固定 640×360 离屏目标，运行 100 / 1,000 / 10,000 Mesh 阶梯；
- 预热 3 帧后采集可配置数量的 CPU 样本，输出 `wp0-v3` JSON 的 min / average / p50 / p95 / p99 / max；
- 输出 `RenderFrameMetrics` 的 draw calls / instances / triangles；
- 输出 benchmark 进程 CPU allocation count / bytes / live delta / peak delta；
- 输出 renderer 已知的 2D vertex buffer capacity / peak bytes；
- GPU timestamp 当前明确标记为 `null`，并带 `gpu_timestamp_supported=false` 与原因字段，不以 CPU 时间冒充 GPU 时间；
- `scripts/verify/verify.ps1 -Benchmarks` 运行并校验 3D 报告契约。

## 运行

```powershell
cd engine
$env:CARGO_TARGET_DIR='..\\.cargo-target'
cargo run --release -p engine --example wp0_3d_stress -- --cycles 30 --output ..\\artifacts\\baselines\\wp0-3d-stress.json
```

或从仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify/verify.ps1 -Benchmarks -SkipClippy -SkipTests -SkipBuild
```

## 当前证据

最小 smoke（每个阶梯 1 个样本）已验证：

| Mesh 数 | draw calls | instances | triangles |
|---:|---:|---:|---:|
| 100 | 2 | 100 | 100 |
| 1,000 | 2 | 1,000 | 1,000 |
| 10,000 | 2 | 10,000 | 10,000 |

2 个 draw call 是 shadow pass + main mesh pass；实例数和三角形数按逻辑场景几何统计一次。完整性能结论必须使用固定机器运行 30 个样本后比较 p95/p99，不能用 smoke 数字代替。

## 未完成与边界

GPU timestamp 仍未接入 resolve/readback；本批的 JSON 明确记录不可用原因，后续批次再实现可选 timestamp。GPU 总显存不通过 wgpu 跨后端 API 猜测，报告只包含引擎可知的 buffer 字节与 CPU 分配统计。
