## 0. 哲学

- **没跑 ≠ 通过**：任何一步打印 `BLOCKED`/`skipped` 都不是通过；退出码 `3` 是显式环境受限，
  必须在答复里写原因。
- **基线只由 `--update` 生成**：带 `-Reason` + 干净工作树；基线 diff 进评审，`git_dirty` 不能更新。
- **时间类指标同指纹 + ≥3 样本中位数**；确定性指标（覆盖率/几何量/字节数）跨指纹可比。
- **`history/*.jsonl` 是事实源**，`trend.sqlite` 可重建，`baselines/*` 人工确认。
- **不新增 Rust 依赖、不引入外部 SaaS**：扫描器是 Node 零依赖，趋势库是 Python stdlib `sqlite3`。

## 3. 七个域

### 3.1 Rust 代码覆盖率（P4-01）

- 采集：`cargo llvm-cov --workspace --all-features --locked --no-fail-fast
  --ignore-filename-regex 'vendor[\\/]|target[\\/]' --json --summary-only`（从 `engine/` 跑）。
- 归一化：`node scripts/metrics/coverage-summary.mjs` → `coverage-v1`（overall + per-crate 表，
  **口径含测试代码**，报告必须写明）。
- 门：`scripts/verify/check-coverage.ps1`——总行覆盖掉 `>0.5pp` 判 2；单 crate（源码行 ≥200）
  掉 `>2.0pp` 判 2；缺工具/缺基线退 3；测试失败退 1（`--no-fail-fast` 不掩盖红测试）。
- 自测：`scripts/test/test-coverage-gate.ps1`（5 用例）。

### 3.2 wasm 条件编译覆盖（P4-02）

  工作树漂移会以 `--check` 判红）：
  `files=822`、`sites=766`、`wasm_attrs=70`、`wasm_macros=4`、`not_wasm_attrs=88`。

  `gpu-web-probe` 必须被显式 check（独立 wasm 探针，不在 `game_web` 闭包）；

- 门：`scripts/verify/check-cfg-coverage.ps1`；自测 4 反例 + 基座（`scripts/test/test-cfg-coverage.ps1`）。

### 3.3 多平台矩阵（P4-03）

- workflow：`.github/workflows/matrix.yml`——7 cell（Windows ×3 blocking；Linux/macOS ×4 advisory）。
- 档位事实源：`metrics/promotion.json`；`scripts/verify/check-matrix-policy.ps1 -List/-Check/-Summarize/-SelfTest`。
- 晋升判据：advisory 在 `main` 连续 2 次绿 + 无 flaky → `experimental=false`；**到期仍 advisory 判 2**
  —— 不论该 cell 当轮是绿还是红（"绿着但一直不升档"同样不允许；`-Summarize` 与 `-Check` 同口径）。
- 到期机制自身的证据：`-SelfTest` 正反 6 例（全绿+未到期→0；全绿+已到期→2；advisory 红+未到期→0；
  advisory 红+已到期→2；`-Check` 两向）。CI 的 `matrix-summary` 同时跑 `-Check` 与 `-SelfTest`。
- 运行期宿主矩阵不重复造：桌面 = `verify.ps1 -Mvp`，WebGL = `verify-webgl-bundle.ps1`，
  微信 = `verify-wechat-minigame.ps1`；本项只证明编译。

### 3.4 趋势库（P4-04）

- `scripts/metrics/trend_db.py`：`rebuild/ingest/report/check/query/prune/selftest/accept-baseline`；
  表 `runs/samples/artifacts/schema_migrations`；`samples` 上 `(domain, workload, metric, created_at)` 索引。
- 适配器：`wp0_3d_stress`（wp0-v3/v4/v5）、`wp0_scene_frame`/`wp0_ecs_storage`、
  `ecs_stress`/`sprite_stress`/`tilemap_stress`（通用 perf JSON）、`jhyt_m19_soak`、
  `editor_perf`（37 场景文本，解析失败标 `unparsed` 退 1）、`coverage-v1`/`compile-v1`/`binary-v1`/`package-v1`。
  coverage 适配器读**嵌套**的 `overall.lines.percent`（旧实现读扁平的 `lines_pct` ⇒ 历史样本全是 0.0，
  2026-11-26 修复），per-crate 用独立 metric `crate_lines_pct`。
- **规则键映射**：采样是逐 artifact / 逐 package 一条，而 policy 的规则键是
  `exe/wasm/editor_exe/js`、`total/main/subpackage/component`；`check()` 经 `rule_key_for()` 映射后查规则
  （旧实现直接 `rules.get(metric)` 两类键永远对不上，二进制/包体红线从未触发，2026-11-26 修复）。
- 每个适配器写 `source.path` + `sha256`；`run_id` 由稳定内容生成（排除 ts），幂等可去重。
- **判红口径（2026-11-26 收紧）**：
  - 同指纹：只看与最新样本同一 `env_fingerprint` 的样本；跨机/跨 runner 样本不参与判红。
  - `compare_mode=same_fingerprint_trailing_median`（perf/compile）：同指纹最近 `min_samples`（默认 3）
    个 run 的中位数为参考，不足退 3（BLOCKED）。
  - `compare_mode=baseline_delta`（coverage/binary/package）：单样本即可判——当前值 vs **已批准基线**
    （`accept-baseline` 写入的带 `baseline` 标记的 run）；没有基线时退回上一条同指纹样本；只有一条时自比不判红。
  - 阈值：p95 +5%、p99 +10%、`cpu_peak_bytes` +10%；几何量/分配次数任何变化判 2（docs/54 红线）；
    覆盖 −0.5pp / 单 crate −2.0pp；exe +3% 或 +128 KiB、wasm +3% 或 +64 KiB、editor +256 KiB；
    包体 total/main +3%、subpackage +5%、component +10%。
- **红线自证**：`trend_db.py selftest`（正反 10 例：覆盖率 −1pp/−0.49pp、exe +4%、包体 +4%、
  跨指纹样本忽略、时间类样本不足退 3、批准基线优先）。`check-metrics.ps1` 每次先跑它，
  自测失败按 exit 1（红线不可信 ≠ BLOCKED ≠ 通过）。

### 3.5 编译时间（P4-05）

- `scripts/metrics/measure-build.ps1`：`-Mode check|test|release`、`-Cold`（必须 `-Yes`）、
  `-Incremental <crate>`；专用 `CARGO_TARGET_DIR=artifacts/metrics/target-compile`；≥3 次 min/median/max。
- `scripts/metrics/parse-cargo-timings.mjs`：从 `cargo-timing*.html` 的 `UNIT_DATA`/`CONCURRENCY_DATA`
  算 wall/critical/parallelism/per-crate。
- 门：冷构建只 nightly；PR 只跑 `check_warm` 并打印 delta（不判红）；同指纹 ≥3 样本才判。

### 3.6/3.7 二进制与包体（P4-06/07）

- `scripts/metrics/measure-artifacts.mjs --kind binary`：game/editor/assetc exe + game_web wasm/js；
  `bytes_raw`/`bytes_gzip9`/`bytes_brotli11`/`sha256`/mtime；`llvm-size` 分节（不可用打印
  `sections=unavailable`，不伪造 0）。缺文件标 `missing`，`-RequireAll` 判 1；`partial=true` 不更新基线。
- `--kind package`：PC / 引擎绿色版 / WebGL（wasm/js/字体/pack 分账）/ 微信（`game.json` 口径
  主包 = 总 − 分包，4MiB/20MiB 配额）/ `.rlb` 资源容器。
- 门槛：exe +3% 或 +128 KiB、wasm +3% 或 +64 KiB、editor +256 KiB；总包/主包 +3%；组件 +10% 附归因。

## 4. 基线更新流程

1. 跑采集/测量 → 产出 JSON（`artifacts/metrics/`）。
2. 人工审阅报告（`trend_db.py report` / 覆盖率 summary），确认变化是**有意**的
   （新依赖/新能力/工具链升级）而不是回归。
3. `git status` 必须干净（`accept-baseline` 会拒绝 dirty 工作树）。
4. 登记批准基线：
   ```powershell
   python scripts/metrics/trend_db.py accept-baseline `
     --input artifacts/metrics/binaries.json `
     --reason "M84 Spine 2D 接入：wasm +2.56MB raw / +0.79MB gzip，已评审接受"
   ```
   该命令写 `history/<月>.jsonl` + 派生库，run 带 `baseline: true` + `extra.baseline_reason`；
   之后 `check` 对 coverage/binary/package 优先用它作为比较基准。
5. 基线 diff 进评审；`metrics/history/` 的写入按下面这条**明确流程**（2026-11-26 定，替代原来的
   "CI bot 或人工 merge"这句话——它没写清谁做、怎么做，结果实测从未发生过）：
   - **当前仓库采用"人工 merge"模式**：`metrics.yml` 只有 `contents: read`，nightly/weekly 把
     `metrics-history` artifact 上传，不直接写库；
   - 有权限的人（发布负责人）在 nightly 绿后把它落到 `metrics/history/<YYYY-MM>.jsonl` 并提交 PR：
     ```powershell
     # 拿到 artifact 后（或本地已采集）——ingest 带 --history 会同时写派生库与 history JSONL
     python scripts/metrics/trend_db.py ingest --input artifacts/metrics --history metrics/history
     git add metrics/history && git commit -m "metrics(history): <date> nightly 样本"
     ```
   - 若将来给 bot 开 `contents: write`，改为只允许 bot 提交 `metrics/history/**`（docs/69 的权限口径），
     并删掉这条人工步骤；**在此之前不要假设 history 会自动增长**（2026-10-21 之后断了 5 周就是这么来的）。

## 5. 豁免怎么写（allowlist）

`metrics/allowlist.json` 的 `entries`：每条 `{id, domain, reason, owner, review_by}`；
`review_by` 过期 → 判 2，无黄期。豁免不是无限期的：到期要么修好、要么重新确认。

## 6. 哪些数字跨机可比、哪些只是记录

| 域 | 跨机可比？ | 说明 |
|---|---|---|
| 覆盖率（lines/functions/regions %） | 是 | 确定性，同基线比 |
| 几何量/分配次数（draw_calls/instances/alloc_count） | 是 | 确定性，docs/54 红线 |
| 字节数（binary/package） | 是 | 同 commit 打包方差 >2% 先修可复现性 |
| p95/p99/cpu_peak（perf） | 同指纹 | runner 硬件漂移→时间列可标 advisory，几何/字节仍判红 |
| 编译时间（wall_ms） | 同指纹 | 受杀毒/索引影响，只对中位数判红 |
