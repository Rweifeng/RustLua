# 层级面板优化方案：对标 Unity Hierarchy 操作规则

> 本文档以 Unity Hierarchy 面板的成熟操作规则为基准，盘点当前编辑器层级面板
> （`engine/crates/editor/src/panels/hierarchy.rs`）的能力与差距，并给出分优先级的
> 优化条目与验收标准。执行时遵循
> [27-editor-ui-optimization-plan.md](./27-editor-ui-optimization-plan.md) 的状态分层
> 与 [28-editor-ui-optimization-execution-tasks.md](./28-editor-ui-optimization-execution-tasks.md)
> 的事务化约定。

## 1. 现状盘点

当前层级面板已具备的能力：

| 能力 | 现状 | 位置 |
|---|---|---|
| 场景切换 / 新建 / 保存状态 | 下拉列出 `scenes/` 下场景文件，标题栏显示未保存标记 | `draw_hierarchy_panel` |
| 文本过滤 | 按名称递归匹配，命中节点的祖先链强制可见并强制展开 | `hierarchy_filter_matches` / `draw_entity` |
| 树形展示 | 展开/折叠箭头，按深度缩进 | `scene_state.collapsed` |
| 显示 / 隐藏 | eye 图标切换，写入场景 metadata `editor.hidden.*`，Scene View 渲染跳过隐藏实体 | `persist_hierarchy_flag`、`scene_view.rs` |
| 锁定 | lock 图标切换，写入 `editor.locked.*`，Scene View 点选 / Gizmo 跳过锁定实体 | 同上 |
| 选择 | E03 `SelectionModel` 统一选择源；Ctrl/Cmd+点击加选或减选 | `selection.rs` |
| 右键操作 | 每行 `⋮` 按钮弹出菜单：新建子/同级节点、重命名、复制、粘贴为子节点、Prefab、聚焦、UI 根、移动到根、删除 | `draw_entity` |
| 拖拽重挂载 | 单实体拖拽，上/中/下三分区对应 Before/After/Child，循环校验，E09 事务化 + Undo | `dnd_drag_source` 分支 |
| 删除快捷键 | Delete 键按 `DeleteTarget::Hierarchy` 作用选区，删除后选择回退父节点 | `main.rs` `DeleteTarget` |

已确认的缺陷：

- **重命名是坏的（P0 bug）**：`⋮` 菜单的「重命名」实际执行
  `rename_selected()`，且事先把 `entity_name` 拼成 `"{name} Copy"`，
  结果是把实体改名为 `<原名> Copy`，没有提供任何改名输入。
  真正的改名只能绕道 Inspector 的名称输入框。
- 没有行右键上下文菜单（只有每行一个 `⋮` 按钮），空白区域没有 Create 菜单。
- 没有 Shift 范围多选；拖拽 payload 只携带单个实体 ID，无法多选拖拽。
- 没有 Ctrl+D 原地复制；复制/粘贴语义是「剪贴板 + 粘贴为子节点」，与 Unity 不一致。
- 没有双击 / F2 行内重命名，没有 ↑↓←→ 键盘导航。
- 没有头部「+」新建入口，点击面板空白区域不会取消选择。
- 折叠状态是会话态（切换场景即清空），未按文档 27 的约定持久化到编辑器配置。
- eye/lock 图标常驻显示且位于行首，与 Unity「hover 或选中时出现在行尾、
  未激活时弱化」的习惯不同；没有缩进参考线和实体类型图标。

## 2. Unity 操作规则对照表

| Unity 规则 | 当前状态 | 差距 | 优先级 |
|---|---|---|---|
| 点击单选；Ctrl/Cmd 加减选；Shift 范围选 | 前 1.5 项已有 | 无 Shift 范围选 | P1 |
| 双击 / F2 行内重命名，Enter 提交、Esc 取消 | 缺失，且菜单入口有 bug | 全部缺失（先修 bug） | P0 |
| Ctrl+D 原地复制（同父、紧随源节点，名称与源一致） | 缺失 | 只有剪贴板复制/粘贴 | P1 |
| Delete 直接删除整棵子树，可 Undo，不弹确认 | 已有 | 无 | - |
| 拖拽多选重挂载；上/中/下分区指示线；禁止拖入后代 | 单选拖拽已事务化 | 多选拖拽缺失 | P1 |
| 行右键实体菜单；空白右键 Create 菜单；头部「+」按钮 | 仅每行 `⋮` 按钮 | 行右键、空白菜单、「+」均缺 | P0 |
| ↑/↓ 移动选择，←/→ 折叠或跳转，F 聚焦 | 仅 F 有菜单入口 | 键盘导航全部缺失 | P1 |
| 过滤框有占位提示、一键清空、命中高亮与计数 | 只有递归匹配 + 强制展开 | 视觉与反馈缺失 | P2 |
| Alt+点击折叠整棵子树；折叠状态持久化到编辑器配置 | 折叠会话态，切场景清空 | Alt 折叠与持久化均缺 | P2 |
| eye/lock hover 或选中时显示，未激活时弱化；隐藏影响 Scene View 渲染 | 图标常驻行首；渲染/拾取联动已有 | 布局与显隐策略不同 | P2 |
| 点击空白取消全选 | 缺失 | 全部缺失 | P2 |

## 3. 优化条目

### H01（P0）：修复重命名 + 右键上下文菜单

**目标**：让「改名」真正可用，把实体操作从每行 `⋮` 按钮迁移到 Unity 风格的右键菜单，
并补齐创建入口。

**实现要点**

- 删除 `draw_entity` 中「重命名」按钮的 `"{name} Copy"` 拼接逻辑；
  菜单项改为触发 H02 的行内重命名。
- 用 egui 的 `response.context_menu()` 在整行响应上挂实体菜单，
  菜单项与现有 `⋮` 菜单等价（新建子/同级、重命名、复制、粘贴为子节点、
  创建/重新应用 Prefab、聚焦、设为 UI 根、移动到根、删除）；`⋮` 按钮保留为触达性兜底。
- 面板空白区域右键弹出 Create 菜单（新建空实体、新建 3D 实体、粘贴）；
  头部新增「+」按钮，展开同一 Create 菜单，父级取当前主选中（无选中时挂根）。
- 菜单中与 Play 模式互斥的项保持现有锁定提示。

**验收标准**

1. 菜单点「重命名」后行内出现文本框，修改后 Enter 生效、Esc 取消（H02 落地前可先跳 Inspector 聚焦名称框，但不得再出现 `<原名> Copy` 行为）。
2. 右键任意实体行弹出实体菜单，功能与 `⋮` 一致。
3. 空白处右键与头部「+」均可创建实体；Play 模式下创建/删除项给出锁定提示。

### H02（P1）：行内重命名

**目标**：Unity 风格的双击 / F2 重命名。

**实现要点**

- `EditorApp` 新增 `hierarchy_rename: Option<(SceneEntityId, String)>` 状态
  （改名中的实体 + 输入缓冲），不与 Inspector 共用 `entity_name`，避免互相覆盖。
- 行被双击、或行选中状态下按 F2 时进入编辑态；渲染时该行用
  `text_edit_singleline` 替换名称按钮，`request_focus` 并全选文本。
- 提交条件：`lost_focus && enter_pressed`；Esc 或点击其他区域取消。
  提交走 `tree.rename`（`CommandKind::Rename`），空名保持 `EmptyName` 校验并留在编辑态。
- 过滤态下同样可用；改名成功后 `on_document_changed(EntityRenamed)`。

**验收标准**

1. 双击实体名或选中后按 F2 进入编辑；Enter 提交并产生一条可撤销的历史。
2. Esc 取消不产生历史、不改名；空名提交被拒绝并保持编辑态。
3. 改名后 Inspector、Scene View、过滤匹配即时反映新名称。

### H03（P1）：多选增强

**目标**：Shift 范围选、多选拖拽、多选批量操作。

**实现要点**

- 绘制层维护当前帧「可见顺序表」`visible_order: Vec<SceneEntityId>`
  （过滤态即为过滤后的先序遍历），`EditorApp` 记录 Shift 锚点
  `selection_anchor: Option<SceneEntityId>`。
- Shift+点击：以锚点到被点击行之间的可见连续区间 `set_many`；
  锚点不可见（被过滤/折叠）时退化为单选。Ctrl/Cmd 加减选沿用现有 `toggle`。
- 多选拖拽：拖拽 payload 携带主选中 ID，落点结算时取「选中集合中的顶层根」
  （祖先也在选区内的子孙剔除）逐个 `validate_reparent_target` + `reparent_at`，
  整批包在一个编辑事务内，任一校验失败整批取消。
- 右键菜单增加批量项：删除全部选中、隐藏/锁定全部选中（写各自 metadata）。

**验收标准**

1. Ctrl+点击与 Shift+点击组合符合上表语义，且过滤态下范围选不越界。
2. 多选拖拽一次落点只产生一条 Undo 记录；把选中集合拖入自身后代被整批拒绝。
3. 批量删除/隐藏/锁定按选中集合生效并全部可撤销。

### H04（P1）：快捷键与键盘导航

**目标**：补齐 Unity 的键盘操作闭环。

**实现要点**

- Ctrl+D：`duplicate_selected()` —— 取主选中实体，`duplicate_subtree` 到
  **原父节点**，随后 `reparent_at(copy, source, After)` 紧贴源节点之后；
  名称与源一致；一个 `CommandKind::Create` 事务。根节点复制利用
  `reparent_at` 的根序持久化路径。
- F2 / Delete / F：F2 触发 H02；Delete 沿用 `DeleteTarget::Hierarchy`；F 调用现有 `focus_selected_scene_view`。
- ↑/↓：在可见顺序表中移动单选（跳过不可见行）；→ 展开当前行或进入首个子节点；
  ← 折叠当前行，已折叠则跳转父节点。
- 焦点护栏：任何文本框（过滤、重命名、Inspector 输入）持有焦点时不消费上述按键；
  面板无选中时 ↑↓ 不做任何事。

**验收标准**

1. Ctrl+D 复制体出现在源节点正下方（兄弟位置），Undo 一步整体消失。
2. ↑↓←→ 在折叠/过滤混合状态下行为符合预期，不与过滤框输入冲突。
3. F 聚焦后 2D/3D Scene View 均以选中实体为目标。

### H05（P2）：过滤框升级

**实现要点**

- 过滤框加占位文本「搜索实体」；非空时右侧显示清空按钮与命中数「N 项」。
- 命中节点名称用富文本高亮匹配片段；过滤态下折叠箭头已被强制展开逻辑覆盖，
  保持现状即可。

**验收标准**：输入即时过滤 + 高亮 + 计数；清空按钮一键恢复完整树并保留手动展开状态。

### H06（P2）：视觉与状态对齐

**实现要点**

- eye/lock 图标移到行尾，hover 或选中时显示；未激活（可见/未锁定）时弱化或隐藏，
  激活（隐藏/锁定）时常驻提示。
- 行首展开箭头后增加实体类型图标（2D 实体、3D 实体、UI 根节点）；
  深度缩进旁绘制垂直参考线。
- 折叠状态持久化：在编辑器会话/配置文件中按场景标识保存
  `collapsed` 集合（不写入场景文件，符合文档 27 的状态分层）；
  Play/Stop 快照机制（`hierarchy_collapsed`）保持不变。
- Alt+点击展开箭头：折叠/展开整棵子树（递归写 collapsed 集合）。

**验收标准**：图标布局与 Unity 习惯一致；重启编辑器或切换场景后折叠状态恢复；
Alt+点击一键折叠整棵子树且可逐层展开回去。

### H07（P2）：空白区交互

**实现要点**

- 树区域底部填充一段可点击区域：左键点击执行 `selection.clear(Hierarchy)`，
  右键打开 H01 的 Create 菜单。

**验收标准**：点击空白处取消选择并同步清空 Inspector；右键弹出创建菜单。

## 4. 决策点

| 编号 | 决策 | 说明 |
|---|---|---|
| D1 | hidden/locked 继续持久化到场景 metadata | Unity 的 eye 是瞬态，但本引擎的隐藏/锁定同时约束 Scene View 渲染与拾取，作为编辑意图持久化是产品需求；文档与 UI 文案明确其为「编辑器可见性」而非运行时属性 |
| D2 | 复制体名称与源一致 | 与 Unity Duplicate 行为一致，不引入 `Copy` 后缀 |
| D3 | 折叠状态不写入场景文件 | 按文档 27 状态分层，折叠属于编辑器会话状态 |
| D4 | 多选拖拽原子性 | 整批一个事务，任一目标校验失败整批回滚，避免半挂载状态 |

## 5. 测试计划

单元测试（`hierarchy.rs` / `scene_tree_state.rs`）：

1. Shift 范围选择计算：可见顺序表上取连续区间、锚点不可见退化为单选。
2. 多选拖拽顶层根提取：选中 {父, 子} 时拖拽集合只含父。
3. duplicate-in-place：子节点与根节点两种情况下复制体位于源节点之后，Undo 可整体回滚。
4. 行内重命名：Enter 提交产生一条 Rename 历史；空名拒绝；Esc 无副作用。
5. 批量隐藏/锁定：metadata 键按实体 ID 独立写入。

手工验收清单：

- 无场景 → 新建场景 → 「+」创建实体 → 双击重命名 → Ctrl+D → Shift 多选 →
  多选拖拽 → 批量删除 → Ctrl+Z 全链路。
- 过滤态下的选择、重命名、键盘导航、范围选退化。
- Play 模式下创建/删除/重命名/拖拽全部给出锁定提示且不产生历史。
- 切换场景、Play/Stop、重启编辑器后折叠状态与选择行为符合第 3 节验收标准。

## 6. 风险与回归

- egui 中 `context_menu` 与 `dnd_drag_source` 叠加时右键事件可能被拖拽响应吞掉，
  需验证菜单挂在外层行响应上；不行则以 `secondary_clicked()` 自绘菜单。
- 键盘导航依赖绘制期构建的可见顺序表，需保证该表每帧与实际渲染一致，
  否则 ↑↓ 会跳行或漏行。
- 多选拖拽落点计算要把「先移走的兄弟」对后续兄弟插入位置的影响考虑进去
  （与现有 `reparent_at` 的 retain-then-insert 顺序一致）。
- 回归范围：场景切换、Play/Stop 快照、Undo/Redo、Prefab 创建/重应用、
  Scene View 点选与 Gizmo、文档 28 的 E03/E07/E09 既有验收项。
