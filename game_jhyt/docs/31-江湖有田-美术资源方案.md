# 《江湖有田》美术与音频资源方案

- 文档版本：0.2
- 本版同步：总策划案 0.2、开发计划 0.2
- 目标：建立可用于原型、垂直切片和商业化版本的资源获取、制作、导入和授权流程

## 1. 总体策略

采用“三层资源策略”：

1. **原型层**：优先使用 CC0 或明确允许商业使用的通用资源，快速验证玩法。
2. **垂直切片层**：购买或委托统一风格的中国武侠素材，完成对外展示。
3. **正式发行层**：关键角色、Logo、主线场景、Boss、UI 和宣传图使用原创或专属委托资源。

不要把多个不同画风的免费资源直接拼在一起作为最终版本。所有外部资源先进入许可证登记，再进入 `assets/`。

## 2. 资源目录建议

```text
assets/
├── art/
│   ├── tilesets/       # 地面、道路、山林、洞窟、室内
│   ├── characters/     # 玩家、NPC、敌人
│   ├── crops/          # 作物、药材、成长阶段
│   ├── props/          # 家具、工具、建筑部件
│   ├── weapons/        # 刀、剑、棍、暗器
│   ├── effects/        # 攻击、受击、天气、采集
│   ├── portraits/      # 对话头像
│   └── ui/             # 面板、按钮、图标、字体
├── audio/
│   ├── music/
│   ├── ambience/
│   └── sfx/
├── fonts/
├── data/
└── licenses/
    ├── ASSET_REGISTER.tsv
    └── <asset-id>.txt
```

## 3. 资源清单

### 3.1 Tilemap 与环境

| 类别 | MVP 数量 | 首发数量 | 要求 |
|---|---:|---:|---|
| 山庄地面 | 3 套 | 8 套 | 土地、草地、石板、木地板 |
| 村庄环境 | 2 套 | 6 套 | 街道、河岸、集市、屋檐 |
| 山林 | 2 套 | 6 套 | 树木、岩石、竹林、溪流 |
| 洞窟 | 1 套 | 3 套 | 墙体、矿脉、机关、火把 |
| 室内 | 2 套 | 8 套 | 药庐、铁匠铺、客栈、门派 |
| 装饰物 | 40 件 | 150 件 | 牌匾、灯笼、旗帜、石碑、屏风 |

建议统一 Tile 尺寸为 32×32，角色碰撞脚底约 12×8 像素，地图按 32 像素网格设计。若选择 16×16 资源，导入阶段统一放大 2 倍，不要在同一地图混用不同逻辑网格。

### 3.2 角色

MVP 最少需要：

- 玩家 1 套基础服装、4 方向行走、待机、工具动作、攻击、受击、死亡，共约 32–48 帧；
- 3 个 NPC，每人 4 方向行走、待机、交互姿态，共约 12–20 帧；
- 1 个山贼，待机、移动、攻击、受击、死亡，共约 16–24 帧。

正式版本建议：

- 玩家 3 套服装、4 种武器动作；
- NPC 10–12 人；
- 普通敌人 8 种、Boss 3 个；
- 对话头像至少 12 张，关键剧情表情 4–6 套。

### 3.3 作物、药材和物品

每个可种植对象建议提供：

```text
种子图标、芽期、幼苗期、成熟期、收获动画、掉落物图标、品质变体
```

MVP 资源：稻谷、灵芝。扩展资源：茶苗、何首乌、人参、毒草、雪莲、莲子、芦苇。

物品图标建议 32×32，使用统一描边、光源方向和背景透明规则。武器、药剂、材料、礼物和任务物品共准备 60–100 个图标即可覆盖首发。

### 3.4 UI 与字体

需要：

- 背包、商店、对话、任务、武学、建筑放置、存档、设置面板；
- 生命、体力、内力、时间、日期、金钱和快捷栏；
- 物品品质、状态效果和交互提示；
- 中文字体至少覆盖项目实际字符，发布时使用现有字体子集化流程；
- 高对比度模式、字号调整和纯键盘操作应在 Beta 前验证。

UI 设计建议使用深墨灰、朱砂红、竹青、米白和旧金色作为基础色，面板边角采用木纹或宣纸意象，但应保证文字和按钮的可读性。

### 3.5 特效

MVP：

- 锄地尘土；
- 播种闪光；
- 浇水水花；
- 收获跳字；
- 刀光；
- 命中火花；
- 受击闪白；
- 轻功残影；
- 治疗和中毒提示。

正式版本再增加天气、剑气、Boss 技能和节日烟花。当前引擎已有基础粒子能力，但复杂序列特效建议先用 Sprite sheet 动画，不要立即投入通用 VFX 编辑器。

### 3.6 音乐、环境音和音效

MVP 音频包：

- 山庄日间 BGM 1 首；
- 村庄 BGM 1 首；
- 山道 BGM 1 首；
- 夜间 BGM 1 首；
- 战斗 BGM 1 首；
- 雨、风、溪流、鸟鸣各 1 组；
- 锄地、播种、浇水、收获、脚步、挥刀、命中、受击、开门、UI 点击各 1–3 个变体。

正式版本可增加四季 BGM、节日主题、洞窟环境、门派主题和 NPC 主题动机。避免直接使用来源不明的“古风音乐”或影视剧音频。

## 4. 资源来源与用途

### 4.1 优先来源

- [Kenney Game Assets](https://kenney.itch.io/kenney-game-assets)：页面标注 CC0，适合原型中的通用 UI、自然、家具、道具和音频。风格偏通用，需要统一调色或仅作为占位。
- [Kenney Isometric Assets](https://kenney.itch.io/kenney-isometric-assets)：可参考建筑和环境构图；本项目为俯视角，使用前需确认透视是否适配。
- [OpenGameArt FAQ](https://opengameart.org/content/faq)：资源授权说明入口。该站资源授权逐条判断，不能把网站整体视为同一许可证。
- [Freesound License FAQ](https://freesound.org/help/faq/#licenses)：音效来源。只选 CC0 或允许商业使用的 CC-BY，并保留署名记录。
- [GameCreator 素材工坊](http://www.gamecreator.com.cn/material)：寻找古风像素、UI、行走图和图块；必须逐个资源核对商业授权和二次分发限制。
- [爱给网 2D 素材](https://m.aigei.com/game2d/lib/)：可用于参考和筛选古风资源；来源不明、仅预览图或非商业条目不得进入发行包。
- [HTgame2089-X](https://htgame2089-x.itch.io/)：中国神话和古代场景资源，可作为山门、寺庙、雪山和秘境方向的候选；购买前核对具体许可。
- [Seliel the Shaper](https://seliel-the-shaper.itch.io/)：16×16/16-bit 地图和室内资源，可作环境原型或参考；确认脱离 Unity 使用和商业发行条款。
- [30 Pixel Mythology](https://pixelartmaterial.itch.io/cp48-30-pixel-mythology-png-mlll)：中国神话角色、神兽、怪物方向的候选资源；页面声明商业使用和修改，但禁止重新分发原始或修改后的资源包，需保留版权信息。
- [Game-icons.net](https://game-icons.net/)：武器、药材、状态和技能图标候选，通常需要 CC-BY 署名；逐个图标记录作者。
- [Poly Haven](https://polyhaven.com/)：CC0 3D 模型、材质和 HDRI，适合宣传图或后续 3D 展示，不是当前 2D MVP 首选。

### 4.2 推荐采购组合

**MVP 原型**：Kenney CC0 通用环境 + 自制颜色表 + 自制玩家占位 + Game-icons 图标 + CC0 音效。

**垂直切片**：购买一套风格统一的 16-bit 中国古代/神话环境包；委托原创玩家、3 个 NPC、山贼和关键建筑；保留通用 CC0 资源作为背景装饰。

**正式版本**：关键角色、Logo、对话头像、Boss、主线场景、UI 皮肤和宣传图全部原创或专属委托；外部资源仅作为可替换的非核心装饰。

## 5. 许可证登记规范

每项资源必须在 `licenses/ASSET_REGISTER.tsv` 登记：

```text
asset_id	名称	类型	作者	来源URL	下载日期	版本	许可证	可商用	可修改	需署名	禁止再分发	使用位置	备注
```

许可证决策：

- CC0：优先，可商用，通常无需署名；仍建议记录作者和来源。
- CC-BY：可商用、可修改，但必须在 Credits 或许可证页署名。
- CC-BY-SA：需确认衍生作品的再许可义务，不用于关键商业资产，除非明确接受其传播条件。
- CC-BY-NC：不用于商业项目。
- GPL 或其他强传染授权：不将其图像、音频和字体混入商业发行包，除非完成法律审核。
- 网站自定义许可：保存购买凭证、许可页面 PDF/文本和下载版本。
- 授权不明：不使用。

## 6. 导入规范

- 纹理优先 PNG，透明背景，避免把 JPG 作为像素角色源文件；
- Sprite sheet 在导入前确定帧尺寸、列数、行数、播放速度和原点；
- Tilemap 所有图块使用统一逻辑尺寸和像素密度；
- 音效优先 WAV/OGG，统一采样率并控制峰值，避免播放时削波；
- 字体使用已有 Font importer，并在打包阶段执行字符收集与子集化；
- 文件命名使用小写英文、数字和下划线，中文显示名放进 JSON 数据表；
- 每个资源必须能通过 `assetc scan`、`assetc import` 和 `assetc --check-deps`；
- 发布前用 `assetc package` 生成 manifest，禁止从素材网站临时 URL 加载。

## 7. 美术制作优先级

P0：玩家、山庄地面、药田、村庄地面、山贼、稻谷、灵芝、背包 UI、中文字体、基础特效。

P1：NPC、药庐、铁匠铺、山道、商店 UI、头像、工具动作、天气和节日装饰。

P2：门派地图、Boss、多套服装、四季变体、复杂技能特效、宣传图和动态标题。

## 8. 版本交付资源门槛

### MVP 垂直切片

- 3 张灰盒地图均有统一 Tile 尺寸、碰撞标记和入口资源；
- 玩家、3 个 NPC、山贼具备完成核心流程所需的动作；
- 稻谷、灵芝具备种子、成长阶段、成熟和收获图标；
- 背包、商店、对话、任务和 HUD 使用同一套中文字体与色板；
- 核心音效至少覆盖劳动、交互、攻击、受击、收获和 UI 点击；
- 所有进入构建包的资源均已完成许可证登记。

### Alpha

- 寒泉洞、药庐、青云门入口具备可识别环境差异；
- 4 种敌人和 1 个 Boss 具备独立轮廓、受击反馈和攻击提示；
- 第一章关键 NPC 有头像与至少一套情绪变化；
- 缺失或导入失败资源能在构建日志中定位，不允许静默替换为最终资源。

### 首发

- 关键角色、Logo、主线场景、Boss、UI 皮肤和宣传图为原创或专属授权；
- Credits、第三方声明和许可证清单与发行包版本一致；
- 发行包不通过临时 URL、源码路径或开发机绝对路径加载资源；
- Windows 干净目录完成启动、切图、存档和资源完整性检查。

## 9. 资源验收记录

每批资源验收记录至少包含：资源批次、负责人、导入工具版本、尺寸/帧数检查、透明度检查、命名检查、运行时预览、许可证状态、缺陷编号和结论。
