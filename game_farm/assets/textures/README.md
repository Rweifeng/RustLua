# 整理版主素材

这里存放的是从 `assets/third_party/` 中挑出的可直接使用候选图。

它是“统一命名后的工作层”：保留来源差异，但先把目录和命名整理好，便于后续继续筛选、拆图集和接入引擎。

在它之上，另外有一个 `assets/curated/` 目录，专门存放按玩法主题二次挑选出的精选组合，适合快速搭农场、小镇、室内和采集原型。

分类说明：

- `environment/`：地形与场景物件
- `interior/`：家具、墙体和室内装饰参考图
- `animals/`：低约束动物表与可直接候选使用的动物素材
- `crops/`：作物、种子和作物表
- `town/`：小镇道路、建筑外观与街景 tilemap
- `fish/`：鱼类、水草、水域背景和海洋小生物
- `mining/`：矿石、矿物和采集物图标
- `foraging/`：花草、蘑菇和野外拾取物
- `food/`：食物、饮料、料理和厨房图标
- `town_props/`：路灯、指示牌和街道摆设
- `kitchen/`：餐具、桌椅和厨房/餐厅小摆设
- `storage/`：货盘、木箱和仓储杂物
- `materials/`：木料、石料、干草和建材贴图
- `shop/`：书架、货架和店铺陈列物
- `items/`：工具与通用拾取物
- `characters/`：角色与坐骑样例
- `ui/`：按钮、面板、HUD 与图标

命名规则：

- 统一使用小写下划线风格
- 文件名末尾保留来源标记，例如 `_kenney`、`_anwar`、`_scratchio`

注意：

- 当前文件仍然以“原图整理”为主，还没有做统一尺寸、统一调色和图集切分
- 正式接入运行时之前，建议再做一轮像素规格清洗
- `assets/curated/` 中的文件都来自这里的复制件，`assets/textures/` 仍然是后续继续扩充和重组的主工作目录
