## `ui.nav_stack(command: Table)`

> 绑定：`engine/crates/rustlua-ui/src/lua_advanced.rs:415`（直写）；签名由 `scripts/docgen/gen-lua-api-docs.js` 从绑定源码推断，需人工核对。

页面导航栈与模态遮罩。返回键语义固定：先关最上层模态，再弹出一页，根页不响应返回；
弹出时把进入该页前记下的焦点 id 交回调用方，避免返回后焦点落空。

- 参数：命令表 `{ op=… }`。`open{root=名字}` 建栈并返回页深；`state` 读状态；
  `push{page, restore_focus?}` 压页；`modal{id, restore_focus?}` 压模态（不增加页深）；
  `back` 返回 `{kind="modal"|"page"|"root"|"empty", id/page?, focus?}`；
  `close_modal{id}` 按 id 关模态，返回要恢复的焦点（无则 `-1`）。
- 返回：`open` 为页深整数；`push`/`modal` 为最新状态表
  `{depth, current, modal, accepts_input}`（有模态时 `accepts_input=false`）；
  `state` 为状态表；`back` 为结果表；未初始化时读操作返回 `nil`。
- 失败：缺少 `op`/`root`/`page`/`id`、未知 op、`close_modal` 指向不存在的模态时报错。
- 示例：`ui.nav_stack{ op="open", root="title" }`、
  `ui.nav_stack{ op="push", page="bag", restore_focus=7 }`、
  `local out = ui.nav_stack{ op="back" }`

## `ui.rich_text(text: String)`

> 绑定：`engine/crates/rustlua-ui/src/lua_advanced.rs:292`（直写）；签名由 `scripts/docgen/gen-lua-api-docs.js` 从绑定源码推断，需人工核对。

解析受限富文本。只认 `<b>`、`<color=#rrggbb>`、`<icon=name>`、`<br/>` 四种标签；
其余尖括号内容按字面量保留并记入 `unsupported`，外部文本不能借标签改变排版或执行指令。

- 参数：`text` —— 待解析的富文本源串。
- 返回：`{plain, lines, spans, unsupported}`。`spans` 每项为
  `{text, bold, color, icon, line_break}`（`icon` 非空时 `text` 为空，表示图标占位）；
  `plain` 是去掉标签后的纯文本，供朗读与宽度估算。
- 失败：不因未闭合或未知标签报错（标签原样保留），仅类型不符时报错。
- 示例：`local r = ui.rich_text("<b>金币</b> <color=#ffcc00>+12</color><br/><icon=coin>")`

## `ui.text_input(command: Table)`

> 绑定：`engine/crates/rustlua-ui/src/lua_advanced.rs:304`（直写）；签名由 `scripts/docgen/gen-lua-api-docs.js` 从绑定源码推断，需人工核对。

文本输入状态与 IME 最小支持。光标/选区都以**字符**下标表示（不是字节），中文与 emoji
不会被切半；预编辑文本单独存放，提交时才落正文。

- 参数：命令表 `{ op=… }`。`open{id, text?}` 建输入并聚焦，返回光标位置；
  `close{id}`；`state{id}`；`edit{id, action, value?/index?}`，`action` 取
  `insert/backspace/delete/left/right/home/end/select_all/set_cursor/focus/blur`；
  `composition{id, action=begin|update|commit|cancel, value?}`；
  `policy{host=desktop|web|wechat, bridge?}` 查询该宿主的输入后端与能力。
- 返回：`open` 为光标整数；`edit`/`composition` 为状态表
  `{text, cursor, selection, focused, composition, committed?}`；`policy` 为
  `{backend, supports_selection, note}`；未登记的 id 返回 `nil`。
- 失败：缺少 `op`/`id`/`action`、未知 op 或 action、`set_cursor` 传负数时报错。
- 示例：`ui.text_input{ id="name", op="open", text="角色" }`、
  `ui.text_input{ id="name", op="edit", action="insert", value="名" }`、
  `local p = ui.text_input{ op="policy", host="wechat", bridge=false }`

## `ui.virtual_list(command: Table)`

> 绑定：`engine/crates/rustlua-ui/src/lua_advanced.rs:173`（直写）；签名由 `scripts/docgen/gen-lua-api-docs.js` 从绑定源码推断，需人工核对。

虚拟列表：把上千项按固定行高映射成「可见窗口 + 有限槽位」。布局只绑定窗口内的行，
滚出窗口的 key 释放回槽位池，key 稳定时同一项始终复用自己的槽位。

- 参数：命令表 `{ op=… }`。`open{id, total, viewport, item_height, spacing?, overscan?}`
  （`item_height > 0`，`viewport/spacing >= 0`，`overscan` 默认 2、上限 64）；
  `close{id}`；`scroll{id, delta}`；`scroll_to{id, index}`；`window{id}`；
  `bind{id, keys?}`（`keys` 提供时必须与可见行数等长）。
- 返回：`open`/`window` 为 `{start, end, offset, total_height}`（`end` 为开区间）；
  `scroll` 为实际位移；`scroll_to` 为是否发生滚动；`bind` 为行数组，每行
  `{index, key, slot, x, y, content_y, width, height}`（`y` 已减去窗口偏移）。
  未登记的 id 返回 `nil`。
- 失败：缺少 `op`/`id`、`item_height` 非正、`viewport`/`spacing` 为负、`keys` 长度不匹配、
  未知 op 时报错。
- 示例：`ui.virtual_list{ id="bag", op="open", total=1000, viewport=200, item_height=20 }`、
  `local rows = ui.virtual_list{ id="bag", op="bind" }`
