# 《江湖有田》总策划案

- 文档版本：0.3（体验收口修订；未标明落地的正文仍为目标设计）
- 当前执行补充：[体验收口与执行基线](<72-江湖有田-体验收口与执行基线.md>)；按数据/系统/交互/体验四层区分完成度，不以历史样例绿灯替代可玩验收。
- 产品形态：单机 2D 俯视角生活模拟 + 轻动作 RPG
- 首发平台：Windows PC
- 后续平台：WebGL；微信小游戏仅在专用适配完成后评估
- 引擎基线：RustLua Rust + Lua 游戏引擎
- 目标：先完成可独立发行的“武侠农庄”核心体验，再扩展江湖内容
- 本版重点：锁定 MVP 闭环、数值边界、内容验收口径和首发版本拆分

## 1. 产品定位

### 1.1 一句话定位

玩家继承一座破败山庄，在耕种药田、经营医馆、修习武学和结交江湖人物的过程中，逐步重建家园，揭开师门旧案，并决定自己最终成为隐士、名侠、掌门还是商贾。

### 1.2 体验关键词

- 春种秋收：土地、药材、茶园和四季生产。
- 日常修行：打坐、练功、试招、读经和提升经脉。
- 江湖往来：村民、门派、镖局、医馆、商贩与敌对势力。
- 小规模冒险：山道、洞窟、秘境和剿匪任务。
- 家园成长：从破旧药庐升级为有田、有铺、有武馆的山庄。
- 有选择的江湖：侠义、利欲、门派忠诚和自由隐居影响剧情结局。

### 1.3 目标玩家

- 喜欢《星露谷物语》、牧场经营、采集制作和 NPC 关系的玩家；
- 喜欢中国武侠世界观，但不希望承担大型 MMO 复杂度的玩家；
- 喜欢像素美术、轻量动作战斗和有明确成长反馈的玩家；
- 首发以单人 PC 玩家为主，不承诺联机、主机和微信小游戏。

## 2. 设计边界

### 2.1 首发版本不做

- 无缝开放世界；
- 多人联机和玩家交易；
- 复杂恋爱模拟和婚后生活；
- 大规模攻城战；
- 复杂装备随机词条；
- 需要高端 GPU 的 3D 场景；
- 微信小游戏原生包；
- 直接复刻《星露谷物语》的角色、地图、文本或美术资产。

### 2.2 合规原则

本作只借鉴“生活模拟 + 农场经营 + 冒险成长”的类型结构，不使用《星露谷物语》的角色、地点、音乐、素材、对白、剧情或可识别 UI。所有中国武侠内容、角色和资源均原创或取得明确授权。

## 3. 世界观

### 3.1 世界

天下名为“九州”，江湖由官府、门派、镖局、商会和地方宗族共同维系。武学并非超自然魔法，而是内功、身法、器械和医术的极致运用。少数失传绝学可以产生夸张但仍具武侠审美的表现，例如剑气、暗器机关和短距离轻功。

### 3.2 起始地区

故事发生在“江南云泽县”。县城外有一座废弃山庄，庄后原有药田和茶园，北面连接青云山。玩家的师父多年前被指认为盗取门派秘笈的叛徒，山庄也因此荒废。师父留下的账册、药谱和半部剑诀，是玩家重新开始的全部资本。

### 3.3 核心冲突

“玄冥会”正在收购云泽县的土地和药材，借镖局、黑市和伪造官契控制地方经济。他们寻找师父当年守护的《归藏经》残页。玩家需要在经营山庄与调查旧案之间做出选择：重建门派秩序、与黑市合作获利，或放弃江湖纷争守住一方田园。

## 4. 角色与阵营

### 4.1 玩家

玩家可自定义姓名、性别、肤色、发型、服装主色和初始武器。背景选择只改变初始配方和少量对话，不改变主线：

| 背景 | 初始优势 | 初始代价 |
|---|---|---|
| 药童 | 药材识别、制药等级 +1 | 武器伤害较低 |
| 镖师 | 体力、负重和基础刀法较高 | 初始资金较少 |
| 书生 | 读经、对话和鉴定能力较高 | 种植效率较低 |
| 浪客 | 闪避和探索收益较高 | 与门派初始关系较差 |

### 4.2 主要 NPC

| NPC | 身份 | 功能 | 关系主题 |
|---|---|---|---|
| 沈青萝 | 医馆掌柜 | 药材、制药、医疗任务 | 仁心与经营 |
| 顾长风 | 退隐镖师 | 基础刀法、战斗训练 | 责任与旧债 |
| 苏晚晴 | 青云门弟子 | 剑法、门派任务 | 守规与自由 |
| 赵铁算盘 | 集市商人 | 买卖、价格和订单 | 利益与诚信 |
| 林小满 | 茶农 | 茶园、天气和节气知识 | 乡土与互助 |
| 玄鹤 | 云游道士 | 内功、观星和特殊事件 | 隐逸与因果 |
| 韩铁山 | 铁匠 | 工具、武器和建筑升级 | 手艺与传承 |
| 阿七 | 年轻镖师 | 山道、护送和支线 | 冒险与成长 |

### 4.3 阵营

- 云泽百姓：关注物价、治安、粮食和医疗。
- 青云门：关注武学传承、门规和声望。
- 护安镖局：关注护送、路线安全和契约。
- 云泽商会：关注贸易、订单和利润。
- 玄冥会：提供高利润但高风险的黑市业务。

## 5. 核心循环

```text
起床 → 查看天气/日程 → 务农、采集、制作或练功
    → 与 NPC 互动/完成任务 → 进山探险或处理事件
    → 出售货物、购买材料、升级家园 → 返回山庄
    → 睡觉结算 → 作物成长、NPC 日程、市场和剧情推进
```

### 5.1 每日资源

- 体力：耕地、砍伐、采矿和近战攻击消耗。
- 内力：武学招式、轻功和特殊互动消耗。
- 时间：每日 06:00 至 24:00；建议 1 游戏小时 = 现实 45 秒，可调试加速。
- 金钱：铜钱，用于购买种子、工具、配方和建筑。
- 声望：村民、青云门、镖局、商会、玄冥会分别记录。

### 5.2 日结算

睡觉时依次执行：

1. 保存玩家、背包、家园、地图和全局变量；
2. 结算作物成长、浇水状态和季节变化；
3. 执行 NPC 次日计划；
4. 计算商店库存、订单和市场价格；
5. 触发生日、节气、天气和主线事件；
6. 生成第二天的可交互对象和任务；
7. 写入日志，便于复现存档问题。

## 5.3 MVP 数值边界与节奏

MVP 以 7 天垂直切片为标准，不追求完整四季内容。以下数值是首轮可玩性基线，实际实现后只允许在评审记录中调整：

| 项目 | 基线 | 设计目的 |
|---|---:|---|
| 每日时段 | 06:00–24:00 | 保证一天可完成 2–4 类活动 |
| 现实时间 | 1 游戏小时约 45 秒 | 兼顾探索和经营，不让等待成为主流程 |
| 初始体力 | 100 | 一天完成约 12–18 次基础劳动 |
| 体力消耗 | 锄地/浇水/采集 5–10 | 让玩家必须选择活动组合 |
| 初始内力 | 50 | 当前状态表基线；恢复与技能消耗以数值案及运行时为准 |
| 睡觉条件 | 允许任意时间睡觉 | 避免玩家被迫耗尽时间；提前睡觉只推进一天 |
| MVP 目标时长 | 30–60 分钟 | 新玩家完成一次完整闭环 |
| 7 日结算 | 第 1、3、5、7 天有明确目标 | 每 1–2 天提供一次反馈或剧情推进 |

### 5.4 新玩家引导与失败保护

> 下列为目标设计，不是现行实现清单。当前地图出口没有首日山道门槛，早期采药路线依赖山道；实施封锁前必须提供替代药材来源。新手阶段拆分、存档迁移与真人测时要求见[体验收口基线](<72-江湖有田-体验收口与执行基线.md>)。

- 目标：第 1 天优先引导山庄和云泽村；是否锁山道需先验证任务材料供给，不直接加门槛。
- 第 1 次战斗前由顾长风演示攻击、闪避、受击和撤退；不把关键操作只写在说明文字中。
- 任务目标同时显示文字、地图标记和当前进度；交付前提示缺少物品。
- 体力耗尽只禁止继续劳动，不直接导致死亡；生命归零才触发回庄。
- 死亡回庄保留已种下作物、建筑和任务进度，只损失当天未入库的部分掉落与少量金钱。
- 关键剧情物品进入任务栏，不允许被出售、丢弃或被死亡惩罚移除。

## 6. 农业、药田与生产

### 6.1 土地类型

- 普通耕地：种植稻谷、茶苗和常规作物。
- 药田：适合灵芝、人参、何首乌等药材，升级后提高品质。
- 湿地：适合莲子、芦苇和毒草，雨天产量增加。
- 茶园：多年生作物，首次种植成本高，之后周期性采摘。

### 6.2 作物生命周期

```text
未开垦 → 已翻土 → 已播种 → 已浇水 → 生长 1/2/3 阶段 → 可收获
```

每个作物数据包含：

```text
id、名称、季节、成长天数、种子价格、售价、产量、品质概率、是否可再生、所需土地类型、收获产物、图标和动画。
```

### 6.3 首发作物

| 作物 | 成长天数 | 产物 | 用途 |
|---|---:|---|---|
| 稻谷 | 4 | 稻米 | 食物、酿酒、任务 |
| 茶苗 | 6 | 春茶 | 饮品、礼物、订单 |
| 灵芝 | 7 | 灵芝 | 药剂、门派任务 |
| 何首乌 | 8 | 何首乌 | 内功药、礼物 |
| 人参 | 10 | 人参 | 高价药材、主线 |
| 毒草 | 5 | 毒草 | 解毒剂、暗器、黑市 |

### 6.4 生产设施

- 药炉：制作回血药、解毒剂、回内力药。
- 茶灶：制作茶饮，提升体力恢复或社交收益。
- 酒坊：将稻米和果物加工为酒，周期长但售价高。
- 研磨台：制作药粉、颜料和暗器材料。
- 铁砧：升级锄头、斧、镐和基础武器。

## 7. 采集、制作与经济

### 7.1 采集区域

- 村外湿地：芦苇、莲子、蛙、毒草。
- 青云山道：柴薪、野果、普通药草。
- 青云山腰：人参、矿石、稀有药材。
- 寒泉洞：雪莲、寒铁矿、玄冥会线索。
- 废弃镖局：木材、旧箱子、战斗掉落。

### 7.2 经济规则

首发不做复杂动态经济，采用“基础价格 + 季节修正 + 声望修正 + 订单奖励”：

```text
最终售价 = 基础售价 × 季节系数 × 商会声望系数 + 订单奖励
```

黑市提供高价和稀有材料，但会降低村民声望，并增加敌人事件概率。

### 7.3 订单

每日最多生成 3 个订单，类型包括：

- 交付作物；
- 交付药剂；
- 护送 NPC；
- 清理山道敌人；
- 修复设施；
- 寻找遗失物。

订单具有期限、委托人、需求物、奖励、声望变化和失败后果。

## 8. 武学与战斗

### 8.1 战斗定位

战斗是生活模拟的辅助成长线，不做高难度硬核动作 RPG。第一版采用俯视角、四方向移动、短距离攻击判定和少量敌人技能。

### 8.2 首发招式

| 招式 | 类型 | 消耗 | 作用 |
|---|---|---:|---|
| 基础刀法 | 普攻 | 0 | 前方短矩形伤害 |
| 追风步 | 轻功 | 15 内力 | 向面向方向位移并短暂无敌 |
| 守心诀 | 格挡 | 10 内力/秒 | 正面减伤，破防后硬直 |
| 回风掌 | 技能 | 25 内力 | 半圆范围击退 |
| 养气诀 | 修炼 | 时间 | 提高最大内力和恢复速度 |

### 8.3 战斗流程

```text
输入招式 → 播放前摇 → 创建 hitbox → 命中去重
→ 产生 AttackHit → 伤害/击退/硬直 → 播放受击动画
→ 收回 hitbox → 进入冷却或恢复阶段
```

### 8.4 首发敌人

- 山贼喽啰：近战追击，低生命。
- 毒蝎：短距离突刺，带中毒。
- 玄冥会徒：格挡和投掷暗器。
- 山魈首领：第一章 Boss，重击、冲撞、召唤小怪。

### 8.5 战斗数值原则

- 玩家默认可通过食物和药剂恢复，不强制死亡惩罚过重；
- 死亡后回到山庄，损失当天部分采集物和金钱；
- 不掉落永久装备；
- 敌人攻击必须有前摇、音效或特效提示；
- 所有伤害、命中和状态变化写入事件日志。

## 9. NPC、对话与关系

### 9.1 NPC 日程

每个 NPC 每天按时间段执行：

```text
06:00 起床 → 08:00 前往工作点 → 12:00 午间活动
→ 18:00 社交/练功 → 21:00 返回住所 → 23:00 睡觉
```

日程数据由 Lua/JSON 驱动，路径由 Rust 网格寻路提供。路径失败时 NPC 停留在最近可达点，并记录警告。

### 9.2 好感

- 每个 NPC 0–10 级关系；
- 送礼、完成任务、对话和节日活动增加关系；
- 失约、黑市交易和攻击村民降低关系；
- 关系等级解锁配方、支线、招式、地图和结局条件。

首发不做婚恋，保留“结交、师徒、门派关系”三条线。婚恋作为后续版本选项，避免扩大内容和 UI 复杂度。

### 9.3 对话数据

对话节点包含：

```text
id、条件、说话人、文本、选项、选项条件、变量修改、关系变化、下一节点、音效、头像。
```

## 11. 家园与建筑

### 11.1 建筑占地

建筑采用网格 footprint，不能重叠，不得覆盖道路、入口、作物和关键交互点。建筑状态包含：

```text
id、类型、地图、格子坐标、宽、高、等级、建造日、库存、生产状态。
```

### 11.2 首发建筑

- 药庐：解锁药炉和药材品质加成。
- 练功房：解锁招式训练和内力上限提升。
- 仓房：扩充存储容量。
- 茶棚：提供茶饮生产和 NPC 社交事件。
- 铁匠台：升级工具和武器。

## 12. 季节、节气与事件

首发保留四季、每季 28 天的底层结构；节气先作为事件标签，不实现完整中国农历算法。

"季内天数"是 M34-02 的实现口径：`day` 落在 `[from, to]` 闭区间内即为该节气的有效日
（`data/festivals.lua`，由 `world/calendar.lua` 按 28 天/季的日数纯函数换算，不入存档）。
七条按顺序各占三天，同一天不允许有两个节气事件（校验器直接报错）。

| 节气/事件 | 季节 | 季内天数 | 内容 | 实现落点 |
|---|---|---|---|---|
| 春分茶会 | 春 | 8–10 | 茶叶订单和 NPC 社交 | 对话 `cond.festival` + 订单 `order_tea`（6 份茶叶，+90 文/村望 8） |
| 清明踏青 | 春 | 15–17 | 山道采集收益提高 | `systems/gather.lua` 山道产量整数倍 ×2 |
| 端午药集 | 夏 | 8–10 | 药材交易和制药挑战 | `systems/shop.lua` 四味药材出售价 +20% |
| 夏至演武 | 夏 | 15–17 | 战斗训练和门派声望 | 对话：门派声望 +10、师父好感 +6（写锚点，只办一次） |
| 中秋灯会 | 秋 | 8–10 | 礼物、对话和结局变量 | 对话：晚晴好感 +8、莲子 ×3；**不**写 `ending` 变量（结局指针仍只由 `ending_sect` 锁死） |

## 13. 结局

首发规划 4 个方向：

1. 山庄复兴：家园等级、村民声望和生产线达标。
2. 青云掌门：门派声望、武学收集和主线选择达标。
3. 黑市巨贾：财富和玄冥会关系达标，但村民声望较低。
4. 归隐田园：完成师父真相线后拒绝各方势力，保留山庄生活。

## 14. MVP 内容锁定

MVP 只做：

- 3 张地图：山庄、村庄、山道；
- 1 个小洞窟可作为山道子区域；
- 1 个可操作角色；
- 3 个 NPC；
- 2 种作物/药材；
- 1 个商店、1 个工坊；
- 1 个敌人；
- 1 个近战招式、1 个轻功；
- 1 条任务链、1 个日循环；
- 1 种天气、1 个节日事件；
- 存档/读档、发布包和基础中文 UI。

MVP 的目标不是内容丰富，而是证明“种田—修炼—社交—探险—睡觉结算”的完整闭环。

## 14.1 版本范围与完成定义

| 版本 | 必须包含 | 不纳入本版本 |
|---|---|---|
| MVP 垂直切片 | 3 张地图、3 个 NPC、2 种种植对象、1 条主线、1 个敌人、7 日循环、存档读档 | 四季、复杂装备、婚恋、Boss、多结局完整实现 |
| Alpha 第一章 | 寒泉洞、5–6 个 NPC、4–6 种作物/药材、4 种敌人、1 个 Boss、青云门入口、第一章结尾 | 第二章及以后大地图、联机、完整动态经济 |
| Beta 首发候选 | 新手引导、设置、键鼠/手柄基础操作、稳定存档、完整中文文本、发行包 | 未完成平台适配、未验证的微信小游戏功能 |
| 首发版 | Alpha 内容完成、Beta 缺陷收敛、Windows 干净目录可运行、资源授权齐全 | 任何依赖开发环境或临时网络资源的功能 |

“完成”必须同时满足：功能可从干净存档开始完成；关键状态可保存并恢复；Debug/Release 构建通过；有自动化测试或可复现手工验收步骤；无 P0/P1 阻断问题；文本、资源和授权记录齐全。

## 14.2 MVP 验收剧本

1. 创建新存档并选择任一背景，进入山庄。
2. 与顾长风对话，获得锄头、种子和基础刀法教学。
3. 翻土、播种、浇水，并在地图切换后确认土地状态未丢失。
4. 进入云泽村，购买或出售至少 1 件物品，接受沈青萝的采药任务。
5. 进入青云山道，击败 1 名山贼或安全撤退，确认体力、生命和掉落变化。
6. 返回山庄制作药剂，将任务物品交付给沈青萝。
7. 睡觉推进到第二天，重新读取存档，确认作物成长、任务进度、资金和关系值正确。
8. 完成第一章节点，触发至少 1 个选择分支并看到不同反馈。
