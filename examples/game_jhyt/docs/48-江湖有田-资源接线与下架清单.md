> 重新扫一遍 `assets/**`，逐行核对"未引用数"，并对每个 `接线` 行断言"文件存在且真的

## 1. 口径（判定"已引用"的精确规则）

一次资源扫描把 `assets/**` 的每个文件分成三类：

| 类别 | 判定 | 处理 |
|---|---|---|
| **已引用** | 其工程相对路径（正斜杠）或文件名出现在 `scenes/*.scene`、`assets/prefabs/` 下的 `.prefab`（整目录）、`scripts/**/*.lua`、`project.toml`、`settings.toml` 中；**Lua 文件先剥掉注释再匹配**（详见下面的两条口径说明）；**音频额外**允许按文件名主干（`audio.sfx("sfx_harvest")` 走 `<assets/audio>/<name>.wav` 或 `<name>.ogg`——引擎先试 `.wav` 再试 `.ogg`，按主干解析）；四季地表额外允许被 `data/season_art.lua` 的格式串展开命中 | 正常发布 |
| **开发产物** | 文件名以 `_` 开头；或名字含 `preview` 的 PNG（`preview.png` / `season_preview.png` / `title_bg_pixel_preview.png`…）；或 `manifest.json` | **不进发行包**（引擎规则 `assetc::is_dev_artifact`，见 §4），仓库里保留 |
| **内容缺口** | 以上都不是 | **必须在 §2 的表里有决定** |

> `manifest.json` 被明确排除在"引用"之外：它是生成器的开发期清单（组件串、`uses_common`
> 之类的索引），**引擎与 Lua 运行期都没有读取点**（`grep manifest.json engine/crates` 为空）。
> 早先的审计把它算作引用，于是 `ui_weather_rain.png` 之类"只在清单里出现过"的文件被误判成
> 已接线——这正是本表要修掉的口径 bug。
>
> **Lua 注释不算引用**：匹配前先把 `--` 行注释与 `--[[ … ]]` 长注释剥掉（字符串保留——
> 字符串里的路径是真的会被引擎读的）。反例：`ui/hud.lua` 的注释里写着"`ui/weather` 图标
> 因为没有阴天取值所以不接线"，裸文本匹配会把这句说明算成"已引用"，于是**没接线的资源永远
> 从清单里消失**。这条口径是 M29 实现审计时踩出来的（当时正好少算了 1 个文件）。

### 3.1 `third_party/MushroomVillage_16px` 的判定档位（2026-09-15 修订）

上表第一行的**工程侧动作**（`assets/art/tilesets/mushroom_village/` 不复存在）是无条件的：
它进过发行包扫描范围，留下就是缺陷。但**搬迁目的地** `<repo>/third_party/MushroomVillage_16px/`
属于仓库级素材存放处——既不进 `assets/`、也不被任何场景或脚本引用，因此**不参与本工程的
可交付验收**。它是否存在于某台机器上属于环境事实，用一句「不存在即失败」把整条 MVP 门拦死
是把环境当契约。所以 `jhyt_m29_season_weather` 第 ⑦ 节按三档判定：

| 档位 | 条件 | 行为 | 理由 |
|---|---|---|---|
| A. 安全不变量 | `assets/art/tilesets/mushroom_village` **必须不存在** | 无条件失败 | 真契约：进了 `assets/` 就会被打包扫描到 |
| B. 搬迁完整 | 目录存在 → 必须 ≥21 个文件且含 `0_license_CC0.txt` | 失败 | 挡「搬一半」——部分搬迁比不搬更危险（残留引用会指向不存在的图） |
| C. 本地缺失 | 目录不存在 | **通过**并如实打印 `third_party=absent` + 原因 | 干净 checkout / CI / 新机器都走这一档 |

需要在本机强制要求该包时设 `RUSTLUA_REQUIRE_THIRD_PARTY=1`：此时 C 档也失败，便于素材线
自查。**不伪造通过**：C 档不静默——它每次运行都会把「本机未保留该第三方包」打进验收输出，
`jhyt_m29_season_weather_ok … third_party=absent` 一眼可见。

## 4. 开发产物为什么留在仓库、但不进发行包

* 生成器（`tools/gen_*.py`）把预览写在美术目录旁边（`_preview.png`），这是美术期望的位置，
  换目录会让每个生成器的输出路径、`--check` 模式、文档全部改一遍，收益只是"目录更整齐"；
* 但预览图**没有任何运行期读取点**，进发行包纯属浪费（`assetc` 打包是按文件数/字节数计的）：

```rust
// engine/crates/assetc/src/lib.rs
pub fn is_dev_artifact(path: &Path) -> bool   // `_` 前缀 / 含 preview 的 PNG / manifest.json
```

`collect_files` 跳过它们，并有单测 `dev_artifacts_are_not_packaged` 守住边界
（`title_bg_pixel.png` 含 "pixel" 不含 "preview"，必须留在包里——这个用例专门防误伤）。
