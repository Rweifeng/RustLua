# 《江湖有田》对标星露谷上线改造计划

- 文档版本：0.1（2026-10-05）
- 依赖文档：[总策划案](30-江湖有田-总策划案.md)、[项目执行总览](29-江湖有田-项目执行总览.md)、[数值设计案](33-江湖有田-数值设计案.md)、[开发计划](32-江湖有田-开发计划.md)、[美术资源规范（对标星露谷）](51-江湖有田_美术资源规范_对标星露谷.md)、[美术资源补充清单](40-江湖有田-美术资源补充清单.md)、[星露谷场景分层参考图集](53-江湖有田-星露谷场景分层参考图集.md)
- 基准参考：星露谷物语（Stardew Valley）的类型结构与品质线；**只对标结构与标准，不复制其角色、地图、文本与美术资产**（延续总策划案 §2.2 合规原则）
- 适用范围：从当前"MVP 已跑通、内容约等于星露谷首发 5–10%"的工程，改造到"玩法完整、数值合理、有差异化创新、达到上线标准"的首发版本

## 0. 结论摘要

1. **现状**（已实测核对）：玩法闭环完整、工程质量是当前最高优先项——26 项 headless 验收 + 1328 项引擎测试 + `game --check` 数据门 + 发布包干净验收。但**内容规模**距上线标准差距明显：2 种作物 / 7 个敌人 / 9 条任务 / 10 个 NPC / 8 张地图 / 7 日目标，约等于星露谷首发内容量的 5–10%。
2. **改造 = 三条主线**：
   - **玩法矩阵补全**：农业深度（四季作物/品质/肥料/洒水器/果树/温室）+ 新增畜牧、钓鱼、采矿、料理、出货物流、节日活动、好感事件、图鉴成就；
   - **数值从"7 天切片"升级为"一年四季 + 跨年"长期曲线**：经济阶梯、体力预算、成长曲线、战斗梯度全部重建并挂上机器断言；
   - **美术从"生成器占位风"升级为"发行级像素美术"**：延续 docs/51 已锁定的 32×32/64×64 硬边像素规格，补齐场景、角色、作物分阶段、UI、特效、音频与宣传物料。
3. **创新**：不靠"更像星露谷"取胜，把武侠种田的招牌做成**只有我们有**的系统——经脉修炼、医馆经营、节气历法、门派声望与黑市抉择、茶会社交、多结局。
4. **首发规模**：1 个完整游戏年（四季 × 28 天）可玩 + 2 章主线 + 自由模式，对应 20–30 小时主线与日常体验；内容预算见 §9。

## 1. 改造目标与原则

### 1.1 上线标准定义（五维可测）

| 维度 | 上线标准（可验收口径） |
|---|---|
| 玩法完整度 | 新档可连续游玩 ≥20 小时无明显内容断层；五条主循环（务农/制作/社交/探险/修炼）各自有 ≥3 个成长阶段 |
| 数值合理性 | 一年四季经济/体力/成长/战斗曲线平滑，无"死胡同"与"无脑套利"；关键曲线全部可由 headless 断言复算 |
| 体验品质 | 新玩家 10 分钟内完成首次种植闭环；60FPS；存档 100% 恢复；中文排版零溢出；键鼠/手柄可达 |
| 创新 | ≥3 个区别于星露谷、且构成完整玩法闭环的招牌系统（见 §7） |
| 合规 | 全部资源有授权登记；不复制星露谷资产；Credits 齐全（已具备，改造中持续保持） |

### 1.2 改造原则

1. **对标结构，不抄内容**：每个新系统先回答"武侠版怎么做"，再动手；星露谷只提供类型基准和品质线。
2. **数据驱动优先**：一切数值进 Lua 数据表，schema 校验 + headless 断言（延续 M23/M24 的 `jhyt_m24_numeric_alignment` 模式），杜绝静默兜底。
3. **完整度 > 炫技**：玩法系统优先级高于画面特效；先"能玩"，再"好看"。
4. **小步快跑**：沿用开发计划的里程碑 + 进入/退出条件 + 回滚点纪律，每个系统先垂直切片再扩内容。
5. **单一来源**：策划案 ↔ 数据表 ↔ 实现 ↔ 验收样例四者逐格对齐；文档与实现相反是 P0 文档问题（延续执行总览 §4 的教训）。

## 4. 玩法改造计划（分系统）

### 4.1 核心循环升级：从"7 日目标"到"四季年循环"

- **日循环**（保留，细化）：起床 → 看天气/日程 → 活动（务农/采集/制作/修炼/社交/探险三选二）→ 睡觉结算。每日体力预算强制"取舍"（见 §5.2）。
- **周循环**（新增节奏）：逢五为集市日（村集：特殊商品/收购价上浮）；逢三镖局护送货；黑市逢七开市（隐蔽入口）。
- **季循环**：每季 2 个节日 + 核心节气事件 + 季末结算（换季作物枯死、土地重耕、季节主题目标）。
- **年循环**：年终山庄评定（山庄声望/医馆口碑/门派试炼三线计分）→ 新春事件 → 第二年开放新作物、新地图、更高难度敌人与更多医馆病人。

**设计意图**：星露谷的粘性来自"日历上永远有下一个节点"。江湖有田以"节气 + 集市 + 门派试炼"构成武侠版日历，每天、每周、每季、每年都有盼头。

### 4.2 农业系统 2.0（对标星露谷，武侠化）

| 子项 | 现状 | 改造目标 |
|---|---|---|
| 作物矩阵 | 2 种 | **每季 6–8 种 × 4 季 + 温室/药圃/茶园/湿地 4 类土地**，含再生作物（茶、薄荷）、蔓生作物（藤架） |
| 品质体系 | 3 档（1.0/1.25/1.6） | 保留 + 品质概率随务农等级成长；新增"上品作物专属用途"（高级药引/送礼/节日订单） |
| 肥料 | 无 | 3 级：草药肥（+品质）/骨肥（+成长速度）/灵肥（+产量），每级由配方解锁 |
| 洒水器 | 无 | 3 级：竹筒引水（3 格）/水车（3×3）/机关洒水（5×5）；消耗材料制作，保留雨天免费浇水 |
| 果树 | 无 | 5 种（桃/梅/枇杷/枣/银杏），树苗 1 季成树、年年结果，秋季收成，送礼/酿酒两用 |
| 温室 | 无 | 药圃暖房（建筑升级解锁），四季可种，功能对标星露谷温室但武侠化为"地热药圃" |
| 工具升级 | 无 | 锄/壶/斧/镐 4 阶：精铁 → 寒铁 → 陨铁 → 灵铁（每阶减体力消耗、提高范围/效率） |

### 4.3 新增系统：畜牧（药园畜养）

- **动物 6 种**（武侠化命名）：白凤鸡（蛋）、芦花鸭（鸭蛋/绒羽）、青山羊（奶/毛）、花猪（松露→"地宝"）、老黄牛（奶/役用）、青驴（代步，解锁后山庄↔村快速移动）。
- **畜舍 3 类**：鸡舍（鸡/鸭）、畜棚（羊/猪/牛）、马厩（驴）；每类 2 级升级。
- **动物好感**：抚摸/喂食/放牧（雨天室内）；好感高 → 品质提升/特殊产物（如"灵蛋"）。
- **饲料循环**：种牧草 → 割草 → 干草 → 畜舍槽位；冬季需囤草（把"冬前备草"变成季节策略）。
- **动物事件**：生病（找医馆）、产仔、走失（山道寻回任务）。

### 4.4 新增系统：钓鱼与水域

- **水域 4 处**：村溪（入门）、山湖（进阶）、寒泉洞暗河（稀有）、雨季涨水（临时钓点）。
- **鱼种 20+**：鲫鲤鲈鳜等家常鱼 + 特色种（桃花鱼/雪莲鱼/寒泉银鱼）；分难度与时段（晨/昏/夜）。
- **竿升级 3 阶 + 鱼饵 + 迷你游戏**：收线节奏小游戏，可按手感调整（允许"简化模式"开关，照顾休闲玩家）。
- **放生池（鱼塘）**：建筑解锁后养鱼繁殖，产出鱼籽/稀有掉落；对标星露谷鱼塘，武侠化为"功德放生"主题（放生稀有鱼 → 声望 + 随机回馈）。

### 4.5 新增系统：采矿与洞窟

- **青云矿脉 30 层**：每 5 层竹梯电梯（对标星露谷电梯）；层越深 → 矿石高级、敌人增强、光照更暗（火把照明资源管理）。
- **矿石分级**：铜（精铁原料）/铁/银/金/寒铁 5 级 + 宝石 7 种（玉石/玛瑙/琥珀…）→ 图鉴 + 送礼 + 打造。
- **现寒泉洞改造**：保留为第一章剧情洞（师父残页），新增矿脉为独立洞窟入口；两者共用洞窟 tileset（已有资产复用）。
- **矿车/绳索/镐**：道具解锁深层通路；体力与负重构成下矿决策。

### 4.6 新增系统：料理与饮食

- **厨房**：住宅升级解锁（对标星露谷厨房），菜谱来源：任务奖励/书籍/节日习得/好感事件。
- **食物 Buff 体系**：体力恢复、内力恢复、攻击/防御/速度/运气临时加成、好感加成（请客吃饭）。
- **酒坊深化**：米酒/果酒/药酒 → 酒窖陈酿（时间投入换高价），季限配方（清明酒/重阳酒）。
- **茶艺（创新前置，见 §7.5）**：泡茶 4 变量（水质/水温/器具/时机），茶品分 5 档，是"种植 → 制作 → 社交"的招牌闭环。

### 4.7 经济与物流

- **出货箱**：山庄门口货箱，睡前统一结算 + 出货记录（图鉴/成就数据源）；与星露谷同构但武侠化为"镖局收单"。
- **任务板 3 层**：村民日常订单（每日 3，保留）/镖局护送与清剿（每周）/商会季度大单（季初刷新，量大价高）。
- **价格系统**：保留 `基础价 × 季节系数 × 声望系数 × 品质系数 + 订单奖励` 公式，新增**稀缺度波动**（雨天药草贵、冬季柴薪贵、节日礼品贵）——以 Lua 表配置，不做复杂动态市场。
- **黑市（落地）**：玄冥会渠道高利回收稀有品，代价为村民声望下降 + 夜间袭击概率上升（现有设计，本次落地为可玩循环）。
- **金币消耗 sink**：工具升级、建筑、土地开垦、住宅升级、医馆扩容、陈酿投资——保证收入曲线有出口（§5.3）。

### 4.8 社交与关系

- **好感 0–10**（保留）+ **生日**（每 NPC 1 个，日历标注，生日礼物 ×3 效果）+ **节日加成**。
- **送礼偏好表**：每位 NPC 爱/喜/厌 3 档物品表（沿用每日 1 礼上限）；送礼与对话构成日常社交节奏。
- **好感事件**：每位深交 NPC 3–4 个场景事件（门槛 2/5/8 心），事件含选择分支与奖励——对标星露谷心动事件，武侠化为"结义/拜师/还愿"。
- **深交角色 6 位**：沈青萝（医道）、顾长风（刀法）、苏晚晴（剑法）、玄鹤（内功）、林小满（茶道）、韩铁山（锻造）；不做婚恋（延续总策划边界），以挚友/师徒/门派线替代。
- **NPC 扩编**：10 → 16 人，每人日程含雨天变体（已有）+ 节日变体 + 伤病变体（医馆联动）。

### 4.9 技能与天赋

- **5 条线**：务农 / 采药 / 制药 / 武学 / 江湖（社交贸易）。
- **每线 0–10 级，5 级与 10 级各选一次专精（2 选 1）**，共 10 个专精（例：务农 5 级"精耕"（产量+10%）vs"药性"（品质+10%））。专精可洗点（代价道具）。
- 熟练度来源与 XP 曲线见 §5.4；专精选择进存档，读档可查。

### 4.10 战斗与武学深化

- **招式 2 → 12+**：基础 4 系武器（刀/剑/棍/暗器）各 3 招 + 内功技 2 + 轻功 2；全部走 `data/skills.lua` 纯数据注册（现有约定）。

- **敌人 12 + Boss 3**：杂兵（山贼/野猪/灰狼/毒蝎…）、精英（玄冥会徒/毒蛇/矿洞蝙蝠）、Boss（山魈首领[强化] / 毒王 / 玄冥护法）；Boss 分阶段（前摇 + 范围提示，延续现有战斗反馈口径）。
- **状态效果扩展**：中毒/灼烧/寒伤/流血/封脉（禁内力）——状态图标美术已有 6 个（docs/40 批次 4）。
- **战斗场景**：演武场（教程与练习）/山道（巡逻遭遇）/矿洞层（探索战斗）/镖局护送战（护送 NPC 的移动战）/门派试炼（挑战赛，年度节点）。

### 4.11 节日与节气（创新核心之一，详见 §7.3）

## 5. 数值改造计划

### 5.1 时间与节奏

| 项 | 现基线 | 改造目标 |
|---|---|---|
| 每日时段 | 06:00–24:00（18 小时） | 保留；新增"菜单/室内时间半速"可选开关 |
| 现实时间 | 1 游戏时 ≈ 45 秒（一天 ≈ 13.5 分钟） | 保留；一天足够完成 2–4 类活动（现有调优指标沿用） |
| 一年 | 28 天/季 × 4 季 = 112 天 | 保留；一年纯游玩 ≈ 25 小时（内容量与 §9 对齐） |
| 睡觉 | 任意时间可睡 | 保留；新增"疲劳提示"（23:00 后扣少量次日上午体力，不强制） |

### 5.2 体力 / 内力预算（年曲线）

- 基础体力 100（保留），**成长来源**：食物上限、务农熟练度、练功房与膳房建筑；**年 1 上限 ≈ 150，年 2 ≈ 200**。
- **日均动作预算**：早春 12–18 次基础劳动 → 中后期 20–30 次（工具升级与熟练度减耗后）；雨天省去浇水。
- **"每日三选"模型**：玩家每天在务农/采集/修炼/社交/探险中选择 2–3 类，任何一类都不应独占一整天——这是体力数值的第一约束。
- 内力：基础 60（保留），练功房/养气诀/经脉系统提升，年 1 目标 ≈ 100。

### 5.3 经济曲线（核心重建对象）

**收入阶梯（文/天，设计目标区间）**：

| 阶段 | 日均收入 | 主要来源 |
|---|---:|---|
| 春第 1 周 | 0–50 | 初始 300 文 + 稻谷首茬 |
| 春中后期 | 50–150 | 稻谷/芍药轮作 + 采集 |
| 夏 | 150–400 | 莲子/枸杞 + 钓鱼 + 订单 |
| 秋 | 400–900 | 人参/果树 + 酒坊 + 护送 |
| 冬 | 300–800 | 雪莲/矿 + 畜牧产物 + 医馆 |
| 年 2 | 800–2000 | 医馆 + 陈酿 + 季度大单 |
| 年 3+ | 2000–5000 | 全套生产线 + 门派试炼奖金 |

**支出阶梯（金币 sink）**：工具升级 500 / 1500 / 4000 / 12000；建筑 1000–8000；住宅升级 5000 / 15000 / 30000；医馆扩容 10000；土地开垦 200–2000。

**作物利润约束**（以"利润/天"排序，风险与收益匹配）：

```
种植（稳定低险） < 采集 < 钓鱼 < 矿洞 < 护送/黑市（高险高利）
```

- 稻谷 ≈ 12 文/天（教学作物，稳定）；芍药 ≈ 10 文/天（药圃门槛高但品质概率高）；人参 ≈ 15 文/天（长周期高单价）；雪莲 ≈ 16 文/天（冬季唯一露地作物，稀缺溢价）；茶树按 5 季采摘累计 ≈ 20 文/天（一次性高投入）。
- **平衡约束**：任何作物不允许"当天买入种子当天卖出"套利（卖价 < 买价）；品质期望收益 ≤ 同地高级作物。

**数值验收（机器化）**：新增 `jhyt_m36_economy_sim` 样例：模拟"标准玩家"按推荐策略玩满一年，断言每天收入落在 §5.3 区间、金币不为负、第 112 天达到"山庄声望 3 级 + 医馆可开张"的门槛——沿 M24 逐格比对口径。

### 5.4 成长曲线

- **熟练度 XP（每线 0–10 级）**：每级所需累计 XP = 50 / 120 / 220 / 360 / 550 / 800 / 1100 / 1500 / 2000 / 2600（10 级合计 2600）。来源：务农（翻土/播种/收获 +5）、采药（+5）、制药（+8）、武学（命中 +2、训练任务 +15–30）、江湖（交易/护送 +10–20）。
- **好感**：100 点/心；普通对话 +2，喜礼 +20，爱礼 +40，厌礼 -10；生日 ×3；任务 +15；节日 +10。**到 10 心 ≈ 25–40 天互动**（对标星露谷"1 礼物/天 + 事件门槛"的节奏，但不复刻其数值）。
- **声望**：0–100 保留，5 档称号（陌生/熟识/受信/重视/核心），每档解锁表沿用现值（解锁配方/订单/区域/结局条件）。

### 5.5 战斗数值

- 玩家：初始攻击 4（保留），武器 +8 / +16 / +28（3 阶）；防御来自护具/丹药。
- 敌人梯度：杂兵 HP 18–30（现有 12–26 偏弱，上修到杂兵可两招带走、被围需要闪避的节奏）；精英 60–90；Boss 300–500 分 2–3 阶段。
- 时间目标：杂兵战 10–20 秒；Boss 战 2–4 分钟（阶段转换 + 前摇提示，不靠数值碾压）。
- 死亡惩罚：保留现有口径（回庄、扣 5% 钱 + 50% 当日掉落、保留一切长期进度）；新增"死亡报告"（面板可查本次损失明细，现有 `death.last_penalty()` 已埋点）。

## 7. 创新设计（武侠差异化招牌系统）

对标星露谷不是为了变成星露谷。以下 6 个系统是《江湖有田》的招牌——每个都必须构成**完整玩法闭环**（有输入、有成长、有输出、有风险），而不是装饰性功能。

### 7.1 经脉修炼（替代"技能条"的成长叙事）

- 简化为 **6 条经脉**（对应 6 项能力）：手太阴肺经→体力上限 / 手少阴心经→内力上限 / 足阳明胃经→进食效果 / 督脉→武学伤害 / 任脉→制药效率 / 带脉→负重与移动。
- 修炼方式：打坐（消耗时间回内力+经脉进度）/ 读经（获得"顿悟"点数）/ 药膳与丹药（加速）/ 冲穴小游戏（时机判定，成功大进、失败反噬小扣）。
- 经脉等级 → 招式解锁、属性上限、生活效率；**与熟练度系统并行但叙事不同**（熟练度=手艺，经脉=身体修为）。

### 7.2 医馆经营（核心差异化，玩法最重）

- **村民就诊**：每天 1–3 位病人，症状描述 → 诊断（望闻问切 4 项信息收集，信息不足会误诊）→ 开方 → 制药 → 交付。
- **误诊惩罚**：疗效差 → 村民信任下降 + 补偿任务；治愈疑难 → 医馆口碑上升 → 病人增多、药材订单、季节疫情事件。
- **疫情事件链**（雨季触发）：全村防疫任务（采药/熬药/隔离/谣言处理 4 步），是"种植 → 制药 → 社交"三线的交汇点，也是星露谷没有的事件类型。
- 医馆升级：药柜 → 诊室 → 病房（容量/科室/声望收益递增）。

### 7.3 节气历法（替代"季节换装"的世界感）

- 8 个核心节气影响：作物生长系数、采集物刷新、天气概率、节日日程、食谱开放（清明青团/冬至饺子）。
- 节气当日特殊互动：谷雨（雨天采集翻倍）、霜降（雪莲可采）、冬至（封山，室内生产加成）。
- 节气以 `data/solar_terms.lua` 纯数据配置 + 日历 UI 标注，与现有 `world/calendar.lua` 合并。

### 7.4 门派声望与黑市抉择（道德压力系统）

- 5 阵营声望条可见化（村庄/青云门/镖局/商会/玄冥会），行为实时反馈（+/- 弹出）。
- **抉择时刻**：主线节点 3 选 1（交残页给青云门 / 隐瞒 / 卖黑市）→ 世界状态分支：村庄经济、门派关系、夜间事件、结局走向。
- **黑市循环**：高利回收稀有品 + 出售违禁物（毒/暗器材料），代价 = 村民声望下降 + 夜间袭击概率上升；形成"短期利润 vs 长期信任"的持续张力。

### 7.5 茶会社交（星露谷"酒吧/舞会"的武侠版）

- **泡茶技艺**：水质（泉水/井水/雨水）、水温（文火/武火）、器具（陶/瓷/竹）、时机（冲泡节奏）4 变量 → 茶品 5 档。
- **茶会**：邀请 NPC（消耗茶叶与时辰）→ 话题选择 → 好感大幅加成 + 解锁对方秘密/支线；林小满（茶农）为该线核心 NPC。
- 与种植闭环：明前/雨前茶品质随节气变化 → 好茶要"节气当天采、当天泡"，把日历与社交绑在一起。

### 7.6 多结局（已设计 → 落地为可玩目标）

- 4 结局 + 结局后自由模式；结局条件由"山庄声望 + 阵营声望 + 主线抉择"三线计分（`data/endings.lua` 纯数据配置）。
- 结局插图 4 张（docs/40 已列 P1 缺口）；结局解锁进图鉴/成就。

| 文本量 8 万字 | 首包字体子集不足 | 字体子集 601 → ≥2000 常用字；`text_audit.lua` 继续把关 |

> 说明：`animation.attach`、A*、战斗 hitbox、出货结算所需的时间/商店/背包接口均已具备（docs/43、docs/34），改造**不依赖新的大引擎能力**，重心在数据与内容。

### 8.2 内容管线

- 数据表扩展：`crops`（品质/肥料/再生）、新增 `animals.lua`、`fish.lua`、`dishes.lua`、`solar_terms.lua`、`collections.lua`、`endings.lua`；全部挂 `validate_data.lua` 校验器。
- 批量生成器：作物表 → 自动产出占位 overlay；`tools/` 新增 `gen_crop_stages.py`（对齐现有 pixel_kit 骨架）。
- headless 断言扩展：经济模拟（§5.3）、成长曲线、节日触发条件、医疗诊断判定、黑市声望结算——每个新系统 ≥1 条验收样例（沿用 `jhyt_m*` 命名）。

### 8.3 平台

- **PC 首发**（已验收，继续为主承诺）；WebGL / 微信小游戏保持"独立验收目标"，**不在首发承诺内扩展内容**（延续总策划边界）。
- 窗口/UI 契约（横屏 1280×720 回归后）保持 `layout_check.lua` 三路守门。

### 8.4 工程质量

- 延续 `verify.ps1` 总门：文档门 / cargo 三件套 / `game --check` / headless / GUI smoke / 发布自检；**每个改造里程碑必须新增对应用例，不允许"改了没验"**。
- 文档同步规则（执行总览 §8）：本计划落地时同步更新总策划案 0.3、数值设计案 0.2、开发计划 0.4 与执行总览。

## 10. 里程碑路线图（改造分阶段）

沿用开发计划"进入条件 → 任务 → 验收 → 退出条件 → 回滚点"的纪律，改造分 5 个阶段：

### 阶段 1「玩法地基」（M36–M40）
- 进入条件：本计划评审通过；数值案 0.2 锁定经济曲线。
- 内容：农业矩阵 2.0（24 作物数据 + 品质/肥料/洒水器/果树/温室）、工具升级 4 阶、出货箱与出货记录、熟练度 5 线 10 级 + 专精、`jhyt_m36_economy_sim` 经济模拟样例。
- 退出条件：四季可种、经济模拟断言全绿、`game --check` 通过、存档迁移用例通过。
- 回滚点：作物表与旧存档字段向后兼容（新字段可选，旧档可读）。

### 阶段 2「内容 Alpha」（M41–M46）
- 内容：畜牧、钓鱼、矿脉 30 层、料理与厨房、NPC 10→16 + 生日 + 好感事件 30、节日 8 个、任务板 3 层、图鉴 6 类与成就 30。
- 退出条件：新档一年四季内容可连续游玩；每新系统 ≥1 headless 验收；P0/P1 清零。
- 回滚点：按系统开关（feature flag），任一系统异常可单独关闭后出包。

### 阶段 3「创新系统」（M47–M50）
- 内容：经脉修炼、医馆经营与疫情事件、节气历法、黑市抉择循环、茶会社交、多结局落地。
- 退出条件：3 个招牌系统（医馆/节气/黑市抉择）构成可玩闭环；主线 2 章可从新档完成。
- 回滚点：创新系统独立模块化，与基础循环解耦。

### 阶段 4「美术与打磨」（M51–M54）
- 内容：Style Bible 验收基准；场景 16 张、角色 16 全序列帧、作物阶段 sprite、动物/鱼/料理图标、UI 全面板、特效 40 组、音频全套、宣传物料。
- 退出条件：风格门全绿、60FPS 性能基准通过、中文排版零溢出、资源授权表齐全。
- 回滚点：生成器占位保留在仓库，可随时回退到原型表现继续可玩。

### 阶段 5「Beta / 首发」（M55–M58）
- 内容：新手引导重做（对齐 5.6 指标）、平衡调优（试玩数据）、全量 QA（存档/性能/无障碍/多分辨率）、商店页与宣传、发布门。
- 退出条件：发布门全绿（延续 docs/32 阶段 H 清单）、外部试玩 ≥10 人完成主线、无 P0/P1。

## 11. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 内容量过大超出 2–4 人团队产能 | P0 | 分层首发：must-have（农业/经济/节日/NPC）/ stretch（矿层深层/全家具）；数据驱动批量生产压成本 |
| 美术风格反复 / 委托成本失控 | P1 | Style Bible 先行冻结；外包批次化（每批 ≤3 周）；生成器占位兜底保证永远可玩 |
| 数值失衡（通胀/死胡同） | P0 | 经济模拟样例前置；试玩指标（§5.6）每次改数必测；一次只调一个变量（沿用调参规则） |
| 新系统破坏存档/旧流程 | P0 | 每个新系统：schema + 迁移门 + 100 次读档循环 + feature flag 回滚 |
| 对标过度、变成"武侠皮星露谷" | P1 | §7 招牌系统前置评审；每个系统必答"武侠版怎么做"；创新系统不进 stretch |
| 文本量 8 万字排版风险 | P1 | 字体子集扩到 2000 字 + `text_audit` 持续跑；对话批量生成模板 |
| 性能随内容膨胀下降 | P1 | 图集/合批/剔除 + `verify.ps1 -Benchmarks` 基线回归 |
