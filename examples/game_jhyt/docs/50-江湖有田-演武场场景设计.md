# 《江湖有田》演武场场景设计

- 文档版本：0.1
- 本版同步：docs/37 山庄主场景美术 0.1（§8.3 已改为"三场景均用正式 tileset"）
- 目标：把 M18-01 的 20×12 战斗灰盒重制成山庄练武场——40×22 整屏、复用山庄
  tileset 与通用道具、保留战斗验收锚点不动，headless 验收零改动通过
- 产出：`tools/gen_arena_scene.py`（生成 + 契约自检）、`scenes/combat_arena.scene`、
  `data/maps.lua` 出口格/标题同步

## 1. 定位与约束

演武场是山庄的练武场（总策划 §10.1"玩家山庄：住宅、药田、工坊、练功场"），
同时承担 M18-01 战斗系统的 headless 验收场。因此重设计遵循两条铁律：

1. **验收锚点不可动**：`jhyt_m18_combat` 硬编码了战斗几何（见 §3），
   布局围绕锚点做，锚点本身一格不移；
2. **farm.lua 防误垦**：`farm.lua` 的 FARM 矩形（x14..33, y4..13）没有场景门禁，
   "可开垦"只看 GroundMap tile==2（夯土）。演武场全场**禁止夯土 tile**，
   否则玩家能在演武坪里锄地。生成器把"无 tile 2"作为硬性自检。

引擎硬约束与 docs/37 §1 相同：tileset 固定 6 列（列语义 1=草地 2=夯土 3=石板路
4=院墙 5=青瓦 6=水）、无 Y 排序（遮挡靠 solid 占位）、sprite 不能选 UV 区域
（一件道具一张图）、碰撞只看 tilemap solid。

## 2. 布局（40×22，cell 0-index，y 朝上）

| 分区 | 范围（cell） | 地表 | 可走 | 内容 |
|---|---|---|---|---|
| 外围院墙 | row0 / row21 / col0 / col39 | 院墙(4) | ✖ | 与三场景统一 |
| 演武坪 | x1..19, y1..12 | 石板(3) | ✔ | 全部战斗锚点都在坪内 |
| 南门 | x8..10, y0..2 | 石板 | 门洞 (9,1)(9,2) ✔ | manor_gate 贴图压墙，立柱 solid，门洞内 (9,1) = 出口格 |
| 器械廊 | y13 草地一排 | 草地(1) | 道具占格 ✖ | 兵器架×2（x4..5, x7..8）、草垛（x12）、演武旗（x15, x18）；石板引道 x9..10 |
| 东侧小径 | x20..29, y7..8 | 石板(3) | ✔ | 演武坪 → 茶水棚/水畔 |
| 茶水棚 | stall (26..27,10)、缸 (28,10)、草垛 (24,11) | 草地 | 道具占格 ✖ | 歇脚处 |
| 池塘 | x30..36, y14..17 | 水(6) | ✖ | 木栈桥贴水面（x31..33, y14） |
| 山林带 | y19..20 一排 | 草地 | 树/竹/石占格 ✖ | 老树×4、竹丛×3、山石，压北墙形成纵深（不放 y20 以免超出上沿被裁） |
| 石锁阵 | (17,9) (17,6) (3,3) (35,13) | 草地/石板 | 各 1 格 ✖ | village_rock 充当石锁，坪东侧两只构成绕走障碍 |

灯杆（village_lantern）分立南门内侧 (6,1)(12,1)；告示木牌（manor_sign）在东侧
小径口 (22,9)；演武旗四杆：北缘 (15,13)(18,13) + 坪北角 (1,12)(19,12)。

设计取舍：

- **不引入夯土/沙土练武区**：演武坪整体石板，单调感交给旗阵、石锁与器械廊的
  道具节奏解决，换来的"全场不可垦"是硬契约（见 §1 第 2 条）；
- **锚点周边 3 格内不放 solid**：灰狼 (2,9)→引敌位 (6,8) 的 A* 追击走廊保持全通；
- **道具全部复用** gen_manor_art.py / gen_village_art.py 既有贴图，本场景零新美术。

## 3. 战斗验收锚点（三方契约，不可单方修改）

| 锚点 | cell | 世界坐标 | 消费方 |
|---|---|---|---|
| 出生/战败重开 | (9,5) | (304,176) | `data/maps.lua` spawn、`jhyt_m18_combat::ARENA_SPAWN` |
| 训练木人 home | (14,5) | — | `data/enemies.lua` enemy_dummy、验收断言 `cell_x==14` |
| 试招站位 | (13,5) | (432,176) | `jhyt_m18_combat::PLAYER_BEFORE_DUMMY`（面向右普攻/武学/击杀） |
| 灰狼 home | (2,9) | — | `data/enemies.lua` enemy_wolf、验收断言 `cell_x==2` |
| 引敌站位 | (6,8) | (208,272) | `jhyt_m18_combat::WOLF_LURE`（追击/受击/战败） |
| 出口格 | (9,1) | — | `data/maps.lua` arena_to_main（南门门洞内，按 E 回山庄） |

改动锚点必须三处同步：`tools/gen_arena_scene.py`、`scripts/data/maps.lua`、
`engine/crates/game/examples/jhyt_m18_combat.rs`。生成器会解析 `data/maps.lua`
做一致性校验，不一致直接非零退出。

## 4. 生成与验收

```powershell
cd examples/game_jhyt
python tools/gen_arena_scene.py                        # 生成 combat_arena.scene + 契约自检
python tools/preview_scene.py scenes/combat_arena.scene --out .temp/arena_preview.png
cargo run -p game --example jhyt_m18_combat            # headless 十章验收（引擎侧）
```

`gen_arena_scene.py` 自检项：tiles/solid 尺寸与值域、**全场无 tile 2**、
六个锚点可走/可达/地表石板、灰狼 home→引敌位连通、门洞通畅且立柱 solid、
道具不占墙/水格、maps.lua spawn/出口一致、全部贴图像素尺寸与声明一致
（最后两项与 gen_village_scene.py / preview_scene.py 同约定）。

## 5. 已知限制与后续

1. **训练木人/灰狼仍是 `__white__` 色块占位**：敌人美术属 docs/40 #2（另一批次）；
2. **演武旗复用 village_banner（商铺招幌）**：专用旗幡贴图待有场景专属美术批次；
3. **无 Y 排序**：树/竹压墙是贴图技巧，人物走到树后仍会被树盖住（引擎层限制）；
4. **木人桩阵、梅花桩等专用器械**：等敌人/器械美术就绪后，可在 enemies.lua 加
   静态木人（speed=0）扩成桩阵，届时按 §3 同步 headless 断言。
