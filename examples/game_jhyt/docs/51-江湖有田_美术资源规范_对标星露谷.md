# 《江湖有田》美术资源规范（对标星露谷物语标准）
> 文档版本：v0.3
> 依赖文档：31‑江湖有田‑美术资源方案.md v0.2、36‑江湖有田‑角色序列帧设计.md、37‑江湖有田‑山庄主场景美术.md
> 基准参考：星露谷物语（Stardew Valley）像素美术生产范式；保留原有三层资源策略、目录结构、许可证登记、引擎约束，对齐星露谷像素规格、动画逻辑、色彩管理、资源生产、验收标准。
> 星露谷核心美术特征：**32×32基础Tile网格、像素硬边无抗锯齿、有限调色板、角色4方向（本项目）、序列帧Sprite Sheet、环境分层、作物多阶段生长、UI高可读性、统一光源、少半透明模糊特效**。

## 1 总体美术策略
依旧执行**原型层→垂直切片层→正式发行层三层资源策略**
1. **原型层**：CC0商用合规占位素材，只做玩法验证；不允许占位素材直接流入正式版本，参考星露谷早期原型，占位资源仅用于逻辑跑通，全部后期替换。
2. **垂直切片层**：统一国风武侠像素风格，禁止多画风拼接；全部内建美术为统一像素体系，外部素材仅允许用作次要装饰碎屑。
3. **正式发行层**：主角、关键NPC、Boss、主线场景、Logo、全套UI、宣传物料全部原创/专属委托；第三方素材仅限次要装饰物件，完整留存授权清单。

> 核心原则：全部游戏内像素美术禁用模糊抗锯齿，硬像素边缘；全局统一虚拟光源；统一调色板管控；Sprite Sheet批量管理动画资源；地图分前景、中景、背景层渲染。

## 2 基础像素规格（对标星露谷物语，适配本项目引擎约束）
> 注意本项目引擎`core/tilemap.rs`原有tileset列数硬编码为6，需要先完成引擎改造支持可配置tileset列数，否则单地图最多6种地表图块。

### 2.1 Tilemap 图块规范（环境/地面）
|项目|规范说明|星露谷对照|
| ---- | ---- | ---- |
|基础Tile尺寸|**固定32×32px**，所有地表、墙体、物件图块统一，不混用16×16与32×32同地图；若使用16px素材，导出阶段2倍最近邻放大至32×32，禁止双线性模糊放大|星露谷原生全部地图tile 32×32，无混合尺寸|
|图片格式|PNG‑24，透明通道，**关闭抗锯齿，硬像素边缘**，禁止JPG作为源素材|全部源资源PNG，无模糊软边|
|Tile分层|地图分为三层：<br>①背景层：地面、泥土、草地、石板（不可交互）<br>②中景层：作物、可拾取道具、建筑主体、NPC、敌人<br>③前景层：树冠、屋檐、栏杆，遮挡玩家角色|星露谷地图三层渲染逻辑，前景物件遮挡角色|
|图块拼接规则|地表图块必须支持无缝拼接；土地、田埂、石板边缘单独制作过渡tile；田地地块支持犁地、湿润、干涸3种状态|耕地拥有干湿状态变体，地块边角过渡tile齐全|
|装饰物Tile（灯笼、石碑、牌匾）|静态装饰物32×32；高于单tile的物件使用多tile拼接（例如大树占用2×2 tile），锚点对齐网格|大树、建筑采用多tile组合摆放|

山庄、村庄、山林、洞窟、室内全部遵循上述规格；MVP/首发资源数量沿用原31号文档。

### 2.2 角色序列帧规范（玩家/NPC/敌人/Boss）
> 本项目采用4方向（上下左右），不强行扩展8方向；动作帧数参考星露谷精简优化。

1. **画布尺寸**：角色Sprite Sheet单帧尺寸 **64×64px**；角色脚底锚点固定在帧底部`y=52`位置，脚底碰撞盒`12×8px`，保证站在32px tile地面上不浮空不下陷。
2. **线条与像素**：硬像素轮廓，禁止模糊抗锯齿；角色轮廓线1像素；全局统一主光源：**光源来自左上**，阴影落在角色右下方。
3. **动作帧数量标准**

|角色类型|必须动作（对标星露谷）|帧数要求|
| ---- | ---- | ---- |
|玩家主角|待机、4方向行走、锄地、播种、浇水、收割、普通攻击、受击、死亡|行走每方向4帧循环；工具劳作动作6‑8帧；攻击4‑6帧；受击2帧闪白；总帧范围32‑48帧|
|普通NPC|待机、4方向行走、交互姿态；无攻击动作|行走每方向3帧循环；待机2帧轻微呼吸动画；单NPC总帧12‑20帧|
|普通敌人（山贼等）|待机、移动、攻击、受击、死亡|移动每方向3帧；攻击5‑7帧；死亡4帧倒地动画|
|Boss角色|待机、移动、多套技能攻击、受击、死亡；体型可大于64×64（例如96×96）|技能动画完整，攻击前摇帧明确，方便游戏做攻击提示|

4. **Sprite Sheet排版规则**
- Sheet按【行=动作类型，列=方向/帧】排布；文件命名小写英文下划线；
- 每个动作循环必须标记循环帧数、帧间隔；项目统一默认`200ms`，快动作刀光可下调至100ms；
- 对话头像（Portrait）：**64×64px**，每个角色至少4套表情（平静、开心、生气、忧伤），首发关键角色扩展至6套表情；头像同样左上光源，1px硬轮廓。

> 已产出主角与7名NPC序列帧资源，需要按此规范做校验，锚点、光源、帧间隔统一修正。

### 2.3 作物、药材和可交互物件（对标星露谷农作物体系）
星露谷作物特点：多生长阶段、每个阶段独立sprite；成熟后可收获；支持枯萎状态；支持品质差异（普通/银星/金星）。

1. 单块田地Tile：32×32px；作物每个生长阶段占1个32×32 tile。
2. 每一种作物/药材必须产出资源：
`种子图标 → 芽期 → 幼苗期 → 成长期 → 成熟期 → 收获动画 → 枯萎状态 → 掉落物图标 →普通品质/优良品质/极品品质变体`
3. 动画规则：生长阶段切换为静态Sprite；**收获使用4‑6帧短动画（抖动+闪光）**；枯萎作物灰色降饱和调色，保留原有轮廓。
4. 物品图标规范：
- 图标基础尺寸 **32×32px**，硬像素，左上统一光源；统一1px深色外描边，保证在不同UI背景上可读；透明PNG；
- 武器、丹药、材料、任务道具全部遵循；MVP 60个图标，首发扩充到100个图标。

### 2.4 特效规范（对标星露谷特效逻辑）
星露谷极少使用复杂粒子，大量采用Sprite Sheet序列帧特效；粒子仅用于雨雪等环境效果。
1. **优先使用Sprite Sheet序列帧动画，复杂粒子后置**；
2. 特效画布：基础特效帧32×32px；大型攻击特效64×64px；硬像素，尽量避免大面积半透明模糊。
3. MVP必做特效清单：锄地尘土、播种闪光、浇水水花、收获跳字、刀光、命中火花、受击闪白、轻功残影、治疗/中毒状态提示。
4. 环境天气：雨、雪使用分层粒子；天气叠加不遮挡UI；特效帧间隔统一配置。

> 禁止过度炫目的全屏特效，保持像素风格统一，特效优先服务玩法反馈。

### 2.5 UI美术规范（国风武侠像素，对标星露谷UI可用性标准）
星露谷UI特征：高可读性，面板分层，像素按钮，字体清晰，色彩克制，缩放适配窗口。
1. **基础色板**：深墨灰、朱砂红、竹青、米白、旧金色；像素化宣纸、木纹做面板纹理，纹理不能干扰文字阅读。
2. UI元件像素规格：
    - 面板、按钮全部为像素绘制，无矢量模糊；按钮具备普通/悬浮/按下三态；
    - 图标全部复用32×32物品图标资源；HUD状态图标32×32；
3. 字体规范：
    - 使用像素友好中文字体；打包执行字体子集化；
    - Beta版本前完成：字号调节、高对比度模式、纯键盘导航测试；
4. UI面板清单：背包、商店、对话、任务、武学、建筑放置、存档、设置、HUD生命体力内力金钱时间快捷栏。

> 重要约束：所有UI文字对比度必须满足可读性；不要使用低透明度叠加文字。

### 2.6 音频资源规范
1. BGM：优先短循环片段，支持无缝循环；MVP音频清单沿用原31号文档；
2. SFX音效：每个交互动作准备**2‑3个变体随机播放**，避免听觉疲劳；格式WAV/OGG，统一采样率44100Hz，控制峰值防止削波。
3. 严禁来源不明古风影视剧音乐，全部登记许可证。
