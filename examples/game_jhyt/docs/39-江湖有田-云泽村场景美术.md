# 《江湖有田》云泽村（山谷村落）场景美术

- 文档版本：0.1
- 本版同步：美术资源方案 0.2、山庄主场景美术 0.1、总策划案 0.2
- 目标：把美术资源方案 3.1 节的"村庄环境"落成**可生成、可验收、可复现**的第二张地图美术，
  并说明接入 `scenes/village.scene` 的方式
- 资源现状：地表 1 套 tileset（6 列 ×32px）+ 8 个建筑 + 6 类道具 + 场景装配，
  由 `tools/gen_village_art.py`、`tools/gen_village_scene.py` 生成

## 1. 与山庄的美术区分

同一套 32px 网格 / 1px 墨色描边 / 同一色板体系，但两个地方要有各自的身份：

| | 山庄（main） | 云泽村（village） |
|---|---|---|
| 地表主色 | 夯土 + 青石院墙 + 石板路 | **青石板街 + 白墙黛瓦**，草地更深更杂 |
| 建筑 | 灰瓦土墙庄院（正房/柴房） | **徽派白墙黛瓦 + 马头墙**，商铺木板门面 + 招幌 |
| 环境母题 | 药田、池塘、晒场 | **山谷**：村北一条溪水 + 石桥 + 渡口木栈桥、竹林山石成山脊 |
| 边界处理 | 石砌院墙整圈 | 南侧白墙院墙 + 村口牌坊；北侧靠竹树与山石成山脊 |

参考对象是江南山村（云泽县），不出现任何具体现实村落或他人美术资产。

## 2. 地表 tileset

`assets/art/tilesets/village/village_ground.png`（192×32，6 列；**列语义与山庄完全一致**，
引擎 `TILE_PALETTE` 固定 6 列且 V 方向整幅采样，不能加列也不能改高度）：

| 列 | 名称 | 村庄用法 | 与山庄同列的差别 |
|---:|---|---|---|
| 1 | 草地 | 村内空地、北岸 | 更深、更杂（山谷野草），带落叶与小三叶草 |
| 2 | 夯土 | **茶园**、田埂土路 | 偏沙、带耙痕（暗示茶垄），不是山庄的深夯土 |
| 3 | 石板路 | 主街 / 市集广场 / 中街 / 各院前 | 大块磨损石板 + 裂缝 + 两道车辙 |
| 4 | 院墙 | 村界墙 | **白墙 + 黛瓦压顶 + 青石墙脚**，替代山庄的石砌院墙 |
| 5 | 青瓦 | 保留列（与山庄同语义） | 色调更冷（黛瓦），供屋顶/马头墙类需求 |
| 6 | 水 | 村北溪水 | 更清、有流向线与浅滩反光，替代山庄的池塘静水 |

预览：`assets/art/tilesets/village/_preview.png`。

## 5. 场景布局与契约

`scenes/village.scene`（40×22，1280×704，正好一屏）：

| 分区 | 范围（cell） | 地表 | 可走 |
|---|---|---|---|
| 村界院墙 | row0 / row21 / col0 / col39 | 白墙黛瓦 | ✖ |
| 村口牌坊 | x18..20, y0..2 | （贴图压住院墙） | 门洞 x19 ✔ |
| 主街 | x16..23, y1..9 | 石板 | ✔ |
| 市集广场 | x12..27, y3..5 | 石板 | ✔ |
| 东西中街 | x10..29, y9..10 | 石板 | ✔ |
| 药庐 / 前院 | x3..8, y15..19 / x2..9, y13..14 | 夯土基底 / 石板 | ✖ / ✔ |
| 杂货铺 / 前院 | x31..36, y15..19 / x30..37, y13..14 | 夯土基底 / 石板 | ✖ / ✔ |
| 茶园 | x10..14, y11..14 | **夯土** | ✔ |
| 溪水 | y16..17, x11..29（x18..21 加宽到 y15..17） | 水 | ✖ |
| 石桥 | x24..25, y16..17 | 石板 | ✔（唯一正门过河点） |
| 北岸 | y18..20 | 草地 | ✔（民居/土地庙/渡口） |

**必须守住的契约**（`tools/gen_village_scene.py` 每次生成都会自检，失败非零退出）：

1. `data/maps.lua` village.spawn = (19,2) 与出口格 (19,1) 必须可走、地表为石板；
2. `data/places.lua` 里 16 个村庄地点格必须可走，且从出生点 4 邻域**可达**（NPC A* 用）；
3. 桥面 (24..25,16..17) 必须可走（否则北岸与土地庙/渡口被溪水切断）；
4. 建筑/道具的 solid 不得落在墙或水格上。

村庄的 16 个地点格跨了商业街、茶园、后巷、土地庙、渡口，因此**过河通道**是本图的连通性关键：
北岸只能走石桥，另外西侧 x9..10 与东侧 x30/x37 两条走廊可绕回村内。
`data/places.lua` 顶部的"可行走格事实"注释已同步为本布局（生成器会打印逐行可走区间）。

## 6. 生成与验收

```powershell
cd examples/game_jhyt
python tools/gen_village_art.py            # 地表 tileset + 8 建筑 + 6 类道具 + 预览
python tools/gen_village_scene.py          # 装配 village.scene（含契约自检 + 可走区间打印）
python tools/gen_village_art.py --check    # 6 列 × 32px / 文件齐全校验
python tools/preview_scene.py scenes/village.scene   # 合成 PNG 预览（不开窗口）
```

| 验收项 | 标准 | 工具 |
|---|---|---|
| 地表规格 | 正好 6 列 × 32px | `gen_village_art.py --check` |
| 列语义 | 1 草地 2 夯土 3 石板 4 院墙 5 青瓦 6 水（与山庄一致） | 场景生成器自检 + `--check` |
| 场景结构 | tiles/solid 长度 = w×h、tile 值 ≤ 6、贴图存在 | `preview_scene.py` |
| 玩法契约 | spawn/exit/桥面/16 个地点格 | `gen_village_scene.py` 自检 |
| 资源链路 | `assetc scan` / `import` / `--check-deps` / `game --check` | 引擎 CLI |
| 目视 | `_preview.png`、`_village_preview.png`、`preview_scene.py` 输出 | 人工 |

## 7. 与美术资源方案的对应与后续

- 对应 3.1 的"村庄环境 2 套（MVP）"：本版先做 1 套（石板街/白墙黛瓦/溪水）；
- 对应 3.1 的"装饰物"：招幌、灯笼、摊位、山石、竹树共 5 类新增 + 3 类复用；
- 未做：客栈/祠堂等更多民居变体、四季与节庆装饰（灯笼串/春联）、村外山道与渡口对岸
  （山道属下一张地图 `mountain_path`，会复用本套 tileset 的 1/2/5 列）。

**已知取舍**：

1. 溪水只让石桥通行，是为了让"过河"成为明确的路线选择；如果后续要做"涉水/游泳"，
   需要引擎支持按地块类型的通行代价，而不是现在的 0/1 solid。
2. 北岸三栋建筑（民居 A/B、土地庙）目前只是场景体块，尚未接 NPC 日程与室内；
   接日程时把它们的地点格加进 `data/places.lua` 即可，契约自检会自动覆盖新格。
3. 茶园是"可走的夯土 + 茶垄纹理"，没有单独的作物 overlay；若要做可采摘茶树，
   参照山庄 `farm.lua` + FarmGrid 的做法加第二张 Tilemap。
