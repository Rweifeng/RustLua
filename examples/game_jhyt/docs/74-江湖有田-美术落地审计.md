- 范围：规范、生成器、真实资产与静态接线；不是新的 M74 里程碑，也不宣称 M72 完成。
- 基线：本轮工作树（含原有未提交 tilemap/scene 迁移）；数字应随工具重跑更新。
- 交付：[Style Bible](57-江湖有田-Style-Bible.md) §1.2–1.3、[只读审计工具](../tools/audit_art_assets.py)。只改这份旧规范，其他旧文档不改。

## 1. 证据等级与复现

从仓库根运行，Python 3.9+，仅标准库，无依赖安装、无生成器执行、无资源写入：

```powershell
python -B -X utf8 examples/game_jhyt/tools/audit_art_assets.py --self-test
python -B -X utf8 examples/game_jhyt/tools/audit_art_assets.py
python -B -X utf8 examples/game_jhyt/tools/audit_art_assets.py --json
```

工具按自身位置定位项目，支持任意工作目录。`-B` 不写字节码缓存，`-X utf8` 避免 Windows 输出乱码。JSON 不含时间戳、绝对路径或随机值，相同输入顺序稳定。

- `FAIL missing_asset`：明确引用或文档约定的素材路径不存在。已接线但目标文件缺失仍归缺素材。
- `FAIL missing_wiring`：NPC 没有明确 character 字段，或字段目标没有注册；不是缺目录的同义词。
- `FAIL asset_spec`：PNG IHDR 尺寸/位深/色彩类型不符合指定规格。
- `INFO`：计数、接线声明、未覆盖项，不表示完成。
- 退出码：0 无上述 FAIL（不代表发行通过）；1 发现缺口；2 输入/解析错误。

**实现边界**：去除 Lua 注释后，用受限静态表提取器逐记录检查字段；支持嵌套花括号、别名与末条无逗号，不执行 Lua、不解释拼接路径、不证明运行时可达性。遇不支持的注册表形状以退出码2中止，不能静默给绿。PNG 仅读33字节并检查签名、IHDR标记与字段，不验证CRC/解码/alpha/像素质量。场景仅扫描 component 行的 texture/sheet 明确路径，不解析正在迁移的 tile 编码。作物阶段暂以当前 stages 数量和文档约定的1起始路径核对，不声称满足未来4–6态完整交付。

## 3. 旧文档与真实实现的分歧

1. [第2轮计划](71-江湖有田-对标星露谷美术迭代计划（第2轮）.md) §7“16 NPC全部有character”与 [NPC注册表](../scripts/data/npcs.lua) 不符；[运行时NPC](../scripts/world/npc.lua) apply_art 优先查character，找不到才回退sprite。这里 [资产台账](58-江湖有田-资产台账.md) 的6白贴图结论反而准确。
2. 鱼并非“23张全缺”： [鱼物品扩展](../scripts/data/items_fish.lua) 已有22项fish_icons映射且文件存在。peach与桃子同ID，碰撞守护保留既有物品；优先解决ID/展示语义，不要再盲补23张同名图片。
3. [山庄美术生成器](../tools/gen_manor_art.py) 已有草、土、石、水多档颜色；缺的是文档统一、变体与正确使用，而非源码里只有八个单色。新57登记真实hex，不强迫“色数够了”冒充质感完成。
4. 该生成器头注和TILE_COLUMNS仍固定6列；当前场景已有tiles_format/atlas_cols/atlas_rows字段。**不要重跑旧生成器覆盖dirty场景**。本轮不裁定引擎迁移是否完成。
5. [角色生成器](../tools/gen_character_sprites.py) 与角色manifest的“NPC无法挂Animation”注释已落后；运行时已有animation.attach调用与失败退化。已有阴影绘制函数/半透明色值也不等于建筑投影或场景遮挡完工。
6. 旧计划“64地形格+145作物格装不下1024²”的面积推论不成立：32px无padding格理论容量1024格，209格面积214016px²。实际预算还须算padding、其他图类、导出尺度、打包利用率和运行时资源驻留；本轮不擅自放宽旧预算。
7. 角色绘制脚底FOOT_Y=29经×2对应58–59行；旧规范写52。登记锚点漂移，需按pivot/脚位/碰撞联合核定，不编造两数已对齐。

## 4. 本轮规范完善与验收边界

[Style Bible](57-江湖有田-Style-Bible.md) 新增四材质×四档的明确sRGB hex表，直接源自生成器。补绘制/导出像素单位、低频背景、操作空间保护、剪影对比、三层遮挡、Y排序容差、工具检查与目验分界。**规范完善不是素材已替换**。

自动检查与美术目验必须分开：IHDR合法不是PNG完整解码；尺寸对不等于像素风；路径对不等于被显示；素材存在不等于原创授权。当前模型read_image不支持图像输入，两次已有预览读取均被工具拒绝，因此本轮不声称完成目验。
