> `meridian.on_day_start()` 等价"内力回 30 点 + 空加成重挂"，不改变既有日结行为锚点。

### 7.3 经脉修炼（1.9 新增，改造计划 docs/54 §7.1）

武侠经脉成长线——与熟练度（§7.1，手艺）并行但叙事不同：**熟练度=手艺，经脉=身体修为**。
12 条经脉（任督二脉 + 手足六经简化链）按前置链逐脉冲开，每脉通后获得永久被动。

**派生口径（`systems/meridian.lua` 单一事实来源）**：

- 耗内力 = `10 + (难度-1)*5`；成功率 = `0.90 - (难度-1)*0.05`（下限 0.35）；
  武学熟练度门槛 = `难度-1` 级（任脉 0 级即可冲）；
- 冲穴：前置已通 + 门槛达标 → 先扣内力与材料（成败皆耗）→ 按成功率掷骰。
  成功：经脉永久冲通（进存档），被动即时生效；失败：内力/材料照耗、**不涨进度**
  （反噬小扣），`last_action = meridian_fail_<id>`；
- 拒绝路径（未知/已通/前置未达/熟练度不足/内力不足/材料不足）一律不扣内力、
  不扣材料、不写 last_action（与商店 sell / 出货箱 add 失败语义一致）；
- 被动四键：`attack/defense` 经 player.stats 常驻（聚合值写成 days=1 的 Buff，
  每日 `on_day_start` 在 stats 衰减之后重挂，等价常驻）；`energy_max/inner_power_max`
  经 state（`meridian.max_energy()/max_inner_power()` = inventory 基础上限 + 加成，
  跨天恢复池读它）；
- 内力每日自然恢复 +30（`on_day_start`，钳经脉内力上限）；掷骰用持久化 LCG
  （存档可复现，headless 可断言）。

全通合计：攻击 +3、防御 +4、体力上限 +30、内力上限 +20。

> 验收：`jhyt_m53_meridian` 断言——12 经脉注册与前置链合法、内力不足/前置未通拒绝
> 且不扣不写 last_action、冲通任脉后体力上限 110、肺经 defense+1 经 stats（query=2）、
> 强制失败路径耗内耗料不通、`on_day_start` 内力恢复 +30 且常驻 Buff 重挂、
> 督脉 attack+1 经 stats（query=3）、存档往返、`validate_data` 通过。
