## 11. 字体与授权登记（M72-03，2026-10-08）

**枚举来源**：`project.toml` 的 `font =` / `font_fallback =` / `text_render_mode =`（实测三值），
字体文件的字节数与 SHA-256 直接读盘，码位数读 TTF 的 `cmap`（fmt4 + fmt12）。

| 资产 | 路径 | 许可 | 字节数 | 覆盖 | 状态 |
|---|---|---|---:|---|---|
| 缝合像素字体 Fusion Pixel 12px Mono zh-Hans（**工程实际用的子集**） | `assets/fonts/FusionPixel-12px-Monospaced-zhHans.ttf` | **SIL Open Font License 1.1** | 597,932 | `cmap` 1,606 码位；`jhyt_m72_pixel_font` ④ 读数：用到的字符 1,605 个（`char_collect` 侧计数 1,606）、缺字 0、空字模 0 | ✅ 已入库并激活 |
| 上游全量字体（子集化的源，**不入库**） | `engine/crates/editor/fonts/FusionPixel-12px-Monospaced-zhHans.ttf` | 同上 | 7,040,712（SHA-256 `339f3c71531a6b3caae1023c68873eea45554e87571e8fac5c8954abe27fbff1`） | `cmap` 36,980 码位 | 开发期本地持有；缺它时 `jhyt_m72_pixel_font` **报错并打印取回命令**（不静默跳过） |
| 许可证与核验记录（必须随每份副本分发） | `assets/fonts/LICENSE-FusionPixel.txt` | — | 11,710 | OFL-1.1 全文 + 上游 `LICENSES/` 各组件 + 表结构核验 | ✅ 已入库 |
| Noto Sans SC VF（**已停用，暂留作对照**） | `assets/fonts/NotoSansSC-VF.ttf`、`engine/crates/editor/fonts/NotoSansSC-VF.ttf` | SIL OFL 1.1 | 17,773,244 | `cmap` 30,890 码位 | ⬜ 17.7 MB×2 待下架（`jhyt_m72_pixel_font` ② 的反面对照要用它，下架前先换对照物） |

- **体积收益**：子集 597,932 B 对原来的 Noto 全量 17,773,244 B = **1/29.7**；`project.toml` 的
  `text_render_mode` 由 `vector` 改为 `sdf`（点阵走 `sdf=2` 阈值档 + Nearest 采样）。
- **授权为什么记 OFL-1.1 而不是 MIT**（`docs/71` 原写 MIT，已更正）：GitHub API 的
  `license.spdx_id = MIT` 描述的是**源码仓库**（构建脚本），发布包内附的是 `OFL.txt`，
  且 TTF 的 nameID 13/14 自证 OFL-1.1。上游版权行**没有** Reserved Font Name，
  所以子集化后改名不受条款 3 约束；条款 4/5 要求衍生品（我们的子集）继续用 OFL-1.1，
  不得转成 MIT/BSD 再发布。复现：`curl -s https://api.github.com/repos/TakWolf/fusion-pixel-font`
  看 `license.spdx_id`，与上游包内 `OFL.txt` 首段对照——两个答案不同正是踩坑处。
- **缺字规则**：像素字体**没有**平滑字体的"缺字还能用相近字形"这回事，缺一个码位就是一个方框。
  所以 `char_collect` 收到的工程用字必须逐个能画——常驻判据是 `jhyt_m72_pixel_font` ④
  （用到的字逐字断言"字体覆盖它"且"点阵有亮 texel"）与 `jhyt_m30_cjk_text` ②
  （运行时字符 ⊆ 子集）。**上游全量字体也没有的字符一律改文案**，实测四例：
  `›`(U+203A)、`−`(U+2212)、`✓`(U+2713)、`鳜`(U+9CDC) 在全量 36,980 码位里都不存在，
  已分别改成 `>`、`-`、`●`（`scripts/ui/quest_ui.lua:332`）、`桂鱼`（`scripts/data/fish.lua:77`）；
  加字体不如改文案：换一款字体 = 首包更大 + 三宿主重验。
- **台账缺口**：`docs/31` §资产结构里规划的 `licenses/ASSET_REGISTER.tsv` **尚不存在**
  （目录都没建），音频/美术的逐素材授权登记仍缺，发布门 #9 与 `docs/70` N-09 保持"待外部"。
