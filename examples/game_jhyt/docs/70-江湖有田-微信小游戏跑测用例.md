## 0. 本文怎么用

### 0.1 定位：跑测补的是机器测不到的那一段

本工程已经有**两层机器化验收**，跑测用例**不重复它们**，而是补其覆盖不到的部分，并对已覆盖项做端到端抽查：

| 层 | 命令 | 已覆盖 |
|---|---|---|
| 游戏逻辑（headless） | `scripts\verify.ps1 -MvpOnly`（清单 72 个 `jhyt_*` 样例） | 30 个玩法系统的规则、数值、五态、幂等、存档往返、经济模拟 |
| 平台产物（无头） | `scripts\verify-wechat-minigame.ps1` | 静态布局/配额/后缀白名单/ES2019、路径方言×4、`Image.src` 三种接管形态、启动看门狗、宿主残缺全局、离屏画布、分包挂载六态、wasm 路径实例化、EH/tag 探针、存档后端、触摸摇杆链路 |

**机器测不到、只能跑测的**（详见 §3 各组与 §17）：

1. 微信**开发者工具/真机的真实打包与运行语义**（本机 harness 是 Node 伪造 `wx`）；
2. **渲染效果**（harness 不栅格化字形，纯文字画面恒读 0）；
3. **触摸手感**（harness 触摸坐标是按 375×667 画布反算的常量，不是真手指）；
4. **真机性能**（帧率、发热、耗电、内存）；
5. **生命周期**（`onHide`/`onShow`、来电、切后台）；
6. **机型/基础库/系统兼容性**；
7. **音频与字体的真实播放/字形**；
8. **平台侧发布合规**。

### 0.2 优先级

| 级别 | 定义 | 处理 |
|---|---|---|
| **P0** | 阻断：起不来、进不去玩法、存档丢失、崩溃/白屏、包体超限传不上去 | 未清零不得提审 |
| **P1** | 核心体验受阻：主循环玩不通、关键 UI 打不开、操作无响应、数值明显错误 | 提审前修或书面降级 |
| **P2** | 次要/体验：文案、视觉细节、个别失败提示不准确、低频边界 | 可带入灰度，进 backlog |

### 0.3 编号与「自动化」列

- 编号 = `组-序号`，组含义见 §2。**编号一经发布不复用**，删除的用例留空号。
- 「自动化」列三档：
  - `hb` = 已被 `verify-wechat-minigame.ps1`（harness）覆盖 → 跑测只需**确认现场一致**；
  - `jhyt` = 已被对应 headless 样例覆盖 → 跑测只做**端到端抽查**；
  - `—` = **无自动化覆盖，跑测是唯一发现手段**（这些是跑测的重点）。
- 表格里的 `jhyt_mXX` 是 `engine\crates\game\examples\` 下的样例名，可单独复跑：
  ```powershell
  cd engine
  cargo run --quiet -p game --example jhyt_m19_slice -- ..\examples\game_jhyt
  ```


### 1.3 真机准入

- 体验版二维码可扫（需在公众平台把测试微信号加为体验成员）；

### 1.4 现场取证：四条互不依赖的诊断通道

小游戏没有 DOM 控制台，且实测**开发者工具控制台的"上下文"与游戏全局不是同一个对象**（`适配层已就绪` 打印了、`__RUSTLUA_DIAG()` 却报 `is not defined`）。任何一条通道可用就能拿到现场：

| 通道 | 用法 | 前提 |
|---|---|---|
| 全局 | `__RUSTLUA_DIAG()` / `__RustLuaWechat.canvasInfo()` | 控制台上下文 = 游戏全局 |
| `wx` | `wx.__rustluaDiag()` / `wx.__p2CanvasInfo()` | 控制台里能看到 `wx` |
| 存储 | `wx.getStorageSync('rustlua_diag')`，或直接看工具**存储面板** | 存储面板能打开 |
| **屏幕覆盖层** | 发布目录放 `debug-overlay.txt`，或 `wx.setStorageSync('rustlua_debug_overlay','1')` | **不需要控制台，真机唯一可用** |

确认现场跑的是哪一版（代码包会被工具缓存，"有没有报错"分不清新旧包）：控制台搜 `适配层已就绪`，版本号同时在 `__RUSTLUA_DIAG().version`。

启动还会打两行自检，跑测时优先读它们：

```
wechat-adapter: 资源读取自检 manifest.txt=ok@mainpack project.toml=ok@mainpack（路径形式: main=root-relative pack=root-relative，分包状态: ready）
wechat-adapter: 宿主全局自检 window=宿主 window（已补齐） document=适配层 shim canvas=转发包装 getElementById=ok body=ok
wasm-bridge: 核心实例化成功（WXWebAssembly/path-instantiate，路径 pack/game_web_bg.wasm，导出 111 项：…）
```
