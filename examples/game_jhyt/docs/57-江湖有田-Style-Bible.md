## 0. 一句话风格定义

**国风武侠 × 星露谷式 cozy 像素**：硬边无抗锯齿、32×32 世界格、64×64 导出角色帧、左上统一光源、有限墨色描边、低饱和宣纸/竹青/旧金色板、三层场景渲染、少半透明。玩家一眼能从剪影认出"这是武侠农家的山庄"，而不是任何别的游戏。

## 1. 全局像素总纲（可验收硬指标）

| 维度 | 可验收基准（量化） | 不合格判据 |
|---|---|---|
| 世界格 | **固定 32×32 px tile**，全项目地表/墙/物件统一 | 同图混用 16 与 32、或导出做了双线性模糊放大 |
| 角色导出帧 | **64×64 px/帧**（绘制 32×32，导出 ×2 最近邻，`ART_SCALE=2`），相机 zoom=2 时角色在屏上 128px | 帧高 ≠ 64、存在半透明缩放 |
| 描边 | **1 px 硬轮廓**，墨色 `#1F2328`（ink/900），4 邻域 | 描边 >1px、灰色描边、无描边 |
| 抗锯齿 | **全程关闭**，`FilterMode::Nearest`、不生成 mipmap、RGBA8/sRGB | 出现软边、ALIAS 模糊 |
| 光源 | **全局左上**，阴影落在右下方；统一方向，禁止同一批资产出现 2 种光源 | 角色脚下阴影方向与场景光源相反 |
| 调色板色数 | 单场景主色 ≤ **1 主色 + 1 强调色**；角色单帧色数 ≤ **12 色**（含描边与阴影） | 同一场景出现 ≥3 套互不协调色系 |
| 透明背景 | PNG-24 透明通道；禁止 JPG 源素材 | 白底/黑底、不透明背景 |
| 动画帧间隔 | 项目统一默认 **200 ms**（5 FPS 待机类）；快动作刀光可 **100 ms**（10 FPS）；同一动作全方向帧间隔一致 | 同 clip 不同方向帧数/FPS 漂移 |
| 渲染分层 | 背景（地面）/中景（作物·道具·建筑·NPC·敌人）/前景（树冠·屋檐遮挡玩家）三层 | 前景不遮挡角色、Z 序混乱 |
| 半透明 | 仅雨雪粒子与受击闪白允许；UI/角色/sprite 主体**禁止大面积半透明模糊** | 道具/面板用了高斯模糊或 <40% 不透明压字 |
| 性能预算 | 每地图 ≤ **1 张 1024×1024 atlas**；字体子集首包 ≥2000 常用字；音频 OGG 96 kbps | 单图多 atlas、字体超包 |

## 3. 角色规范（目标 16 NPC + 主角 3 套；现状 10 NPC + 主角 2 形象有序列帧）

### 3.1 序列帧硬指标（8 方向，2026-10-03 由 4 方向扩展）

- **方向集**：`s / n / e / w / se / sw / ne / nw` 共 8 方向；斜向 = 侧身布局 + 正脸头（3/4 视角）。
- **单帧**：64×64 px；脚底锚点固定帧底 `y=52`（绘制格 `y=29`）；脚底碰撞盒 `12×8 px`，站 32px 地面不浮空不下陷。
- **文件命名**：`<动作>_<方向>.png`，全小写下划线；`w` 由 `e` 水平镜像。
- **目录**：`assets/art/characters/<char_id>/`，含 `static_<dir>.png`（8 张单帧兜底）+ 各动作条带 + `preview.png`。

### 3.2 动作帧数量标准（每方向）

| 角色 | 必备动作 | 帧数/方向 | FPS | 循环 |
|---|---|---|---|---|
| 主角 | idle / walk / hoe / water / attack / hurt / faint | idle 4、walk 6、工具 4、attack 4、hurt 2、faint 4 | 6/10/8/8/12/6/6 | idle/walk 循环，其余单次 |
| 普通 NPC | idle / walk / talk | idle 2、walk 4、talk 2 | 6/10/4 | 全部循环 |
| 敌人 | idle / walk / attack / hurt / faint | walk 3、attack 5–7、death 4 | — | walk 循环 |
| Boss | 上述 + 多套技能（前摇帧明确） | 体型可 96×96 | — | 攻击前摇 ≥1 帧做范围提示 |

> 主角单形象 = 28 条条带 / 约 112 帧（×8 方向口径下条带数按 `tools/gen_character_sprites.py` 的 CHARACTERS 表为准）；普通 NPC ≈ 12 条 / 32 帧。

## 4. 作物阶段 sprite（最大视觉缺口，目标 29 种）

- **地块**：作物每阶段占 1 个 32×32 tile；单阶段切静态 sprite，**生长切换不做动画**。
- **每阶段 sprite 序列**：种子图标 → 芽期 → 幼苗 → 成长 → 成熟 → 收获短动画（4–6 帧抖动+闪光）→ 枯萎（灰色降饱和、保留轮廓）。
- **现状**：`data/crops.lua` 注册 **24 种田/药作物 + 5 种果树 = 29 条**，当前 `stages=3`；**尚无 `assets/art/crops/` 目录，阶段 sprite 全部缺失**（现行共用 overlay 占位）。
- **目标规格**：每种 4–6 阶段独立 sprite + 品质变体（普通/银星/金星 3 档角标）+ 枯萎态；果树 5 种（桃/梅/枇杷/枣/银杏）树苗→成树→结果 3 态。
- **占位路径约定**：`assets/art/crops/<crop_id>/stage_<n>.png`（32×32，硬像素、左上光源）。

## 5. 物品 / 图标规范

- **尺寸**：32×32 px，硬像素、左上光源、统一 **1px 深色外描边**（保证在任意 UI 背景上可读）、透明 PNG。
- **硬像素量化（2026-10-06 固化，全资产通用）**：任何 AI 生成/外部委托交付的图标必须过硬像素量化——alpha 二值化（>127→255）+ 每通道 6bit 颜色量化，**禁止亚像素抗锯齿软边**（违反 §1"抗锯齿全程关闭"即不合格）。
- **路径**：`assets/art/items/<item_id>.png`（与各 `data/items*.lua` 的 `icon=` 字段逐一对齐）。
- **现状**：注册表 `icon=` 引用约 **130 处**（items.lua 82 + 料理 16 + 畜牧产物 7 + 钓竿 4 + 矿石宝石 11 + 阶段3 道具 10，另 23 鱼种待补 icon 字段），现有 `assets/art/items/*.png` **93** 张，其中 **85 张已替换为真实形态像素图标**（AI 生成+硬量化 78 张、程序化几何 7 张；2026-10-06 完成），缺口收窄至 ≈16 张（未被引用的扩展条目，待外部委托）。
- 武器/丹药/材料/任务道具/料理/鱼/矿石宝石全部同规格；HUD 状态图标复用 32×32。

## 7. 特效与音频规范

### 7.1 特效（目标 40 组，现状 9 张 PNG）

- **优先 Sprite Sheet 序列帧**，粒子仅用于雨雪等环境；禁止全屏炫目特效。
- 基础特效帧 32×32 px，大型攻击特效 64×64 px；硬像素、少半透明。
- 必备：锄地尘土、播种闪光、浇水水花、收获跳字、刀光、命中火花、受击闪白、轻功残影、治疗/中毒状态提示；扩展到招式/天气/节日/收获共 40 组。

## 9. 风格门验收（每批交付必跑）

1. `tools/gen_character_sprites.py --check`：帧尺寸/列数/RGBA/命名/lua 引用全过。
2. `assetc scan <项目>`：全部 discovered，无 Invalid；`assetc --check-deps` 无断链。
3. `game --project <项目> --check` 退出码 0（色板 token 引用合法断言）。
4. 人工对照本页：色板一致、锚点正确、帧间隔统一、无混风。
5. 本阶段另跑独立基线：`powershell -File scripts/check_asset_baseline.ps1 <项目根>`（见资产台账 docs/58）。
