# 《江湖有田》UI 资源设计

- 文档版本：0.1
- 本版同步：总策划案 0.2、美术资源方案 0.2
- 目标：把美术资源方案 3.4 节的 UI 要求落成可切图、可导入、可验收的具体规格

## 1. 设计总则

1. **文字一律运行时渲染**：所有中文文案通过 `UiText` 与字体渲染，禁止把文字画进切图；唯一例外是首发的标题 Logo。
2. **一套色板、两套字体**：全部 UI 共用第 3 节色板 token 与第 4 节字体，不允许面板各自引入新颜色。
3. **可读性优先**：面板采用深底浅字，正文对比度不低于 4.5:1；小字号不加彩色。
4. **4px 网格**：所有控件尺寸、间距、9-slice 边距均为 4 的倍数，避免缩放出现半像素。
5. **框与内容分离**：切图只提供"框、条、图标"，格子布局用 `UiGrid`，面板底用 `UiPanel` + NineSlice。
6. **纯键盘可完成**：背包、商店、对话、存档等流程在无鼠标状态下可操作（见第 9 节）。

### 与引擎能力的对应

| UI 需求 | 引擎能力 | 说明 |
|---|---|---|
| 面板/按钮/槽位底 | `UiPanel` + `nine_slice_cells` | 四角不拉伸，边距见切图清单 |
| 背包格、商店列表 | `UiGrid`（`cell_rect`/`total_size`） | 间距计入 cell 尺寸 |
| 文字 | `UiText`（`ui_text_effective_scale`） | 字号缩放走统一选项 |
| 图标、进度条填充 | `UiImage` | 条填充用横向拉伸 |
| 点击 | `ClickEvent` | 状态由 Lua 驱动 |

## 2. 视觉基准

- 逻辑设计分辨率：1280×720（16:9），所有 UI 按 1× 设计；
- 最小窗口：960×540，HUD 采用锚点布局，面板居中；
- 世界渲染按整数倍缩放（默认 2×），UI 层独立缩放，整体缩放选项 0.75×/1.0×/1.25×/1.5×；
- 屏幕四边安全边距 16px，HUD 元素之间间距 8px；
- 纹理一律 PNG、透明背景、sRGB（遵循 docs/06 颜色约定）；
- 命名：`ui_<类别>_<名称>[_9s|_<状态>].png`，全小写英文+数字+下划线，中文显示名放数据表。

### 2.1 标题画面背景

- 整幅位图 1280×720、不透明 RGB、不含任何文字（文案一律运行时渲染，见 §1）；
- 两个版本构图完全一致，切换只改 `scenes/title.scene` 里 `Image` 组件的 `texture=`：
  - `assets/art/title/title_bg.png`：平滑渐变版（`tools/gen_title_bg.py` 生成）；
  - `assets/art/title/title_bg_pixel.png`：像素画版（`tools/pixelate_title_bg.py` 生成）——
    4× 整数降采样到 320×180 后用 28 色渐变梯 + 4×4 Bayer 抖动回放，
    剪影（山脊/月缘）取主色不抖动以保持 1px 硬边，星点按原位置重打为单像素；
- 像素密度可按 `--scale` 调整（`--scale 2` 与游戏内世界默认 2× 缩放同密度）；
- 对比预览：`assets/art/title/title_bg_pixel_preview.png`（上=原图，下=像素化）。

## 4. 字体

| 用途 | 文件 | 许可证 |
|---|---|---|
| 标题、对话、物品名、品名 | `LXGWWenKaiGB-Regular.ttf`（霞鹜文楷 GB） | OFL 1.1 |
| 正文、数字、设置与系统文本 | `SourceHanSansSC-Regular.ttf`（思源黑体） | SIL OFL 1.1 |

两个字体已在 `engine/crates/editor/fonts/` 内置，导入工程时保留 LICENSE 文件并登记 `ASSET_REGISTER.tsv`；OFL 字体须在 Credits 附许可证全文，不得单独售卖字体文件。

字号阶梯（逻辑像素，行高 1.4）：

| 级别 | 字号 | 用途 |
|---|---:|---|
| XS | 12 | 键位角标、页码、时间戳 |
| S | 14 | 正文、按钮、列表行 |
| M | 16 | 对话正文、HUD 数字、任务目标 |
| L | 20 | 面板标题、NPC 名字 |
| XL | 28 | 大标题、结算金额 |

规则：

- 最小字号 12px，禁止在 12px 上使用竹青/朱砂原色；
- 设置面板提供字号四档：0.8×/1.0×/1.2×/1.5×，通过 `ui_text_effective_scale` 统一缩放；
- 金钱、时间等数字右对齐，使用思源黑体保证辨识度；
- 发布走现有字体子集化流程（收集实际用字 + ASCII），字体不进入原始发行包。

## 5. 图标系统

- 物品图标：32×32，透明背景，1px 深色描边（#1F2328），光源左上 45°，遵守美术方案 3.3；
- HUD 图标：20×20（生命/体力/内力、天气），金钱 16×16；
- 状态图标：16×16，外框 1px，增益用旧金边框、减益用朱砂边框，底为 `ink/800`；
- 品质边框：40×40 透明叠加层，2px 品质色内描边 + 左上 8×8 角标，覆盖在 40×40 槽位上；
- 全部图标禁止内嵌文字，数量、等级一律 `UiText` 角标（XS 号）。

MVP 状态图标 2 个（中毒、增益），首发补齐 6 个（流血、减益、睡眠、隐身、天气 buff、节日 buff）。

## 6. 控件规格

所有底板类控件为 9-slice 切图，状态切换优先用现成切图（如按钮两态），颜色叠加用于文字与图标。

### 6.1 状态表（通用）

| 状态 | 表现 |
|---|---|
| normal | 基础切图 |
| hover | 底色提亮一档（`ink/700`），文字不变 |
| pressed | 切图下移 1px，文字不变 |
| disabled | 内容 50% 透明度，文字 `paper/500` |
| focused | 外扩 2px `gold/500` 焦点框（键盘导航时显示） |

### 6.2 控件尺寸

| 控件 | 尺寸 | 规格 |
|---|---|---|
| 主按钮 | 高 32，宽随文本+24 | 朱砂底/米白字，9-slice 边距 8 |
| 次按钮 | 高 32 | 木纹框/米白字，9-slice 边距 8 |
| 危险按钮 | 高 32 | 朱砂框+朱砂字，用于删除/丢弃 |
| 槽位 | 40×40 | 9-slice 边距 6，内放 32×32 图标 |
| 进度条 | HUD 高 8，面板内高 12 | 框 9-slice 边距 4，填充横向拉伸 |
| 复选框 | 16×16 | 勾选态为金框+米白勾 |
| 滑杆 | 轨道 4px 高，滑块 12×12 | 体积类设置用 |
| 下拉框 | 高 28 | 复用输入框切图+8×8 箭头 |
| 输入框 | 高 28 | `ink/800` 底，聚焦金框 |

| 提示框 Tooltip | 宽随文本，最大 280 | 宣纸底（`paper/50`）+ `ink/900` 文字，边距 8 |
| 滚动区 | 列表行高 44 | 行间距 4，滚动条宽 4 |

## 8. 面板设计

通用规则：模态面板居中，背后画面加 60% 黑遮罩；面板底 `ink/900` + 木纹边框；标题栏左侧 24×24 朱砂印章图标 + L 号标题，右上 16×16 关闭按钮；面板与屏幕边距 ≥32；打开动画 100ms 淡入 + 上移 4px。

### 8.1 背包（480×360）

```text
┌─ 背包 ──────────────────────────────── [×] ─┐
│ ┌ 槽位 5×4（40 格距 4）─┐   [图标48] 稻谷      │
│ │ □ □ □ □ □           │   良品 · 作物        │
│ │ □ □ □ □ □           │   描述文本两行…      │
│ │ □ □ □ □ □           │   数量 12/99        │
│ │ □ □ □ □ □           │   [使用] [丢弃]      │
│ └─────────────────────┘   [整理]  17/20     │
└─────────────────────────────────────────────┘
```

- 左侧 `UiGrid` 5×4=20 格（MVP 容量与 `inv.create(state.inventory, 20)` 一致），首发扩到 60 格分页；

- 悬浮/键盘选中格时右侧详情同步，tooltip 只在 HUD 悬浮时使用；
- 丢弃、删除类操作弹二次确认（260×140 小面板：文案 + 确认/取消）。

## 9. 键盘操作规范

| 按键 | 行为 |
|---|---|
| Tab / Shift+Tab | 控件焦点循环/反向 |
| 方向键 | 槽位网格、列表行、选项移动 |
| Enter / Space | 确认、激活 |
