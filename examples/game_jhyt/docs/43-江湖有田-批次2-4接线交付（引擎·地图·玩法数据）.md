## 2. 引擎：`animation.attach`（本批唯一 Rust 改动）

新增两个 Lua API（`engine/crates/engine/src/core/script.rs`）：

```lua
animation.attach(id, "default=idle_s;clip:idle_s:<sheet>:4:6:true;clip:walk_s:...")  -- 返回 true
animation.clips(id)   -- 返回 { "idle_s", "walk_s", ... }（调试/验收用）
```

为什么需要：NPC/敌人/特效都由 `entity.spawn` 在运行期创建，而 `entity.spawn` 只插入
`Transform`；`animation.set/get/frame/ended` 都要求实体**已有** Animation 组件，
于是这三类实体此前只能显示单帧。attach 复用同一套组件串解析
（`AnimationStateMachine::from_component_str`），插入/覆盖组件。

配套单测 `runtime_spawned_entity_can_attach_animation` 覆盖：运行期 spawn → attach → `get` 成功 →
`clips` 列表正确 → 推进 0.26s 后 `frame == 2` → 非法组件串被拒且不破坏已有组件 → 死实体被拒。
