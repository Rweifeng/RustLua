## 0. 本轮结论与开工前置

- 工程根：`C:\GitHub\RustLua`；游戏根：`examples/game_jhyt`；场景：`scenes/manor.scene`。
- 山庄是 M72 金标场景：**Python 生成器 → 写盘 PNG/scene → Rust 例程门独立复算**。任何美术改动
  必须沿生成器走，**不手改盘上产物**；改完同步刷新对应的 Rust 门常量与黄金表。

### 0.2 关键判断：闪屏与现行世界**同族同板**，差距在明度层次、材质画法与构图物件，不在色相

- docs/57 §1.1 锁定 token（墨 `#1F2328` / 纸 `#F2EAD8` / 竹青 `#789262` / 旧金 `#C9A05A` /
  朱砂 `#C3452F` / 水 `#7FA3D4` / 木 `#4A3628`）与 §1.2 六族四档色阶，正是从这套闪屏语言收敛出来的。

  `jhyt_m72_manor_terrain` 门钉死，P0 不许改。
